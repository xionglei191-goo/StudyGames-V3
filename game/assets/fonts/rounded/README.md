# 界面圆体

使用作者发布的 [Resource Han Rounded v0.990](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990) 简体中文 Medium 和 Bold 原文件。正文使用 Medium，较大的标题使用 Bold；原 `IslandSans.otf` 作为字体后备，已有明确指定字形的学习舞台继续使用各自字体。

字体文件未修改，完整许可见 [LICENSE.md](LICENSE.md)，来源、文件哈希和字重见 [manifest.json](manifest.json)。字体为 SIL Open Font License 1.1；许可文档还分别说明了上游代码和图像资源的许可，不应把这些条款混作字体许可。
