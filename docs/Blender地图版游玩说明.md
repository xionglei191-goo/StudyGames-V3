# 字母岛 · 小岛界面整理 v0.11.0-dev

这一版沿用完整 Blender 字母岛：五个街区、A—Z 的 26 个地标、中央家园和北侧学校。学校按“字母岛 → 完整校园 → 七处功能场所”分层；主岛之外共 28 个二级场景和 7 个校园三级场景，均由 Blender 资产导入，固定倾斜的镜头跟随角色。

本版把位置与今日心愿放在左上，叶币与设置放在右上，地图、背包、旅行册合成底部入口。旅行册左页继续当前旅程，右页按朋友日常、发现回忆、书里故事分类，可向下滚动；地图目录的数字与场景标记对应。引擎实拍与专项验证见 [主界面更新记录](verification/main-ui/README.md)。

保留 v0.10.0 可带回家展示的字母发现卡与五街区旅行页、可改桌布和座位的 U3 欢迎桌、四幕小聚会，以及八位朋友基于真实经历的回应。作品可暂存、确认、取消和继续改样式；聚会实际看完才留下相聚回忆。功能范围见 [生活纪念记录](verification/life-keepsakes/README.md)。

沿用 v0.9.0 的移动起停、对话镜头、暖色画面、圆体文字和旅行册；右键可立即停止自动行走，小窗口自动使用较大的界面比例。该版记录见 [体验优化记录](verification/cozy-ui/README.md)。此前的家园装饰、五街区短旅、26 站操作与字形观察、U1 跨场景回应和 U2/U3 连续事件见 [P0–P2 验收记录](verification/p2/README.md)，邀请封面与回信布置见 [朋友角样板](verification/friend-corner/README.md)。

v0.7.0-dev 更新了玩家、岛民和已实现教材人物共 12 个三维角色，接入 6 种近景道具、6 类场景材质及 182 张新增透明 PNG，16 个界面插画入口复用已有与新增图像。26 个字母 PNG 与原有 10 张专用故事道具继续保留，完整登记见[原素材清单](../assets/art/storybook_v2/manifest.json)和[新增素材说明](../assets/art/story_props_v3/README.md)。真实果园取放、空间地图、衣橱、装修、回忆册和校园小游戏继续保留。当前直接在本机运行工程；专项检查与真实画面见[本地验收记录](verification/art-finish-v3/README.md)。

想先看词故事：点「旅行册 → 教材里的词故事」，搜索 `book`，打开后选择「我们一起看」并播放。第一只猫头鹰打开封面，第二只翻开内页，风筝最后托起书；也可暂停或逐步看。字母图共用于故事舞台、补接候选、字母体验页和果园发现卡。学习进度和字母编码延续原存档，三维角色和近景物件使用新美术，地图布局和入口保持原样。

10 张道具图包括书的底图、封皮、翻页纸，以及足球、门、窗框、阅读台、球门框、猫头鹰翅片和鼓槌，均已在对应故事中实际显示。书的开合与翻页仍由动作进度驱动；动态文字、提示框、光束和连接线保留程序绘制。全套图片通过原图一致性与实际画面检查，书桌和球门已适配标签与动作位置。

## 新旅程从哪里开始

1. 新存档在自己的小屋醒来，点「去和熊叔打招呼」，角色会沿路走到向导身边；预览门口花朵或星星，确认、取消或稍后再选，再拿上旅行册。衣橱仍可另行换装。
2. 选择「请向导陪我去苹果屋」，角色会走到果树附近，随后进入「和兔兔一起采苹果」。完成采摘、搬运和入篮，或请兔兔完整示范，再看 Aa / Apple 发现卡。其余 B–Z 有各自的物件操作，例如装冰淇淋、开罐子、拼布、接车厢和选雨天撑伞；操作后点「看看建筑里的字母」观察原模型，再收下发现页。字母名和地标词音分别播放，静音也能继续。
3. 每站即时保存。旅行册按五个街区选一到三站，向导陪同出发；也可打开地图慢慢走。首站完整体验后就可点「把这张发现卡带回家」，做卡并选是否展示；完成一个街区的全部字母体验后，还可做该街区旅行页。随后继续下一站或回家。可选回想分为大小写、形象对应与尝试说字母名，均可跳过；说过只记录自述，不评分。看示范同样能完成体验并取得制作资格，不会变成英语独立掌握。
4. 26 站完成后，三年级上册进入欢迎会：问早安、去校园认识 Lingling，给游戏角色选称呼、布置欢迎角，感谢 Peter，任选是否看 hello 故事，与 Anne 打招呼，拍合照并带回家。Peter 实际递书并收回手后才推进；拍照和整章完成分开保存。回家能看照片、换相框并重拍，不会重复发放纪念记录。还可从旅行册去花园与兔兔回应，记录与欢迎会分开。
5. 欢迎会后继续 U2：认识姓名、给 Lingling 和 Tim 投递邀请，拖信到同名信箱，或先点信再点信箱。投错可重试；完成后收到回信。U3 在教室认识年龄卡，按实际三人/四人的人数摆座位；年龄不等于人数。可加减座位，错误不会清空前一步。姓名和年龄情境均提供小提示、陪同选择和完整示范。U3 完成后可回家布置欢迎桌，再看四幕聚会；无需再购买材料。
6. 底部「旅行册 → 教材里的词故事」可按册次、单元及词形/中文搜索。点「播放故事」看动作怎样连接，可暂停、重播或逐步看。六个帮助按钮可随时切换；重复字母保留不同位置。书写练习可选，先看故事再答对会记作有支持的回应。

关闭词故事后再次打开，会恢复分镜、提示、已揭开的缺口、书写草稿和动作位置，并保持暂停，等你点继续。保存失败会保留页面及待写事件，恢复写入后按原顺序重试；不要在未保存提示期间强制结束进程。旧存档可从旅行册「继续原有的生活小心愿」继续原路线，也能参加新旅行。

选册不会清空既有记录。U1/U2/U3 进行中先完成当前章节再换册；其他册目前提供词故事和自由生活，完整八册连续主线仍属后续制作。

## 朋友捎来的小邀请与家长观察册

1. 打开底部「旅行册 → 朋友捎来的小邀请」。系统只从已经体验的字母和已经开放的 U1–U3 中挑选，每段旅程最多两项。没有邀请时可以继续主线或自由生活，不必等待或刷睡觉。
2. 点「去见这位朋友」，到花园、家里或校园与朋友做一件小事。字母任务分大小写和形象对应；情境任务是书面选择，不自动判断发音或口语。
3. 可以自己选、点「给我一点提示」或「看看朋友怎么做」。完整示范后点「和朋友一起看好了」会记录观看示范；不会补成正确作答。
4. 点「先收好，下次接着玩」暂存这一份邀请；重新打开或重启会保留同一份邀请及原提示。点「这次先不试了」结束本次机会，不扣叶币、不影响主线。第一次答错不会因后来选对而被覆盖。
5. 后续邀请使用现实时间安排，游戏日和睡觉不计算在内。错过建议时间不会积累欠账。首次接入的旧档若缺少真实接触时间，显示「间隔未知」。
6. 家长可从「旅行册 → 家长观察册」或设置页进入，按字母、U1–U3、词故事和旧情境课筛选、翻页，查看具体生活经历、首次作答、帮助与时间。原始旧汇总保持原值，不补造逐次表现。观察页没有掌握分数。

回访参数、两种窗口尺寸的实拍和专项检查见[回访验收记录](verification/revisits/README.md)。本机时钟不能验证关机期间的改时钟，界面标明本机间隔；这些记录不等于长期学习效果。

## 把字母发现带回小屋

每一站完整体验后，结果页有「把这张发现卡带回家」。以后可从「旅行册 → 发现卡和街区旅行页」重新打开，或走近小屋里的发现架互动。

1. 选一张已经实际体验过的字母卡。每张卡固定使用自己的地标图，例如 Aa 的苹果，不能换成另一个字母的图。
2. 选晨光、草地或海边背景，再选「大图」或「明信片」排法。当前选择自动暂存，预览不替换家里原来的作品。
3. 想放进小屋时，点「收进册里 · 点这里选展示」，看到「已选：带回小屋展示」后再点「确认收好」。未选展示时，确认后的作品只收在收藏册。
4. 点「下次接着做」保留草稿；点「取消这次修改」放下草稿，原来确认的作品保持不变。之后可从收藏册继续编辑。

晨光村 A–F、巧手街 G–K、林间村 L–P、山丘学园 Q–U、海湾远行区 V–Z 各有一页旅行页。对应街区的每个字母都实际完成体验后，最后一站结果页出现「做一张这个街区的旅行页」；也可从收藏册进入。旅行页可选本街区任一真实发现图作为主图，背景和排版操作与发现卡相同，当前没有自由涂画。

家里同时展示一张发现卡和一张旅行页，替换后原作品仍留在收藏册。只路过地点不开放卡片；旧档会按真实体验记录恢复可制作资格，不替玩家补选过去的图片或展示。制作、换样式和反复回看不加叶币，也不产生英语掌握记录。

## 摆好欢迎桌，再请朋友坐坐

U3 完成后，打开「旅行册 → 我们的欢迎桌 · 相聚回忆」，或回家走近欢迎桌互动。

1. 点「布置欢迎桌」，选择花朵或星星桌布。
2. 先点 Mingming、Dongdong、Tim 或 Anne，再点一把椅子；已有朋友时，两位交换位置。四位来客各保留一个座位。
3. 点「确认摆好」，小屋使用这次确认的桌面。也可以「下次接着摆」保留草稿，或「放弃这次试摆」保留之前确认的样子。
4. 点「请朋友来坐坐」。欢迎、认识来客、一起相聚、道别依次播放，共四幕；可「暂停一会儿」或「稍后接着看」。回来后点「接着看聚会」继续；后台不补播。
5. 实际看完四幕后保存相聚回忆。之后可「再和朋友聚一聚」或继续布置，不重复领取章节成果和叶币。

聚会尚未看完时，先选择继续观看，或「先结束这次放映」，再编辑桌面；结束未完放映不会生成这次的完整相聚回忆。旧档即使早已完成 U3，也只是开放新布置资格，需要实际看过新聚会后才会保存观看记录。保存失败时保留当前页面，按提示重试；未成功确认的草稿不会覆盖家中的成品。

## 去见记得小事的朋友

「旅行册 → 去看看我的朋友」列出已经结识的朋友：熊叔、兔兔、Lingling、Peter、Anne、Tim、Mingming、Dongdong。点名字会前往其所在地点；当前主线正需要这位人物时，入口优先接着完成眼前的事。

朋友会根据实际保存的经历提起邀请封面、回信位置、真实合照、确认展示的旅行作品或欢迎桌。只有真的看完聚会后，才会回忆那次桌布和座位；未确认草稿不会变成朋友记忆。回访可打开相关作品、找别的朋友或继续散步，不发额外奖励、不产生新学习尝试，也没有离线疏远或关系分数。

## 和兔兔一起采苹果

新存档完成熊叔的出门准备后，沿引导进入 A 果园；之后也可从「旅行册 → 和兔兔一起采苹果」再次进入。活动期间镜头会照向果树和篮子，由你指挥兔兔完成动作。

1. 点低枝上的红苹果，或点底部「摘苹果」。兔兔会走到树旁伸手，手接触苹果后才拿起它。
2. 看到「把苹果送到篮子里」后，点场景中的篮子，或点「放进篮子」。苹果会随兔兔的手移动；走近篮子后弯身放下，苹果留在篮中。
3. 发现卡出现后，可分别听「A」和「Apple」，再点「收下这次发现」，随后观察 A 建筑里的字形并收下发现页。完成方式随发现一起保存，看示范完成仍会保留示范记录。
4. 想再试一次，可在发现卡点「再玩一次」。这是新一轮取放，已保存的发现页不会重复计数，也不额外发叶币。

| 想做什么 | 操作 | 看到的结果 |
|---|---|---|
| 先看完整过程 | 点「请兔兔示范」 | 兔兔依次采摘、搬运、入篮；记录为示范完成 |
| 临时停下 | 点「暂停」或在活动中按 Esc | 当前动作与活动暂停；点「继续」后接着进行 |
| 离开果园活动 | 点「下次再来」 | 回到探索；已确认的拿取、入篮状态保存，再进入时恢复 |
| 点击目标不方便 | 用底部「摘苹果」「放进篮子」按钮；空格或 Enter 也执行当前主要动作 | 与点击场景目标使用同一取放流程 |
| 遇到保存失败 | 保留当前页面，恢复写入后点「再试一次」 | 拿取未保存时苹果留在枝头，放下未保存时兔兔继续拿着，保存成功才改变归属 |

拿起、拿着和放入篮子分别有记录，重复点击不会重复推进。这项活动用于 A 的发现体验，不给旧苹果委托增加背包苹果或叶币；原来的每日三颗采集与交付流程仍从生活委托入口进入。

## 看词故事怎样动起来

在 Unit 1 选择「打开 hello 的故事」，或从「旅行册 → 教材里的词故事」查找一个条目。页首显示当前含义和可用帮助；每页最多四个字母演员，较长词分多页，两个相同字母仍按原位置分别出场。

| 按钮或设置 | 操作与结果 |
|---|---|
| 播放故事 / 继续播放 | 从当前动作位置播放；动作做完后依次接下一个字母，整页结束后可翻页 |
| 暂停 | 停在当前动作位置；离开应用窗口也会暂停，回来后手动继续 |
| 再看一次 / 再播放 | 从当前页第一个动作重新播放 |
| 逐步看 | 每点一次看下一个关键姿势，适合慢慢观察取放、打开或传递过程 |
| 上一页 / 下一页 | 切换长词分镜；「给我第一步」只显示第一格 |
| 设置 → 减少动态 | 连续位移改为有意义的关键画面，仍保留动作顺序；不会把动作快进后直接记完成 |
| 遮住试一试 | 隐藏字母图像，自己写一遍；之前实际看过的帮助继续保留 |

`hello` 用抬帽、探头问好和灯光传递串联；`nose` 用猫头鹰的大鼻子托起星星，再把星星喷进蛋壳；`book` 让两个 O 分别打开封面和翻页，最后由风筝托起书；`football` 让足球经过角色传递和两盏门灯。其他故事从现有动作文本生成搬运、接住、翻开、照亮等结构化演出，仍需要后续逐词编辑复核。

「自己想一想」「想想它住哪里」不显示字母演员；「一起补空格」只显示已揭示的位置，动作和相邻说明也不透露缺口。只有画面实际显示后才增加相应动作提示记录。看完整拼写、重播、听已有音频或写对一遍，都不会自动记为长期掌握或独立听说能力。当前是二维图像故事舞台，并非所有词都拥有独立制作的三维动画。

## 启动与游玩

双击项目根目录的 [启动字母岛.cmd](../启动字母岛.cmd)，默认使用本机 Godot 4.7.2 直接运行当前 `game/` 工程。PowerShell 也可执行 `./start-game.ps1`；需要编辑场景时执行 `./start-game.ps1 -Editor`。素材或代码改动后重新启动即可查看当前工程，启动脚本不会自动运行旧 EXE。工具路径可通过 `-GodotPath` 指定，详细步骤见[本地开发流程](planning/art-refresh-all/local-workflow.md)。

[v0.6.1 离线包](../build/AlphabetIsland-v0.6.1-Windows.zip)作为历史成品保留，仅包含首批 B/O/K 插图更新，其成品检查见 [v0.6.1 实施记录](verification/v0.6.1/README.md)。需要查看旧成品时才运行 `./start-game.ps1 -Built`；该命令不会打包，也不包含当前尚未导出的开发改动。旧包复制到其他电脑时须保留同目录 EXE、PCK 和 LICENSES，运行旧包无需安装 Godot。

| 操作 | 方法 |
|---|---|
| 移动 | WASD / 方向键 |
| 自动走路 | 点击可走地面，或在地图中选择目的地 |
| 互动、进入或离开场所 | 点击人物或入口，自动走近后互动；也可走近按 E |
| 继续旅程 | 点击左上心愿条，打开当前旅程步骤 |
| 地图 | M，或底部「地图」；悬停地点可看路线，点击开始步行 |
| 背包 / 旅行册 | B 或底部图标；J 保留原生活回忆册；左上头像也能打开衣橱 |
| 调整远近 | 普通探索时滚动鼠标滚轮 |
| 取消自动走路 | 在场景中点右键立即停下，WASD / 方向键接管，或按 Esc |
| 关闭面板 / 设置 | Esc 先关闭当前面板；没有面板和导航时打开设置；果园活动中 Esc 用于暂停/继续，退出请点「下次再来」 |

## 先过一天小岛生活

1. 原有生活委托仍可直接点场景里的熊叔进入；旧存档也可点旅行册中的「继续原有的生活小心愿」带路。到达后会自动交谈。
2. 和熊叔问好，接下苹果委托。点击心愿条去果园，点击苹果采摘点，每天可以采三颗。采摘结果会显示在场景与背包中。
3. 集齐三颗后再次点心愿条，带苹果找熊叔交付，获得叶币、蛋糕和食谱。蛋糕可以出售；以后采到三颗苹果也能制作蛋糕。
4. 从熊叔的杂货架或背包进入家园布置，挑选家具。点「看看」会回家展示效果；「买下并摆好」才扣叶币并保存。
5. 已有家具点一下可预览摆放或收起，确认才保存；取消或 Esc 会恢复原样。「撤销上次」可撤销本次运行期间的已确认布置，购买的物品仍归你所有。
6. 点击背包选择衣服配色，拖动三维角色查看另一面。回家走近床休息，新一天果园会补充苹果。

家具使用已有的固定摆放位置，暂不支持自由拖放坐标。关闭购买预览不会扣费；购买与摆放一起保存，写入失败会恢复原有余额和物品状态。

## 修改 Blender 地图

主图日常编辑文件是 `assets/blender/alphabet_island/alphabet_island_layout_v06_game.blend`；原 v05 和原始模型保留。校园使用 `assets/blender/interiors/school/school_v03.blend`，其余场景为 `assets/blender/interiors/<room_id>/<room_id>_v01.blend`。音乐、美术和科学教室目录分别是 `music_room`、`art_room`、`science_room`；足球场目录为 `football_field`。

1. 在对应 Blender 工程里调整地形、建筑、家具、道路或材质。
2. 移动场所时连同其入口和交互标记一起移动，保留 `SG_*` 名称。新增或移走障碍时同步调整碰撞代理。
3. 保存 `.blend`，退出正在运行的游戏。
4. 在项目根目录运行 `./sync-blender-game.ps1 -SkipBuild`，读取已保存工程并导出、同步地图，不构建 Windows 成品。若 GLB 已导出，可使用 `-SyncOnly -SkipBuild` 仅同步。
5. 重新启动游戏，走一遍修改区域，检查可见性和通行。

这个更新流程不重新运行场景生成器，也不把人工编辑的地图恢复成初始布局。命名、碰撞和坐标约定见 [Blender 游戏接入约定](Blender游戏接入约定.md)，各地标规划见 [二级地图制作策划](二级地图制作策划.md)。

开发时可在 PowerShell 使用：

```powershell
# 从已保存 Blender 文件导出并同步，保留本地运行方式
.\sync-blender-game.ps1 -SkipBuild

# 只同步已经导出的 GLB，不再启动 Blender，也不打包
.\sync-blender-game.ps1 -SyncOnly -SkipBuild

# 直接运行当前工程
.\start-game.ps1
```

同步脚本支持 `-BlenderPath`、`-PythonPath`、`-GodotPath` 指定本机工具。本地制作使用 Blender、Python（含 fontTools）和 Godot，不需要为了每次查看改动准备新成品包。只有明确需要发布时才运行 `build-game.ps1`；原 [更新Blender地图.cmd](../更新Blender地图.cmd)也会执行完整构建，日常开发优先使用上面的 `-SkipBuild` 命令。

## 遇到问题

- 修改 Blender 后游戏没变化：确认保存的是 v06 游戏编辑版或对应二级场景，完成导出、同步后重新运行工程；同时确认没有使用 `-Built` 查看旧成品。
- 角色走不过去：检查标记是否放在家具里面、通道宽度是否足够，以及碰撞代理是否挡门。
- 导出提示缺少 `SG_*`：在 Blender 中恢复对应标记，不要用游戏代码里的坐标补洞。
- 新材质与 Blender 预览不同：确认使用 glTF 可导出的材质；游戏光照由 Godot 独立配置。
- 本地启动失败：确认 Godot 4.7.2 路径可用，可通过 `start-game.ps1 -GodotPath <引擎路径>` 指定；使用 `-Editor` 查看工程导入或脚本错误。只有启动历史成品时才检查 EXE 与 PCK 是否同目录。
- 词故事停在一幅画面：重新打开或切回应用时默认暂停；点「继续播放」。如果启用了减少动态，画面会按关键姿势切换。
- 新存档直接点果园活动却返回熊叔：先完成打招呼、选衣服、拿旅行册和出发准备，再进入 A。
- 果园提示保存未成功：先保留活动，通过「再试一次」重试；未确认拿取或放置前，物品不会被当作已交接。
