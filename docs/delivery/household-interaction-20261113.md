# 家务改为场景操作

2026-11-13，当前本地 Godot 源码入口。

原先 8 个家务共用全屏文字面板和「下一步」按钮。现已改为在原房间家具上直接操作，进入时镜头拉近，隐藏常规 HUD，左上只保留操作提示，右上可以放下退出。

| 家务 | 实际操作与可见反馈 |
| --- | --- |
| 摆餐桌 | 从旁边托盘拖出 4 张餐垫、4 个餐盘和 4 个杯子，分别放到座位前；每放好一件，物件留在桌上。 |
| 摆茶几 | 展开桌垫，放好两只杯子，再摆果盘。移除原先与任务重叠的预摆杯盘，相聚纪念移到窗边书桌。 |
| 整理床铺 | 拖开床尾被子、把枕头放回床头，再按住被面来回抚平；褶皱随动作逐渐消失。 |
| 收书 | 把地上的 3 本绘本按高矮拖回书架下层对应位置，腾出原先被静态书本占用的书位。 |
| 晾袜子 | 从衣篮取出 4 只袜子挂到晾衣架，再拖动夹子夹住袜口。 |
| 洗蔬菜 | 点击场景里的水龙头开水，抓住蔬菜在水流下反复移动，泥点随清洗消失；洗净后拖入菜篮，关水才完成。 |
| 洗手 | 打开水龙头、按洗手液，按住双手揉搓，再拖到水流下停留冲净泡沫，最后关水。揉搓时可以先关水。 |
| 浇花 | 拿住水壶，在 3 处花丛上方停留倾倒；显示流动水滴，土壤逐块变深，最后把水壶放回架上。 |

放错位置会退回，静止点击不会自动推进清洗和抚平。途中退出会恢复此前已保存的房间状态；完成后显示保存结果，离开再回来仍能看到完成后的摆设。重复游玩后取消也会保留原来的完成记录。保存失败时保留当前操作成果并提供重试。切离窗口会释放正在拖动或按住的动作。

完成记录继续使用原有 `life.home_tasks`，旧存档兼容；家务不会新增英语答对、课程掌握或经济奖励。

## 运行

关闭旧游戏窗口，再双击项目根目录的「启动字母岛.cmd」，使用当前源码入口。走到对应物件旁，打开卡片后选择「摆餐桌」「洗蔬菜」等操作。

```powershell
& 'F:\Tools\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe' --headless --path game --script res://tests/test_household_interaction.gd -- --test-harness
```

添加 `--capture-household` 并去掉 `--headless` 可重新生成原生验证画面。
