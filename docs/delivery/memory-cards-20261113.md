# 物件卡片调整

2026-11-13，当前本地 Godot 源码入口。

- 家园、校园和字母地标的物件卡使用统一布局：标题与地点、英语、出处、横排短按钮。
- 英语旁提供「听读音」「跟读试试」「中文贴士」。中文默认收起，点击后显示句意与原有活动说明。
- 家园卡继续播放对应句子的配套音频。教材出处直接显示册次、单元及纸面页码；原创地标情境显示自己的来源，不标作教材原句。
- 出处将教材、单元、页码连成一行，不再强制换行；长文本仅在空间不足时自然折行。
- 贺卡手工台底部为「画一画」「退出」，短按钮整组靠右排列。其他物件保留相应活动，用相同布局显示。
- 修复书房绘画入口原先被校园场所限制拦住的问题；可直接在书房画贺卡，保留原有画布、保存与未保存离开提示。
- 跟读在当前卡片内录音、结束和显示识别内容，保留英语原句。关闭卡片或切离窗口会停止录音。无输入、静音和服务失败分别提示，不写入英语答对记录。

## 验证

- Godot 4.7.2 / Windows / Forward+ / RTX 4070 图形流程 250 项检查通过，包括 40 个家园物件、实际鼠标点击、音频、中文贴士、画布入口、退出、960×640 / 1440×900 / 1920×1080 布局。
- 现有家园状态回归 23 项通过。
- 通过卡片实际 WAV 编码与现有本机语音服务，预先生成的语音样本识别为 `i'll make a beautiful card`。没有采集玩家麦克风；真人麦克风和背景噪声环境尚待试玩。
- 验证使用进程独立角色，未写入玩家存档。
