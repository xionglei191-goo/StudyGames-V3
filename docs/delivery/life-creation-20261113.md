# 经营与创作系统第一版

交付日期：2026-11-13。适用入口：当前 Godot 源码，通过项目根目录的「启动字母岛.cmd」或 `start-game.ps1` 启动。旧 Windows、Web 导出包没有重新构建。

## 怎样开始

1. 完成熊叔的四步家园介绍；已有兼容存档也可直接进入。
2. 打开「旅行册 → 生活工坊 · 设计、制作与小摊」，领取一次性材料包，选择阅读角、作品收藏或小摊心愿。
3. 在工坊选模板。画布支持画笔、填色、橡皮、印章、撤销和文字；旁边可查看并旋转实物预览。草稿自动保存，设计可另存、命名和归入自定义系列。
4. 保存设计，再确认材料清单并制作。实物进入仓库。进入客厅或小院，点击地面、用方向键微调位置，按 R 旋转，确认后保存。
5. 在作品页面邀请朋友、放到桌面、赠送、借展、陈列或回收。初次可邀请熊叔；Lingling、Anne 在原旅程结识后开放，当前剧情正在使用的人物会提示稍后来访。
6. 想经营时，到小院陈列实物并主动开摊；也可以在订单页接单，带作品到指定场所交付。收入只在确认交付后增加。

米洛和花婆婆的场景对话也有学习手艺入口。材料页会列出当前库存、今日可采数量、地点和补料价格。回家休息推进游戏日，采集恢复一批。

## 本次实现

| 部分 | 当前行为 |
|---|---|
| 材料与配方 | 6 类材料、12 个配方；初始提供基础四种木作，制作、居民示范、借展或招待开放其余配方；不以开店或英语答对作为条件 |
| 创作 | 64×64 画布、16 色、8 个有明确来源的印章；配色、两种款式、装饰部件；招牌、桌布、地毯、画框显示真实绘画，食物托纸使用图案 |
| 设计和实物 | 设计保存、复制和改版免费；制作扣材料；每件实物保存当时完整外观；赠送、出售后的版本不会被原设计修改 |
| 摆放与使用 | 客厅、小院的 0.5 米位置调整、旋转、收纳；检查墙、家具、入口和可达路径；原有自由装修也会避开新增作品 |
| 家具用途 | 凳子可供来访者坐下；桌子／陈列台可放一件花瓶或食品，随桌移动、随桌收纳；篮子打开仓库；绘本架打开词故事库；灯笼可开关灯光 |
| 社区与来访 | F 花园有一处可替换、收回的借展位；朋友实际走向作品，使用座位或观看；支持已摆好的原有沙发、桌、书架等，不复制成手作库存 |
| 收藏 | 真实来访合照保存在本机，可装入新画框；已有 U1 合照也可选用；作品系列、交付对象、当时版本及生活经历可回看 |
| 订单与小摊 | 最多 3 张建议订单，可接、取消或更换，按地点交付；小摊初始 1 位，可扩到 3 位；一场最多接待 3 位顾客，退出后保留营业和收入记录 |
| 原有经济衔接 | 叶币、苹果、蛋糕继续使用原账目；新增蛋糕和旧制作入口不会同时增加两份；已陈列／摆放的蛋糕要先收回才能从旧渠道出售 |
| 保存 | 新内容放在独立 `creation` 段，通过原有整档临时写入、备份和回滚保存；确认页携带版本检查，过期或重复确认拒绝结算；损坏新增数据拒绝覆盖有效存档 |
| 学习记录 | 本次制作、布置、来访和交易不写入英语正确记录，也不替代 26 字母体验或教材章节完成 |

原有房间、物品、服装、教材进度和领取事实继续保留。新增材料包只领取一次，不另外赠送一份初始叶币。米洛教学开放蛋糕资格，不虚构原苹果委托完成。

## 当前边界

- 这是一版可操作的经营与创作流程。新物件采用程序生成的基础模型；坐姿、造型与居民活动仍可继续精修。本版一位朋友一次来访，主要执行坐下、观看和简单取用动作，没有持续需求数值与复杂居民日程。
- 赠送和订单完成后保留对象、缩略图及外观版本；尚未为每位收件人制作独立住宅中的永久摆放与持续使用场面。
- 现有 U2 回信、U3 欢迎桌和发现作品仍使用原入口；这次新画框接入已有 U1 合照与新增来访照片，其他旧收藏尚未全部统一到新画框选材页。
- 图案支持整图铺满与四格重复；暂不提供任意裁剪框、导入外部图片或 AI 生成资产。部件款式按模板选择，暂不提供自由三维建模。
- 新材料包、配方数值和销售价格按设计初值实现。长期经济、儿童操作体验、不同体型坐姿与长期存档仍需继续试玩；没有把短流程通过当作长期平衡结论。
- 首版容量保护为 96 份设计、512 件累计实物记录、4096 条生活回忆；达到上限会拒绝相关新增操作并保留已有内容，不自动丢弃旧作品。
- 本轮未重建 Windows/Web 导出包，未验证跨设备照片同步；照片目前是本机文件。代码改动未提交或推送。

## 代码位置

- `game/gameplay/creation_catalog.gd`：材料、配方、定价、印章和订单内容。
- `game/gameplay/creation_state.gd`：纯数据事务、版本检查、库存和存档验证。
- `game/gameplay/creation_controller.gd`：工坊、仓库、订单、小摊、场景摆放、来访和照片。
- `game/ui/creation_canvas.gd`、`game/gameplay/creation_visuals.gd`：画布与实际物件表面。
- `game/actors/seated_pose.gd`、`game/scripts/textbook_actor.gd`：复用现有骨架适配的坐姿。
- `game/scripts/game_state.gd`、`game/scripts/main.gd`：旧账目、主入口和房间生命周期衔接。
