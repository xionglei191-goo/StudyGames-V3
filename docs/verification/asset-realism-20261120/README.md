# 家园与学校的美术实机记录

本轮调整覆盖 8 个家园场景、8 个校园场景、15 个出场角色、92 件学习道具和手作工坊的 12 种配方。角色沿用字母岛的绘本比例，物件按实际的结构、材质和摆放方式制作。双击工程根目录的脚本即可进入当前版本。[启动字母岛](../../../启动字母岛.cmd)

## 在游戏里看

卧室的大衣柜里，衣架挂钩扣在横杆上，外套沿肩线垂下，裤子与毛衣叠在搁板上。音乐教室的木吉他和小提琴按琴架高度摆放，可以直接从琴身或琴颈点选。工坊的木凳有木榫、斜腿和横撑，制作预览和摆进家里的成品使用同一套模型。[同机位局部对比](comparison.jpg)

客厅里的孩子从妈妈面前走过时，妈妈的头颈会在原有待机动作上轻轻转向孩子。孩子走到背后时，人物逐步回正。挥手、行走和交谈等动作各自控制姿势，开启「减少动态」时会关闭待机转头。[客厅实机动图](attention.webp)

学习道具区分了布料、纸面、木纹和釉面。餐点的近景能看到饺子的捏褶、蒸笼的箍边、米粒以及自然交叠的面条。工坊另有编织篮、花瓶、苹果果盘等 15 款造型，可通过原有工坊入口改颜色、摆放和使用。[全部学习道具](props.jpg) · [工坊造型](craft.jpg)

## 模型和运行验证

- **92 件学习道具。** GLB 合计从 13,718,900 降至 12,809,444 字节，三角面从 493,204 降至 481,468。107 件学习和手作模型均已在 Godot 中逐件渲染，运行版 GLB 与源目录的导出件逐个核对了 SHA-256。两份 Blender 5.2.2 源文件可以独立打开，使用的细节与法线贴图均已打包。[学习道具源文件](../../../assets/art/layer2_storybook_v1/layer2_storybook_v1.blend) · [手作源文件](../../../assets/art/handcrafted_furniture/handcrafted_furniture.blend)
- **15 个角色。** 对原始模型、运行网格、蒙皮权重、形态键和原始分辨率的贴图做了逐项校验。贴图增加 11 级远景采样，用于减轻镜头拉远后发丝和衣纹的闪烁。15 个角色的运行资源因此增加 77.3 MiB。[校验数据](verification.json)
- **16 个场景。** 家园和学校的室内投影距离调整为 60 米，室外为 72 米，覆盖常用正交相机与场景主体之间约 39～40 米的距离。日光和环境补光共同显出脚底、桌腿和墙角的接触关系。[教室全景](after/classroom.png) · [客厅全景](after/home.png)
- **7 组相关回归。** 家校美术 80 项、家校互动 368 项、角色步态 391 项、角色动作 623 项、制作摆放 62 项、工坊存档与经济 110 项、工坊界面 77 项，共 1,711 项通过。工坊界面组使用实际渲染窗口操作，覆盖 1440、1194 和 960 像素三种窗口宽度。[验证明细](verification.json)
