## 范围与保护基线

- 范围：玩家、熊叔、兔兔及已有 9 位教材人物的可变形网格和蒙皮；现有地图近景道具与材质细节；增量故事道具与 UI 插画。
- 原有 94 个 Blender/角色源资产、36 张已验收字母与故事原图及运行副本、课程目录/字母体验数据、动作关键帧库、正式存档与备份在 `protected-baseline.json` 记录 SHA-256。该基线是本轮开始的证据，不把其历史测试结果移作本轮结果。
- 旧角色原型、历史发布包、原始地图和图像保留；制作使用新增路径。测试只写独立 `user://validation-*` 存档。
- 任何影响动作时长、挂点、交互、学习判定的实现变化必须增加对应回归，不能只更新素材清单。

## 必须保留的行为

1. 角色动作的可视接触、语义回执和状态写入分开。手挂点先同步后发接触；同一事件键重播仍有视觉接触，但不重复语义回执。拿取/放置需演完恢复段。
2. Jim 保持坐姿和脚踏支撑，拒绝站立、普通步行及低处拾取；Dino 保留独立翼尾动作。暂停、后台、减少动态不能丢失动作位置。
3. 果园取放接触不超过现有 0.22 米门槛，保存失败不提前转移物品归属；中断恢复、重玩、示范/独立操作区分，以及旧苹果/叶币计数保持。
4. `SG_*` 标记、碰撞、地点入口、返回门前位置、各房间五个探索锚点保持。鼠标走近互动、键盘接管、衣橱三色、家具预览/取消保持。
5. H0/H1 不构建演员舞台，H3 不请求未揭示字母及答案道具；旧教材/编码版本、作答历史、帮助等级、暂停位置与恢复保持。视觉播放不授予独立掌握。

## 证据要求

- `.blend`、GLB、资源、manifest、统计和截图各自能追溯到实际文件 SHA。
- PNG 来源必须为 Godot 原生渲染；静帧只证明该姿态，动作需要多阶段连续采样。至少覆盖人形招手、兔兔取放、Dino 翼尾、Jim 接物及玩家行走/换装。
- 不以“资源可加载”“蒙皮数大于零”“脚本退出 0”代替视觉核查。报告分别记录自动检查、人工图像复核与仍待审阅项目。
