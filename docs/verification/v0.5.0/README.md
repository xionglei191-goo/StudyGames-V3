# v0.5.0 · GDD 首段实施记录

日期：2026-10-22。此版本是 GDD 的首个可玩闭环，仍有明确的后续内容和美术生产工作。原 Blender 文件、固定地标和原始 GLB 未被重写。

## 已接入的体验

- 家园向导、旅行册、26 处真实地标到访和有支持体验；五个事实分别保存，示范完成不增加掌握分数。
- 三年级上册 Unit 1 的欢迎会：游戏昵称、欢迎角选择、可选词故事、首张真实场景合照、回家展示。照片凭据和整章凭据分离且幂等，不额外发叶币。
- 8 册、1,314 个词表出现条目、1,073 个词形、1,096 个故事候选，按真实条目 ID 与教材单元定位。不是 1,314 个互不重复的单词，也不是 81 章生活事件全部实装。
- H0—H5、每镜最多四个字母图卡、重复字母与特殊拼写、可选书写、提示与作答证据和分镜恢复。存储失败时顺序队列保留未确认事件，关闭失败保留页面。
- 四种天气、四个时段、树冠与水面动态、局部小雨、对白/学习暂停、固定白昼与减少动态。环境钟与游戏日分离。
- 144 个来源身份登记，11 个刚性骨骼原型；家园 1 位向导、校园 3 位同学、教室 4 位同学。Dino 使用独立骨架，Jim 原型受轮椅动作限制。未制作角色保留待生产状态。
- 离线内容、26 张原创矢量图、52 条本地合成字母名/地标名音轨、覆盖新文本的内置字体。字体用预组合 é 呈现 café；独立重音元数据不当作额外字母。

## 与完整 GDD 的距离

此版将序章微动作实现为按钮分步与图卡反馈，尚无完整拖拽、地标构件取景高亮和所有可选回想模式。家园首步提供换装选择，门口装饰专用流程仍待制作。欢迎会 U1-01—09 可以完成，U1-10 的跨情境复现和后续章节尚未编排。

词故事当前为可交互的二维图卡分镜，尚未制作完整三维记忆小舞台或每词独立动画；义项题干使用中文释义，只有精确匹配的已有音频可重播，不伪造词义图片或听说测评。人类编辑复核、71 个标题级章节的正文审校和儿童试玩仍待完成。

角色有 Skeleton3D 与刚性部件绑定，尚未制作最终蒙皮、Mixamo 导入动作和 Tripo 替换成品。144 条来源身份不等于 144 个已完成 NPC，也不等于 144 个互不重复的自然人。天气与昼夜已经运行，但没有跨设备性能结论或完整质量档位验收。

## 运行与核验

根目录 `build-game.ps1` 先重建词汇包、复用/生成独立音轨并核验字体，然后运行新模块测试、实际场景旅程测试和原有状态、行走、校园层级、Blender 绑定、UI、生活小游戏与集成检查，最后导出 Windows。

字体扩充命令：`uv run --with fonttools==4.61.1 python -X utf8 scripts/build_font.py`。构建时只需现有字体与 `--check`，不会为成品运行引入 Python 或网络依赖。

详细结果以同目录报告及 `build/logs/` 为准。测试使用进程独立的验证存档，不覆盖正式游玩文件。内置成品检查通过 `AlphabetIsland.exe -- --test-harness --release-smoke` 显式启用，验证包内词库、字体、图卡、语音、场景与演员，运行后删除自己的临时存档。
