# 本机角色与进度互通

2026-10-25，v0.13.0-dev。电脑单机与网页已使用同一份本机角色存档，入口服务运行于 http://127.0.0.1:4189/ 。仍限定本机，没有部署公网、账号系统或跨设备云服务。

## 怎么继续玩

1. 双击根目录「启动网页联机.cmd」，选择「我的单机角色」或新建角色。原来的单机进度已复制导入默认角色，原件未改动。
2. 选「自己逛逛」，点「在网页继续」；也可以点「在电脑端继续」，打开同一角色的桌面游戏。邀请朋友和加入邀请码仍在同一个入口。
3. 网页顶部显示保存状态。「进度已保存到这台电脑」表示共享存档已确认写入。点「保存并返回」，先保存游戏事务与浏览器文件，再释放角色占用。
4. 电脑端退出后，在网页选择相同角色即可接着玩。双击原「启动字母岛.cmd」也会使用共享默认角色，且不依赖网页服务运行。其他角色可用 `start-game.ps1 -ProfileId <角色编号>`。
5. 同一角色正在一端游玩时，另一端会提示先保存退出。不同角色互不占用；与朋友同行时，物品、任务和学习记录依然各归自己的角色。

网页旧角色会显示「等待网页导入」。必须在保存它的原浏览器、原网址进入一次并保存，才可在电脑端继续。导入前保留浏览器源副本；导入中断不会允许电脑端先建空档，也不会让没有原文件的另一浏览器补建空档。原浏览器角色目录清单未被改写。

`-Editor` 的编辑器运行、直接运行 Godot 工程，以及 `-Built` 的历史成品仍使用旧存档入口；当前共享流程由上述启动器和网页入口提供。

## 保存与恢复

- 规范文件：`.local/shared-profiles/<角色编号>/progress.json`；上一份有效文件为 `progress.json.bak`。
- 原单机导入另保留 `import-original.json`，角色资料记录原路径和 SHA-256。不会把测试进度写回 AppData 原档。
- 原生进程由独立 supervisor 持有文件锁；Windows Job 将游戏生命周期与锁绑定。网页服务持有相同的锁，并用内容 SHA 校验保存版本。
- 网页先保留恢复草稿再上传。断线时显示待同步；服务恢复后点「重试同步」。失效连接无法覆盖另一端的新进度。
- 若两份进度已经分叉，入口保留副本并提供「使用已同步进度」「恢复未同步副本」。恢复前也会备份当前进度；「恢复记录」可查看时间、叶币和天数。
- 浏览器空间不足时不会声称已经同步。最新候选可能暂时只在内存，页面会要求不要刷新，并提供「下载进度副本」和重试。
- 服务重启后，网页重试如果发现另一端已有新存档，会要求重新加载，避免旧游戏在取得新版本号后覆盖新进度。

学习记录随角色写入本机共享存档服务；房间 WebSocket 广播仍只包含昵称、同行位置、场景、衣服及挥手，不广播完整个人存档。

实际 Chrome 页面读回了原生测试角色的 83 叶币、第 4 天、单元 2 和 3 条学习记录。第一次换装退出实操出现「粉色曾写入，随后又变回蓝色」，该次不计作成功往返。[失败记录](native-web-continuation-failed.json) 与 [修复前页面](screenshots/01-web-continued-pre-fix.png) 保留。

纯 Node 测试用实际旧版入口源码复现了条件性路径：用户选择粉色后，延迟的蓝色同行报告回写下拉框，后续 change 再把蓝色排入保存。新版在 input 时保存用户意图，待游戏确认前不让旧报告覆盖选择；对应序列只产生一次粉色保存。该复现证明旧代码有此路径，不能直接证明真实浏览器当时必然发生了相同的第二次 change。

修复后另以真实 HTTP 服务和实际网页同步模块写入粉色，再由实际 Godot 原生进程读取粉色并改为黄色，83 叶币、天数、单元、完成记录和学习记录数量全部保持：[HTTP/JS 证据](http-js-roundtrip.json)、[原生续接证据](native-web-transport-roundtrip.json)。这是存档传输往返验证，未冒充最终浏览器 UI 复测。

界面自动化在识别前台浏览器网址时触发停止，未绕过该限制。因此最后一版的浏览器「换装 → 保存返回 → 再进入」整段实操仍待复测。此次未运行全量项目测试，也不代表公网、手机、跨设备或学习效果验收。

原内容与正式存档保护清单 69/69 文件 SHA-256 不变：[保护报告](protected-files.json)。默认共享档、共享备份和永久导入副本均与原单机文件逐字节一致：[导入报告](formal-import.json)。

当前 4189 服务健康检查与首页返回成功，实际提供的大厅、同步模块、样式与源码哈希一致，仅监听 127.0.0.1：[运行核对](served-runtime.json)。4191 隔离验收服务已停止。
