# P0–P2 实施与验收清单

用户要求完成 P0–P2；范围按 GDD §21 的项目阶段，不把美术域的 priority 同名编号当作另一个阶段。当前基线 v0.7.0-dev，保留现有美术、地图几何、入口、课程原文、经济和正式存档。本轮仅本地工程，不导出成品。

| 工作 | 实施内容 | 验收证据 |
|---|---|---|
| P0 | 核对策划/教材来源/角色 ID 与跨域契约，保留未知与后续 P3 范围 | 静态验证及来源报告 |
| P1 | 沿用四类角色和故事样板；对受影响接口回归，刷新当前资产下的风水同条件性能 | 动作/故事/碰撞/暂停与原生性能记录 |
| 家园 | H02 门口装饰预览、确认、取消和稍后选择；H03 实际地图入口 | 新档真实输入与恢复 |
| 26 站 | 真实地点与现有节点；每站原策划具体微动作、点选替代拖动、四级帮助、暂停恢复；源模型字形取景 | 26 项动作语义与原生双尺寸画面 |
| 旅行册 | 五街区与 2–3 站自选短旅、回访、独立音轨播放记录、三种可选回想证据 | 跳过/示范/乱序/静音/磁盘恢复 |
| U1 | 欢迎角名牌、真实交接与合照、照片安放和重拍、另一场所跨情境复现 | 交接后提交、照片/整章幂等、提示不降级 |
| U2/U3 | 原创邀请投递、姓名问答与道别；角色年龄卡、十以内座位卡、下一位来客 | 连续故事、实际演员、错误重试/示范/保存失败恢复 |
| 总体验 | 新旧存档、选册、全部帮助、可选记忆跳过、退出恢复、学习证据隔离 | 受影响逻辑、端到端与双尺寸原生测试 |

正式源资产、课程文本和存档以开工基线/历史美术保护清单核对；允许修改的代码副本留在 `.local/p2-baseline`。本文件保留开工范围，实施结果与通过状态以 [本轮验收记录](README.md)、`verification-summary.json` 和各项原始报告为准。独立儿童试玩、全部八册课程与 144 条身份记录生产属于后续验收范围，不能以自动测试替代。
