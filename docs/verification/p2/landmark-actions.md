# 26 站实际动作与实现边界

每站先完成对象操作，再观察原始三维地标中的字形；实际点击查看后保存 `glyph_seen`。字母名与地标词音各有入口，静音不写入已播放。第 0 级为自己尝试，第 1/2/3 级依次为小提示、陪同一步、完整示范；最高帮助等级保持。A 保留三维果园的原有分层帮助与接触记录，其余站点在实际对应场景打开二维观察卡。

| 字母 | 操作 | 画面反馈 |
|---|---|---|
| A | 兔兔摘取、拿着、放入篮子 | 实际三维角色、苹果挂点与篮子接触；失败不提前转移归属 |
