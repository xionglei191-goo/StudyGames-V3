# v0.9.0-dev · 温暖绘本生活

2026-10-23。本轮依据实际运行画面处理操控、镜头、字体和界面，方向由用户选择为「温暖绘本生活」。使用 Godot 4.7.2 本地工程，入口仍是根目录 `启动字母岛.cmd`。

## 本轮变化

- **走路更连贯。** 到达路径点后同帧寻找下一点，消除原先每个路径点停一帧的现象。键盘与点击行走都加入短起步缓冲、松开后的减速；最终落点减速，右键停止立即清空路径、待交互目标和落点提示。按键接管与门口自动交互继续保留。
- **角色更靠近。** 普通探索镜头略拉近；对话根据两人距离取景、互相转向，配上实际三维角色头像。对话与手帐打开时收起外围 HUD；人物提示放在底部，不覆盖角色脸部。衣橱和头像有轻微待机表情，支持减少动态。
- **画面更暖。** 室内暖米色背景、较暖的环境填光和较轻的阴影；室外保留草木与道路层次。昼夜、天气、故事指定的早晨、固定白昼和减少动态继续生效。
- **文字更清楚。** 界面使用资源圆体 Medium / Bold，暖棕正文、植物绿主按钮和暖纸底色。标题与正文区分字重，较小辅助文字最低 18 个逻辑像素；窄窗口采用 1280×800 的逻辑画布，1440 宽窗口使用 1440×900。已有明确指定字形的学习舞台仍使用原字体。
- **入口更像生活手帐。** 旅行册左侧集中展示接续目标，右侧使用带插画的生活入口。心愿提示去掉重复章节前缀，U1 用具体行动取代步骤编号。朋友角、词故事、地图与衣橱仍从原入口到达。

## 存档与字体来源

修改前源文件及正式存档备份保留在 `.local/backups/cozy-ui-v1/`。第一次截图期间，先前仍在运行的游戏实例退出，正式存档哈希发生变化；差异只涉及此前朋友角版本的迁移字段，没有回写旧档。后续以这次落盘后的主档、备份和两张已有合照作为保护基线，隔离验证的核对结果见 [存档保护记录](preservation.json)。

字体采用作者发布的 [Resource Han Rounded v0.990](https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990) 简体中文原文件，未修改；[字体清单](../../../game/assets/fonts/rounded/manifest.json)包含来源和 SHA-256，[完整许可](../../../game/assets/fonts/rounded/LICENSE.md)为随附的作者许可文件。运行时以原 `IslandSans.otf` 作为后备。[字体和界面对比度核查](font-and-contrast.json)记录本轮所用文件与主要配色。

可复现入口：`game/tests/test_cozy_controls.gd`、`test_movement.gd`、`test_life_ui.gd`、`test_living_world.gd`、`test_friend_corner_game.gd` 和 `capture_cozy_review.gd`。涉及正式主场景的测试必须传入 `-- --test-harness`；截图及朋友角脚本支持尺寸和输出目录参数。
