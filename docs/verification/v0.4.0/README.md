# v0.4.0 生活交互升级与验证

2026-10-22 · Windows x86_64 · Godot 4.7.2

## 已交付的体验

- 主界面合并头像、地点和日期，心愿条可以带路；地图、背包、回忆册使用统一图标。
- 点击场景中的人物或入口会沿真实可走路线靠近、转身并互动；WASD / 方向键和 Esc 可取消导航。
- 地图渲染当前真实场景，包含当前位置、空间标记、悬停路线。密集标记错开放置并连回原地点，当前位置不会被遮住。
- 对话采用底部人物布局；衣橱提供可旋转的三维角色、即时配色与随身物品格；家园布置保持房间可见。
- 家具先预览，再确认、取消或撤销。购买并摆放为一次存档事务，保存失败会一起恢复叶币、所有权和摆放状态。
- 人物增加行走摆臂、招手、伸手和踢球动作，采摘和奖励在场景中出现，并配有互动音效。
- 音乐欢迎曲、美术明信片、三组科学调色、五球射门练习均可操作。美术草稿在离开时可保存、继续或放弃；射门保留最好成绩。
- 回忆册记录探索地点、体验和作品；英语提示/试错/独立答对继续单独记录。新增玩法不写入英语掌握成绩。

## 复现与边界

运行项目根目录 `build-game.ps1` 可重新执行构建检查并导出。生活交互测试与截图脚本分别为 `game/tests/test_life_ui.gd`、`game/tests/capture_ui.gd`；都必须带 `-- --test-harness`，以免接触玩家进度。截图脚本仅在带图形界面的 Godot 下运行，支持 `--capture-dir=绝对目录`；生活测试支持 `--report-dir=绝对目录`。

最终 PCK 的外部测试脚本通过 Godot 编辑器可执行程序的 `--main-pack` 运行；EXE 通过程序内置的 `-- --validate` 入口验证。二者的验证入口分别记录，未将外部脚本测试冒充为发行 EXE 的外部脚本能力。

家具沿用三种装饰及固定位置，衣服沿用三套配色。足球是五球射门练习，尚无完整比赛或多人对战；音乐、美术和科学为短体验，各地标完整经营流程与其余教材课程仍属于后续内容。本次交付和验证平台为 Windows，未发布新的 Web 或移动端成品。
