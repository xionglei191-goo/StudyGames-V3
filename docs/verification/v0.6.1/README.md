# v0.6.1 · 第一批生成式故事插图

本轮将 B 小船、O 猫头鹰、K 风筝三张透明生成插图接入游戏，共用在词故事舞台、H4「一步一步接」候选按钮和字母体验页。图像沿用同一参照板的暖木色、奶油白、鼠尾草绿和圆润手绘质感。每张原始 PNG 为 1254 × 1254，源图与游戏副本逐文件摘要一致。

素材与完整生成提示词保存在 [素材说明](../../../assets/art/storybook_v1/README.md) 和 [清单](../../../assets/art/storybook_v1/manifest.json)。旧 SVG 继续作为回退；独立美术版本为 `storybook-v1`，教材内容与字母编码版本没有改变。原有三维地图、骨骼角色和其他字母图片不在本批替换范围内。

原生截图验证实际纹理出现在舞台、候选按钮和体验页中；`book` 的两个 O 保持不同演员位置和不同动作。H3 未揭示的字母图片不加载；H0/H1 保持无图片答案；旧内容版本、首次回应、后续回应和真实独立存档往返均通过。正式存档及备份的前后摘要相同。

实际点击 H4 候选图时发现并修复了一个原有类型错误：条件表达式产生的无类型数组无法赋值给 `Array[String]`，使候选按钮构建中断。现改为显式类型数组后按原规则调整顺序，两次猫头鹰选择和后续风筝候选均实际点击验证。

Godot 的默认透明边缘修补会改写低透明度像素的 RGB，本批关闭该选项，导入后的原生纹理与源 PNG 像素一致。大小窗口的真实浅色背景未见明显色晕或拉伸。详细说明见 [组件视觉复核](../art-refresh-v1/focused-visual.md)。

四词视觉复核发现新猫头鹰正面图的喙部位置与旧 SVG 不同，长鼻会从侧翼伸出。现仅为实际加载的新 O PNG 调整鼻根并应用演员的旋转、缩放；SVG 回退仍保留原锚点。星星位置、动作时间、语义与保存格式不变。最终两尺寸采样均对应修正后的舞台源码。逐动作视觉说明见 [四词画面复核](../art-refresh-v1/animation-visual-review.md)，128 张最终图的解码、尺寸和摘要核对见 [产物审计](../art-refresh-v1/animation-artifact-audit.json)。
