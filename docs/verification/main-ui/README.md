# 主界面与面板协调更新 · v0.11.0-dev

日期：2026-10-24（Asia/Shanghai）。本轮针对场景周围常驻信息分散、按钮视觉重量相近、面板标题和留白不一致的问题，重组 Godot 原生界面。沿用现有暖色三维场景与绘本插画，工程直接本地运行。

## 实际改动

- **主界面**：左上是角色、地点和日期，下面单独放今日心愿；右上合并叶币与设置；地图、背包和旅行册放进底部同一组，旅行册是主要入口。互动提示位于按钮组上方，行走提示放在左下，路线提示靠近当前心愿。
- **旅行册**：左页放当前故事、下一步行动和真实发现进度；右页按朋友日常、发现回忆、书里故事分组。目录支持滚动和键盘焦点跟随，原有入口继续使用相同动作 ID。
- **地图**：保留真实场景俯视图与路径入口，地点列表改成较轻的目录行；探索点的数字与地图标记对应。
- **共享面板**：标题在上、说明在下，关闭键固定在右上；缩小按钮圆角和阴影，对话面板收紧留白。衣橱、设置、朋友、发现作品和欢迎桌沿用同一主题。
- **关闭与恢复**：修正隐藏期间计算底部按钮组最小尺寸所造成的位置漂移，关闭面板后重新布局。

本轮没有修改场景几何、碰撞、课程或存档格式。既有家园、朋友角、发现作品和聚会功能继续沿用；本次画面检查不代表这些系统全部重新验收。

## 专项验证

测试工具为 Godot 4.7.2，Windows / OpenGL Compatibility / RTX 4070。检查使用独立的 `validation-<进程号>.json`，不向正式存档写入测试进度。

两个窗口分别保留 12 张画面，包含客厅、岛上、地图、衣橱、设置、对话、新档与 U3 旅行册、朋友、发现页、朋友角和欢迎桌。960×640 窗口沿用项目的宽高比适配，逻辑画布为 1280×800，原生画面导出为 960×600；1440×900 窗口与导出一致。

主界面检查覆盖按钮边界与重叠、地面点击行走、真实鼠标命中及动作分发、关闭/Esc 后恢复、旅行册每个入口的滚动裁切可见性。移动专项覆盖路径连续性、右键停止、滚轮缩放、对话人物取景、模态恢复和核心字体字符。

| 检查 | 结果 | 原始报告 |
|---|---|---|
| 1440×900 原生界面 | 278 / 278 通过 | [默认窗口报告](after/1440x900/report.json) |
| 960×640 原生界面 | 278 / 278 通过 | [小窗口报告](after/960x640/report.json) |
| 移动、停止、缩放与对话镜头 | 20 / 20 通过 | [操控报告](controls-report.json) |

复测时发现一次输入预检的时序问题：合成鼠标移动已命中目标，但等待一帧后系统鼠标位置和窗口焦点发生变化。测试现在在同一次输入分发后读取真实 GUI 命中，按下与抬起前重新定位，仍要求动作实际触发；报告的 `input_trace` 保留即时与下一帧的对照。最终默认窗口记录中，目标位置 `(856, 836)` 的旅行册按钮即时命中，下一帧位置变为 `(1112, 715)` 且窗口失焦，明确证明了这类测试干扰。

本轮为受影响界面的专项验证，没有运行游戏全量测试，没有生成 EXE 或 ZIP；自动检查与画面审查不构成儿童可用性或学习效果结论。

正式存档、备份和两张欢迎照片的前后哈希见 [保护文件核对](protected-files.json)，均与修改前备份一致。修改前代码与文件清单保存在本机 `.local/backups/main-ui-20261024/`。已有旧游戏进程未被本轮关闭。

## 运行与复核

关闭旧游戏窗口后，双击仓库根目录的 [启动字母岛.cmd](../../../启动字母岛.cmd)，即可运行当前工程。底部打开「旅行册」；从左页继续当前旅程，或在右页选择想做的事。

```powershell
& 'F:\Tools\Godot\4.7.2\Godot_v4.7.2-stable_win64_console.exe' --path game --max-fps 60 --script res://tests/test_cozy_controls.gd -- --test-harness --report-dir=F:/LoveStudy/docs/verification/main-ui
```

主要实现为 `game/ui/island_hud.gd`、`game/ui/travel_book_view.gd`、`game/ui/island_theme.gd` 和 `game/scripts/ui.gd`。旧版验证记录保留在各自目录。
