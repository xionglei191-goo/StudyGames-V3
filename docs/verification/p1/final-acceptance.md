## 保留的范围限制

- 角色仍为刚性骨骼样板；四类通过不代表全部教材人物已完成最终蒙皮与外观生产。
- 专属词动画与通用来源动作舞台分开登记；当前样例不推定全词库语义审校或儿童理解效果。
- 窄窗口为实际 960×640，内容纹理为 960×600；其他设备和分辨率未据此推定通过。
- 性能为 Ryzen 5 3600 / RTX 4070 / 驱动 610.88 / 1440×900 / GL Compatibility / 4× MSAA 的调试引擎固定镜头记录，关闭 VSync，全部 Windows 样本实际在前台；不能称默认发布版、后台或低/标准/高三档验收。
- CPU/GPU 计时仅覆盖根视口，另有 Windows 进程 CPU/内存。引擎 TIME_PROCESS/PHYSICS 是每秒缓存峰值，只保留诊断，不当作逐帧 CPU 预算。
- PNG 序列读取在计时以外，目标 20 秒/4fps；主岛实际捕获 37.235 秒且世界时钟推进约 8 秒，故不称实速连续视频或全帧闪烁证明。
- 四天气×四时段×全部房间/尺寸、指定低端设备预算、P2/P3 扩展和儿童真实试玩仍按计划另行验证。
