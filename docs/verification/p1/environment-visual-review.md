# P1 风水样区原生视觉核查

核查日期：2026-10-22。结论：**通过本轮晴天、白昼、固定镜头的 P1 样区视觉门槛**。未发现需要阻止封包的材质缺失、树根漂移、镜头跳变或整幅颜色异常。

依据为 [正式采样目录](performance-20261022-193930/)、[原生序列清单](../../screenshots/v0.6.0/environment-motion/visual-capture-report.json)与下列三段 GIF 所依据的 243 张 1440×900 原生 PNG。全部 PNG 均成功解码；目视复核了三张全景拼图、各场景首帧，以及第 0、20、40、60、80 帧的树冠、树干和水面局部对照。GIF 为原生帧缩小后的 960×600 预览，没有生成中间帧。

风的幅度较轻，缩小后的全景拼图不适合单独判断是否运动。原尺寸局部序列可分辨树冠轮廓变化，且不同树冠没有明显整齐同步摆动；湖面细纹比树冠运动更容易观察。此次没有为展示而移动镜头或增大风力。

碰撞与锚点结论来自运行记录，而非仅凭画面：三段序列的 `static_structure_unchanged` 均为 `true`；[配对摘要](performance-20261022-193930/summary.json)中六组动态关闭/开启配对均可比较，结构、演员布局与相机条件一致。现有实现只变换树冠网格并添加水面覆盖材质，树干与静态碰撞不随风水变换。这证明受测序列及配对中的结构稳定，不替代全地图重新行走。

采集目标为每段 20 秒、4 fps；果园和校园分别实际跨约 20.005 秒、20.004 秒。主岛 81 帧因图像读回及编码开销实际跨 **37.235 秒**，世界时钟推进约 8 秒。GIF 保留采样间隔，不能称为固定频率的实速视频。所有截图均在正式性能计时区间以外；性能结论只取独立 CSV，详见 [性能说明](performance-20261022-193930/performance-review.md)。

在已检查的稀疏原生帧中未见明显闪屏、颜色跳变、树冠脱离或岸线错位；这些最多 4 fps 的样本**不证明所有渲染帧均无闪烁，也不证明视频流畅度**。本轮不覆盖四天气×四时段、其他分辨率、三档画质、全岛全部风水目标或其他硬件。
