# 生活心愿与工坊界面重做 · 2026-11-13

已接入当前本地 Godot 工程，正常退出此前打开的游戏，再从项目根目录 `启动字母岛.cmd` 启动即可使用。

## 实际调整

- 心愿页突出当前心愿、实际进度与下一步行动。其他心愿收为次级入口；回家、小院和邀请朋友集中在旁边。
- 主要导航为心愿、工坊、作品册、仓库、材料。订单、小摊和回忆放在“更多生活”中；编辑作品时只保留返回、草稿状态与关闭入口。
- 工坊模板改为实物模型图库，显示材料要求与尚未学会的配方。预览直接使用游戏中的作品模型。
- 小凳、花瓶、收纳篮等没有绘画表面的物件，以大实物预览、配色、有效的造型选项与命名为主。
- 招牌、画框、桌面、地毯和食品托纸等有绘画表面的作品，以大画布为主，配色在侧边，右侧显示实物预览；外观与文字按页切换。
- 保存设计、制作确认和材料需求固定在底部。次要的另存与换表面操作保留在“更多”菜单中。
- 调整了窗口边距、容器缩放、长文字换行和布局稳定时机；次级页面的操作行可以自动换行。

原有设计、绘画数据、制作事务和存档结构沿用。非绘画物件中已有的图案和文字仍保留在设计内，换到支持的表面时可继续使用。本轮未修改 Blender 原始模型、角色或学习内容，也未重建旧 EXE/PCK 和网页导出包。
