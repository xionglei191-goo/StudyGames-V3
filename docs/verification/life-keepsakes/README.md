## 现在可以玩什么

| 成果 | 入口和操作 | 保存边界 |
| --- | --- | --- |
| 字母发现卡 | 完成任意一站真实体验后，点「把这张发现卡带回家」；也可从旅行册打开收藏。选晨光、草地或海边背景，选大图或明信片排版。 | 字母与固定地标不变。试做会暂存，确认才进入收藏；可选带回家展示，再次编辑或取消。 |
| 五街区旅行页 | 本街区所有字母体验完成后制作；可选择街区内的一张地标图作为主图。 | 五区分别解锁；家中可同时展示一张字母卡和一页旅行页，其他作品仍在收藏册。 |
| U3 欢迎桌和小聚会 | U3 最后一页进入欢迎桌；旅行册也有「我们的欢迎桌 · 相聚回忆」。选花朵或星星桌布，再选朋友、点椅子换座位，确认后请大家入席。 | 试摆可恢复或取消。四位角色实际坐在对应椅子上；四幕约 18 秒，支持暂停和下次继续。完整看完才保存相聚回忆。旧 U3 完成档可以布置，不会自动获得观看记录。 |
| 朋友记得小事 | 旅行册 →「去看看我的朋友」，或直接走近已结识的朋友。 | 熊叔、兔兔、Lingling、Peter、Anne、Tim、Mingming、Dongdong 依据存档中的邀请、合照、采摘、作品或聚会回应。当前未完成任务优先；Tim 聚会后仍能聊原邀请。 |

新作品和聚会不增加或消耗叶币，不修改原有英语掌握、帮助级别或章节奖励。保存失败时回滚本次确认并保留草稿，可重试；确认相同作品不会重复生成奖励。聚会离开或进入后台会停止推进，旁白与画面同步暂停。
