# 英语学习小镇的字母地标与记忆宫殿世界设计

版本：世界素材第五版，材质统一与角色视角局部精修。日期：2026 年 10 月 22 日。

这是一座以英语学习为核心、具有温暖生活感的 2.5D 小镇。孩子可以走动、拜访邻居、收集物品、完成委托和布置自己的家。A—Z 对应 26 个外形鲜明、位置固定的公共地标，字母直接融入地标的门洞、窗框、支架和材质；孩子通过反复生活，逐渐熟悉地图，并学习借助地点回忆英语。

当前阶段优先完成世界地图素材：26 个字母地标、中央家园与独立学校。五个街区及已有空间记忆规则保留。教材故事线暂不开发，后续以家庭和学校为开篇范围，并按选定教材内容另行编排；本稿中的旧剧情草案暂存。具体首发设备暂不锁定。

## 一 核心设计决定

| 项目 | 本版决定 |

孩子首先体验到的是“我在这里有自己的家，认识朋友，能让这里越来越好”。英语是理解邻居和参与活动的工具。玩家的穿搭、装饰和个人喜好允许多样选择；涉及语言理解的委托才有明确的完成条件。

## 二 字母锚点的选择规则

每个字母只有一个主锚点词。主词及对应轮廓在后续版本中保持稳定，换皮和升级不得把 Apple 换成另一种 A 开头的对象。

选择对象时同时考虑：容易画出明确轮廓、儿童能理解实物、能发展成有用途的场所，以及与相邻地标区别足够大。地标可以是建筑，也可以是可进入的树屋、码头、露台或自然观察站。

地图中的大写字母直接成为建筑的一部分：A 可以是苹果屋的入口木架，G 可以是地球仪支架，X 可以是木琴舞台的交叉琴槌。字母与对象轮廓共同承担识别，取消建筑旁独立的字母牌。字形需要简洁、朝向清楚，在总览和正常游玩距离均能辨认；夜间也应有足够的材质或灯光对比。

走近并交互后，可以在短暂的学习界面显示大小写组合与完整英文词，如 `Aa · apple`，并播放独立的标准读音。建筑主要承载大写字形，小写字形通过识字互动单独建立联系。首字母关系用于识字和导航，不能代替自然拼读教学；字母名称和词内发音分别处理。

Q 选 Quilt，V 选 Volcano，X 选 Xylophone。这些词优先承担地标命名功能，初见时提供图片、中文和读音支持，不要求先会拼写才能进入场所。Xylophone 的词首读音尤其需要单独示范，不能从字母名称推断。I 的主词固定为 Ice cream，Y 固定为 Yarn。

26 个地标不按首字母收纳全部词汇。C 蛋糕坊可以学习 egg、milk、mix 和请求表达；这些内容依据真实活动建立联系。A—Z 负责稳定的世界索引，主题任务负责语言的使用。

## 三 世界地图与街区布局

世界暂称“字母岛”，属于工作名称。全岛为一块相连的陆地，中央有湖泊和家园草地，外缘是海湾。道路随地形弯曲，公共地标朝向道路，入口可见。河流、低矮台地、树林和小桥帮助区分街区。

| 街区 | 字母 | 总览位置 | 地形与气氛 | 主要活动 |
|---|---|---|---|---|
| 晨光村 | A—F | 左下、西南 | 果园、浅水码头、花圃与低矮房屋 | 初识小镇、食物、物品、简单请求 |
| 巧手街 | G—K | 左上、西北 | 石板街、小店、工作台和风筝草地 | 购物、制作、收集、颜色与选择 |
| 林间村 | L—P | 上方偏右、东北 | 缓坡、林间空地、树屋与小农田 | 邻里、阅读、位置与自然观察 |
| 山丘学园 | Q—U | 右侧、东南 | 低台地、观测屋、实验院子与车站 | 顺序、天气、时间、计划与探究 |
| 海湾远行区 | V—Z | 下方中央、南岸 | 海滩、平缓岩丘、栈道和邮驿 | 旅行、交流、回顾、综合委托 |

中央玩家家园设在湖泊南侧的小草地，通往各街区的入口清楚可见。中央空间使用普通住宅、邮箱和小广场，不占用 A—Z 编号。玩家可以修改自家外观和家具摆放，公共街区保持可辨认的结构。

主导览路线为：晨光村 A—F → 巧手街 G—K → 林间村 L—P → 山丘学园 Q—U → 海湾远行区 V—Z，再经南岸步道回到晨光村。每段路线内部都可以单独复习。导览沿地标入口依次行进，地图坐标不随任务重新随机生成。

日常玩法同时保留各街区到中央草地的捷径。孩子熟悉地点后可以用地图跳转到已访问的街区入口，避免复习变成重复长途跑图。主路线是回忆线索，不是强制通行规则。

### 字母融入建筑的具体方式

这是每个地标的建模规格。优先用有用途的构件构成字形，曲面或不便承重的位置可采用嵌入式窗洞、浮雕或编织纹样。字形不附带底板，不悬浮，也不作为路旁摆件。整体保留对象轮廓，避免为了拼字母而失去 apple、boat 等物体特征。

## 五 地标内部的固定记忆位置

每个已制作地标先规划五个可区分的位置，不要求一次学满。位置按“入口 → 左侧工作点 → 中央工作点 → 右侧工作点 → 出口或展示点”形成可复述的小路线。具体形态随建筑变化，不机械复制五个相同柜子。

| 地标 | 五个固定位置 | 首批可以发生的动作 |
|---|---|---|
| A 苹果果园屋 | 门前篮子 → 左侧果树 → 中央分拣台 → 右侧洗果池 → 出口礼物架 | 摘取、分拣、清洗、交付 |
| B 船屋码头 | 岸边路牌 → 左侧长凳 → 中央系船柱 → 右侧货架 → 船舱门 | 找物、装箱、运送、登船 |
| C 蛋糕烘焙坊 | 门口订单板 → 左侧材料架 → 中央料理台 → 右侧烤箱 → 出口取餐窗 | 识别需求、取料、混合、招待 |
| D 鼓屋音乐厅 | 门口节目牌 → 左侧乐器架 → 中央鼓台 → 右侧排练席 → 出口纪念墙 | 听、敲、停、轮流、邀请 |
| E 蛋壳孵化屋 | 门口照料板 → 左侧软垫 → 中央孵化台 → 右侧食水架 → 出口观察窗 | 观察、匹配需求、照料、记录 |
| F 巨花温室 | 门口种子盒 → 左侧花盆台 → 中央花床 → 右侧水池 → 出口花束架 | 选种、栽种、浇水、整理花束 |

公共位置及主要功能保持稳定，装饰只在不破坏轮廓和入口的范围内更新。任务用的小篮子、信件或花束可以移动；承担长期回忆功能的工作台与建筑入口不能随机搬家。

一个位置先关联一个基础概念或紧密相关的小组。比如 C 的材料架关联烘焙原料；新单元通过新的订单复用这些原料。不要每天把同一位置改成完全无关的单词清单。需要扩容时增加有清楚入口的新房间，并保留旧路线。

五个位置是制作规格，不是“每个地标只能学五个单词”的容量结论。不同知识目标可在同一场景中以不同事件练习，但只有被明确教学的地点关联才记入记忆线索。

## 六 英语学习与记忆任务

一次完整学习过程包含：看见实物并听到表达 → 在有支持的任务中使用 → 撤掉部分提示后再用 → 隔次回忆 → 在其他场景使用。

系统分别记录四类表现：字母与地标关联、空间路线回忆、英语理解、英语表达。找到苹果屋不等于听懂 apple；听懂 apple 不等于会拼写；跟读完成不等于能主动表达。

| 阶段 | 孩子的体验 | 支持与证据 |
|---|---|---|
| 初识 | 邻居带领孩子走近地标，说出单词，展示物品 | 图像、英文、中文解释和可重播语音；不做能力判定 |
| 有支持的使用 | 根据一条需求拿取物品，角色示范动作 | 提示可用；记录提示后完成，不标记为独立掌握 |
| 独立理解 | 新需求出现，物品无正确答案高亮，选项位置变化 | 记录首次选择、提示情况和完成结果 |
| 地点辅助回忆 | 在别处想不起词时，想一想之前去过的地点 | 可依次提供街区、地标、内部位置和完整答案提示 |
| 情境迁移 | 在家里或另一位邻居处使用同一词或表达 | 原地点不在画面里；重新理解请求，而非重复点击路线 |
| 表达尝试 | 用词块或简短语音向邻居说明需求 | 词块辅助、跟读、主动口语分别标注；不混为一个分数 |

地点提示只对已建立过关联的内容使用。孩子初次不知道词义时先教清楚，不让其凭空猜。选择任务至少改变选项位置与无关外观细节，避免用“固定左边按钮”代替语言理解。

方位任务需要保留真实空间关系。例如同一个 basket 可以在长凳下或货架上，但 bench 和 shelf 的位置稳定。这样孩子必须理解 under 或 on，不能只背某个坐标。尚未教过的地点名和操作动词可以用图标与中文辅助，避免把无关难点叠加进测试。

回访暂采用当次短回顾、后续约 1 天、3 天、7 天的任务窗口，属于待验证的产品参数。以实际回访时间记录间隔；错过窗口时在下次游玩自然补上，不扣奖励、不损坏家园，也不要求每天登录。

## 七 旧版剧情草案（暂存）

### 第一次冒险 新邻居的欢迎会

目标时长约 8—12 分钟，为原型估计。首次只引入 A、B、C 三个主锚点。新的核心词为 apple、boat、cake；核心理解表达为 `I like ...`。其他角色台词提供简短中文和动作支持，不作为本轮测试内容。

| 步骤 | 地点和故事 | 学习与操作 | 完成反馈 |
|---|---|---|---|
| 1 | 中央家园，孩子刚搬进小镇 | 学会移动、走近、交谈；挑选自己的门牌样式 | 房屋成为可布置的家 |
| 2 | A 苹果果园屋，邻居准备水果 | 先认识 apple，再听一条需求并拿取苹果；必要时提供提示 | 苹果装进欢迎会篮子 |
| 3 | B 船屋码头，另一位邻居送来野餐用品 | 认识 boat，找到系在码头的小船并帮忙取下坐垫 | 船和小路成为熟悉的地点 |
| 4 | C 蛋糕烘焙坊，确认客人喜好 | 听 `I like cake.`，从已教过的食物中为客人取物；孩子自己的口味自由选 | 欢迎会准备完成 |
| 5 | 中央家园，摆放收到的苹果坐垫 | 自由决定摆放位置；拍下第一张小镇相册 | 获得可持续看见的家园变化 |
| 6 | 可选的短回顾 | 在家中对已学词做一次新请求，先不显示原地点；需要时提供地点提示 | 留下独立或提示后完成记录 |

正式的独立理解探测不复用演示时的高亮、物品排列或固定镜头。初访 C 的顺序本身就可能提示 cake，因此初访表现只作为练习，主要学习证据来自家中或后续新任务。

### 第二次冒险 欢迎会的小节目

首次回访时先轻量复用 apple、boat、cake，再开放 D、E、F 的导览。孩子在鼓屋排练、在蛋壳屋帮忙照料、在温室准备花束。新词为 drum、egg、flower；按进度学习 `This is a ...` 和 `This is an egg.`，不把冠词差异混成随机扣分点。

第二次冒险可以拆成多个短委托，不要求一口气走完三个新地点。完成后得到一盆可摆放的花。玩家可以在已开放街区自由活动，地标开放与英语熟练度分开记录。

## 八 制作边界与验证方式

第一版原型需要实现：角色移动、摄像机跟随、接近交互、物品拾取和交付、少量家具摆放、可重播语音、提示层级、任务记录与本地存档。公共地标使用固定坐标和稳定标识，任务内容单独配置，方便替换教学内容。

首批搭建 A—F 的外部轮廓、入口及上述固定工作点；室内按任务需要逐步开放。其余二十个地标先保留在世界规划和概念图中，不同时制作完整室内。中央家园与开放地标之间应有短路程和清楚入口，具体移动速度和距离通过儿童试玩调整。

每次学习事件至少能够区分：目标词或表达、提示形式、提示层级、是否首次独立正确、是否换情境、距上次接触的时间。步行速度、反应时间、口音和操作熟练度不直接当作英语水平。

第一轮可邀请约 6—8 位目标儿童做定性试玩，主要找操作与理解问题。观察：

- 能否直接辨读建筑内嵌的字形，并说明它与对象的关联；检查 G/C、O/Q、P/R、M/N、I/J。
- 在测试图中遮去主要字形后，能否凭对象轮廓区分地标，尤其是 C/I、E/N、D/X、M/U、G/Y。
- 离开一个街区后，能否描述或找到刚去过的地点；是否必须一直依赖导航箭头。
- 在没有原建筑、没有答案高亮的新任务中，是否能理解目标英语。
- 地点提示是否帮助回忆，还是增加额外负担。
- 孩子是否主动使用家具奖励、拜访邻居，以及是否愿意继续生活任务。

小样本试玩用于发现问题，不能证明学习效果。若要主张字母地标本身改善记忆，需要在学习时间、词汇、任务和反馈相近的条件下，与不使用显式地点联想的版本比较，并安排前测和延迟测；不要把“记住了已知单词”算作新增学习收益。

## 九 世界地图的美术规格

概念图采用横向高分辨率鸟瞰构图，能看清整块岛屿。用柔和的立体游戏模型感表现 2.5D 观感，树木、房屋、路面都有体积与接地阴影。相机采用比实际游玩更高的俯视角，减少建筑相互遮挡。

色彩以草绿、浅蓝水面、暖米色道路和低饱和屋顶为主；鲜艳色集中在主锚点对象。五个街区依靠地形、植被和建筑材质区分，仍属于同一个自然连贯的世界。道路必须留出角色活动空间，建筑要有生活细节，地图不能变成二十六个孤立图标。

图中包含 A—Z 各一个主要大写字形，直接嵌入对应地标的结构或材质。材质包括木架、铜框、玻璃开口、奶油门廊、石砌凹槽和编织线条；字形须有真实厚度与接地关系。取消独立的字母牌、底板和悬浮标记，不塞入长段中文、任务面板或复杂图例。中央保留湖泊、普通玩家住宅和小广场。地图不复制现成游戏的角色、地图布局或界面。

图片的检查重点是：整体是否像可以生活的小镇、26 个锚点能否辨认、字母是否与建筑真正结合、分区关系是否与本稿一致。图片中的道路不是可运行的导航网格，建筑尺寸和道路宽度会在原型阶段校正。概念图表达融合方向，具体构件仍按上表在建模时逐项校正。
