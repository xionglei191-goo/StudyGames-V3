# v0.5.0 环境与角色渲染核查

2026-10-22，Godot 4.7.2、Compatibility / OpenGL 3.3、NVIDIA RTX 4070。

使用独立 `WorldBuilder + Living` 截图场景；命令包含 `-- --test-harness`。没有实例化主线场景，没有写入游戏进度，没有运行全局导入，也没有修改已冻结的运行脚本与模型。

## 核查范围

- 主岛、苹果园各完成晴／多云／小雨／薄雾 × 清晨／白昼／黄昏／夜晚的 16 组真实渲染，共 32 张。
- 校园与教室保留默认演员位置，补拍两个实际游戏俯视角群像。
- Lingling、Peter、Anne、Mingming、Dongdong、Tim、Dino 各一张清晰近景。为检查单个原型，近景截图实例临时隐藏其余演员与旧静态老师；不改变演员位置、场景建筑或正式运行行为。
- 第一轮 9 张低角度角色截图保留作诊断。目录共 50 张 PNG，均为 1280 × 800。

## 结果

32 组环境画面均能正常显示地面、模型和水体；晨昏与夜晚的照明、雨雾的能见度变化可辨。未见黑屏或整片材质失效。夜晚保留较亮的环境光，是本次学习场景可读性方案的表现，不代表真实夜景写实效果。

实际游戏俯视角中，校园三名同学、教室四名同学均可见。第一轮低角度近景中，Tim、Mingming 被前景演员或旧静态老师遮挡；其中一张的前景 Dongdong 脸部出现黑色多边形与细纹。拉远正交相机并采用单人检查后该现象消失，实际游戏俯视群像未复现；本轮没有把它认定为已证实的模型或着色器缺陷。低角度特写仍需单独安排镜头与站位。

`render.stderr.log`、`actors.stderr.log` 均为空；标准输出没有 Shader Error、SCRIPT ERROR 或失败保存记录。全部 PNG 能解码且具有非均匀画面，数值检查见 `image-quality-check.json`。

## 交付边界

角色是 `Skeleton3D + BoneAttachment3D` 刚性分件原型，尚非最终蒙皮模型。截图核查没有验证完整步态、脚底接触、口型、变形质量、全部 142 个教材来源身份或低端设备性能，也不构成最终角色生产验收。静态天气矩阵不证明完整 36 分钟自动昼夜周期；共享时钟及暂停另由组件测试覆盖。
