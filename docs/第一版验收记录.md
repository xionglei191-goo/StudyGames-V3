# 字母岛 v0.1.0 实机验证记录

验证日期：2026-10-22。游戏引擎：Godot 4.7.2。验证环境：Windows，NVIDIA GeForce RTX 4070，Compatibility / OpenGL 3.3，1440 × 900。

## 可交付内容

- `game/`：完整可编辑 Godot 工程、三个复用模型、场景代码、课程数据、18 条语音和可离线使用的中文字体。
- `build/windows/AlphabetIsland.exe` 与同目录 `AlphabetIsland.pck`：Windows 独立运行程序。
- `build/AlphabetIsland-v0.1.0-Windows.zip`：包含程序、资源包、字体许可和游玩说明的分发包。
- `启动字母岛.cmd`：项目内双击启动入口。

第一版包含村庄、校园、教室、食堂、操场和家园。生活循环为认识邻居、采摘、委托、制作、售卖、装饰和休息；课程覆盖前三个单元的部分核心表达与九个改编情境，不代表整册或完整单元已经全部制作。

## 本版边界

这是已实现开场玩法的独立片区。原有 Blender 全岛 26 个地标与 130 个锚点仍保留在素材目录，没有全部接入当前游戏。室内和角色为首版基础造型；尚无自由拖动家具、多人联机、口语识别、口语评分或开放式 AI 生成剧情。学习记录描述本次任务表现，不等同于长期掌握结论。

Windows 独立版已经完成上述验证。仓库提供可选 Web 导出配置，但本次交付未验收浏览器、手机及平板运行。
