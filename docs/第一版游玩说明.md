# 字母岛 · 我的第一天 — 0.1.0 游玩说明

这是面向 Windows 的第一版可玩小岛，采用斜上方俯视的 2.5D 画面与跟随镜头。可以散步、认识邻居、采苹果、制作和出售蛋糕、布置家园，并练习开场三个英语单元的核心表达。

首版学习内容包含三年级上册开场三个单元的九道新编情境题。教材索引与生活词汇预览不等于完整课程已实装；当前版本也不包含开放式 AI 对话、语音识别或口语评分。

## 启动

在项目根目录双击 **启动字母岛.cmd**。启动器优先运行 `build/windows/AlphabetIsland.exe`；尚未构建时会使用本机 Godot 打开 `game/` 项目。

拿到导出包后，也可以直接双击 **AlphabetIsland.exe**。请保持 `AlphabetIsland.exe` 与 `AlphabetIsland.pck` 在同一个文件夹；这个 Windows 包运行时不需要安装 Godot。

第一次打开会使用初始小岛进度。之后再次打开会自动读取本机存档，继续之前的叶币、物品、任务、装饰和学习记录。首版没有多个角色存档槽。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动 | `W A S D` 或方向键 |
| 前往地面位置 | 鼠标点击可行走地面 |
| 与附近人物、建筑或果树互动 | 按 `E`，或点击屏幕下方互动按钮 |
| 地图 | 按 `M`，或点击右上角「地图」 |
| 背包、回忆册、设置 | 点击右上角对应按钮 |
| 关闭面板、返回 | `Esc` 或面板上的「关闭」按钮 |
| 选择对话和答案 | 点击选项；也可用 `Tab` 移动焦点后按回车 |

打开对话或学习面板时，角色会暂停移动。建筑和树木有碰撞，点击目标应落在道路或草地上。

## 第一圈怎么玩

1. **认识邻居**：按左上角的「今日的小心愿」寻找面包师熊叔。走近后互动，完成打招呼任务。
2. **采摘苹果**：在果园采集三个苹果，再去完成邻居的苹果委托。每个游戏日共可采三个苹果。
3. **体验经营**：完成委托后获得蛋糕并解锁制作配方。一个蛋糕需要三个苹果，出售一个蛋糕可获得 15 枚叶币。
4. **布置自己的家**：获得叶币后购买装饰，并在家园布置面板中摆放或收起。黄色、粉色、蓝色三套衣服可免费切换。
5. **到学校学习**：按顺序完成三个单元。每单元包含三道情境题；完成一个单元可领取一次 15 枚叶币奖励。
6. **回家休息**：进入下一游戏日后果园重新可采。这里的「一天」由游戏中的休息操作推进，不依赖电脑日期。

打招呼奖励 5 枚叶币，苹果委托奖励 20 枚叶币及一个蛋糕，均只能领取一次。装饰价格分别为花箱 25、野餐布置 35、暖光小灯 45 枚叶币；已拥有的装饰可以重复摆放、收起，不需要重复购买。

## 学习记录怎么看

题目出现会增加曝光记录；答题尝试、提示后答对和独立答对分别保存。使用提示，或在同一次练习中先答错再答对，会记为辅助答对。以后重新练习并独立答对，可以再增加独立答对记录。

辅助答对也可以用于完成当前单元并解锁下一单元，但不会因此标为独立掌握。重复复习不会再次领取单元奖励。

## 存档与重新开始

重要操作后会自动保存。Windows 默认存档目录是：

```text
%APPDATA%\Godot\app_userdata\字母岛 · 我的第一天\
```

主要文件是 `island-save-v1.json`，备份为 `island-save-v1.json.bak`。主文件损坏时会尝试恢复上一份有效备份；无法读取的原文件会在后续恢复或保存时改名保留。

如需从头开始，先完全退出游戏，再将这两个文件一起**移到自己的备份文件夹**，重新启动后会建立初始进度。只移动主文件可能触发备份恢复。不要在游戏运行中改动存档文件。

## 从源码打开和构建

推荐使用 Godot 4.7.2，并安装对应版本的导出模板。游戏源码在 `game/`；模型、语音及课程 JSON 均随项目保存，日常游玩不需要连接教材网站。

```powershell
# 打开 Godot 编辑器
.\start-game.ps1 -Editor

# 指定自己的 Godot 位置
.\start-game.ps1 -GodotPath 'C:\Tools\Godot\Godot.exe'

# 导入素材、执行状态与实际行走验证、导出 Windows 版本
.\build-game.ps1 -GodotPath 'C:\Tools\Godot\Godot.exe'

# 另行导出 Web 预览，供浏览器检查
.\build-game.ps1 -Web -GodotPath 'C:\Tools\Godot\Godot.exe'
```

也可以设置 `GODOT_PATH` 环境变量，或将 `godot` / `godot4` 加入 `PATH`。脚本还会检查项目内的 `.tools/godot.exe` 和 `tools/godot.exe`。导出日志位于 `build/logs/`，Windows 输出在 `build/windows/`。

Web 预览输出在 `build/web/`，需要通过本地 HTTP 服务打开，不能直接双击 `index.html`。Web 与 Windows 使用各自的存档空间，浏览器预览不共享桌面版进度。

## 常见情况

- **启动器提示找不到 Godot**：使用已导出的 Windows 包，或按上面的命令指定 Godot 可执行文件。
- **复制后运行失败**：确认 EXE 与同名 PCK 文件一起复制，且 PCK 未被改名。
- **角色走不过去**：换一个道路上的点击位置，或用方向键绕开障碍物。
- **苹果采完了**：回家休息进入下一游戏日。
- **制作或购买按钮没有成功**：查看提示，核对配方是否解锁、苹果数量与叶币余额。
- **出现存档写入失败提示**：该次操作会回退，先检查存档目录权限和磁盘空间。
- **听不到发音**：先点击一次游戏页面或语音按钮，并检查系统音量；部分浏览器要求用户操作后才允许播放音频。
