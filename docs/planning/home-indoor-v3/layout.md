# 可行走的门厅与走廊

源码：`scripts/build_home_hall.py`。运行入口 `build(render=True)`，也可在 Blender CLI 中直接执行此脚本。空间 ID 为 `home_hall`；显示名称及 `room_label` 为“家里 · 门厅与走廊”。

这是进入住宅后的导航空间。玩家从正门走进玄关，沿中央地毯进入横向走廊，再走到实体房门前进入七个独立生活房间。空间不放置知识点或家务任务，也不重建七间房内部。模型原创，沿用现有木色、奶油色和青绿色材质，无外部图像、模型或纹理来源。

## 布局合同

Blender 米制、Z 向上、-Y 为前；Godot 对应 `(x,0,-y)`。地板 28×20 m，Blender `x[-14,14], y[-10,10]`。中央通口 `x[-6.1,-.9]` 宽 5.2 m；前排两翼用连续 0.92 m 护墙及短回墙形成剖视轮廓，实体门的门套、门柱、门头保留真实高度。后墙完整，屋顶不生成。

## 生活细节与画面组织

地板为暖木拼板，端缝错排；中央玄关长地毯与后排横向地毯形成 T 型导向。连续护墙板、踢脚线、门头线脚和墙灯连接门洞，避免孤立门框排列。门扇具有下部凹板、门合页、黄铜把手和几何用途图标。

玄关左侧布置鞋格凳、长坐垫、衣帽板、挂钩、衣物、穿衣镜和伞篮。后墙浅柜摆家庭照片、植物，并配墙钟与高窗。前厅右侧为长椅、书、边桌、植物和家庭画框。家具集中在边缘，不占中央通口或七个门前站位。
