## 发现与修复

| 对象 | 发现 | 已落实的修复 |
|---|---|---|
| apple、lemon | 整果突然成为切开的两半 | 明确请求洗净、切开的动作，再承接果肉和两半果实 |
| football | 球先被传过沟，之后又渡同一条沟 | 猫头鹰在同岸传球，火车沿岸送到码头，小船只渡一次沟 |
| can：能够 | 球被接住，但没有明确进入篮子 | 鸟巢托稳篮子，球落进篮底，能力结果可见 |
| can：罐 | 回忆问题突然说空罐 | 改为正文已有的金属罐，结尾保持同一野餐饮品 |
| zoo | 从入口模型无过渡地切换成实景参观 | 全篇统一为玩偶游客沿迷你步道参观动物园模型 |
| interesting | 问题说种子变成树，正文却是门内出现树；暗处线索显现缺原因 | 问题改为种子下的小门里出现纸叶树；蛋壳持灯照出虚线 |
| Mother's Day | 蘑菇想感谢母亲，结尾却由苹果换成感谢自己的母亲 | 苹果陪同，蘑菇亲自向同一位母亲表达感谢 |
| make the bed | 问题要求先移杂物，正文直到后格才移动 | 前格先把枕头和玩具暂放床边，后格放回枕头、运走玩具 |
| rainbow、respect、sandy | 末尾新增未出现的喷水器、无载体回应、苹果脚印 | 分别改为已画好的观察画、写有回应的小卡、苹果滚过的浅痕 |
| airport、I'd like、light | 等候与廊桥的时间关系、点餐者主语或无关说明打断情节 | 理顺登机先后、明确本格主语、删掉无关提示，保持同一任务 |
| cold、you're、yuan、won't、will not | 尾格跳出故事讲解语法或词义 | 用安静陪伴、回应队长身份、完成购物、贴新计划或取下出发提醒收尾；解释留在词义连接栏 |
| park：停放、make：制定 | 英文祈使句与完成状态不合；标题承诺未出现的晴天 | 停车后以通道恢复结束；标题改为把野餐步骤排清楚 |
| congratulation、close、search for、the Golden Gate Bridge | 不自然的中英混句或地球仪量词 | 调整成自然中文叙事，英文目标和解释分开；使用准确量词 |
| 同义补充记录 | 相同意思沿用不同动作稿，或同一正文未标明复用 | 9 条显式引用同义核心正文；保留全部1142个记录ID，共1133份不同正文 |

以上问题已经修改作者稿并重新导出。G4、G6 的分稿记录含再次读取后的确认；G5 发现由主作者修订并在最终文件中核对。另清理不必要的“完整圆身”等插入说明，以及只出现一次的形象误加“第一”的序号；重复形象仍保留各自的次序。
