## nose · 鼻子

**原存放位置：** 家中镜子旁

**原稿动作清单：** 摇出一只猫头鹰 → 用大鼻子顶起星星 → 被喷嚏吹进蛋壳 → 接住星星，壳上留下鼻子印

**扩写故事：鼻子上的小星星**

> 鸟巢觉得镜子前太安静，轻轻摇了摇软枝，把睡在里面的猫头鹰摇醒，请它来照镜子。猫头鹰看见自己圆圆的大鼻子，得意地用鼻尖顶起一颗小星星，还想让它在鼻子上站稳。星星刚站住就咯吱咯吱挠起鼻尖，猫头鹰忍不住“阿嚏”一声，把它喷成一条闪亮的小弧线。蛋壳赶紧滚到镜子下，举起小碗接住星星；猫头鹰凑近查看，鼻尖又在圆圆的壳面上印了一个小鼻子，逗得大家笑起来。

**字母顺序：** N(1)=鸟巢 → O(1)=猫头鹰 → S(1)=星星 → E(1)=蛋壳

**词义怎么连起来：** 大鼻子顶住星星，又因为鼻子痒而打喷嚏；镜子里的鼻尖和壳上的鼻印持续提示鼻子这一含义。

**孩子卡住时：** 猫头鹰的鼻子被星星挠得发痒，接下来会发生什么，谁能接住飞出去的星星？

> 苹果闻见野餐篮的香味，骨碌碌滚下桌沿，眼看就要掉进地上的小水洼。第一个南瓜赶紧张开大叶子，像软软的手套一样接住苹果，却把一点泥印留在了果皮上。第二个南瓜接过这颗苹果，用干净的叶尖轻轻擦呀擦，直到红果皮亮得能照出自己的脸。灯笼把光移到切果板上，请桌旁的大人洗净苹果、横切成两半；灯光一照，白果肉里露出星形果核。

> 蛋壳把两半苹果稳稳托在干净的小碟里，说：“带着这份脆甜的苹果，我们可以去野餐啦！”

**扩写故事：足球的渡沟接力**

> 花朵守在学校球架旁，发现足球滚出了草坪，便伸出软软的花茎脚，把它轻轻踢给路边的伙伴。第一只猫头鹰挺起胸口停住足球，看见前面有条小水沟，就沿着岸边把球传给等候的第二只猫头鹰。第二只猫头鹰接住这记传球，看见球场在沟对岸，便把足球稳稳送进沿岸开来的小火车车厢。火车沿着沟边开到一座小码头，车轮“咔嗒”一停，把车厢和停在岸边的小船对齐。

> 小船接到足球后划过窄窄的水沟，靠岸时放低船头，让球滚到等候的苹果脚边。苹果用叶子扶正足球，瞄着草坪尽头踢出一脚，球“呼”地朝球门飞去。第一盏灯笼赶紧点亮左门柱，金色光线在草坪上划出球门左边界，让大家看清足球飞来的方向。第二盏灯笼照亮右门柱和球网，“扑”的一声，足球落进两盏灯笼之间，大家终于完成这次进球。

**字母顺序：** F(1)=花朵 → O(1)=猫头鹰 → O(2)=猫头鹰 → T(1)=火车 → B(1)=小船 → A(1)=苹果 → L(1)=灯笼 → L(2)=灯笼

**词义怎么连起来：** 所有角色围绕同一颗足球接力，最后把足球踢进由两盏灯笼标出的球门。

**孩子卡住时：** 足球到了苹果脚边，怎样才能让远处的队友看清球门在哪里？

## pencil case · 文具盒

**扩写故事：铅笔想回家**

> 南瓜打开文具柜，发现一支铅笔横躺在柜沿，快要滚下去，便伸出叶子抓住笔杆。第一枚蛋壳马上给笔尖套上软帽，免得接下来的搬运把尖尖的笔头碰断。鸟巢把软枝铺成小床，托住整支铅笔，问大家：“它真正的家在哪里？这里不能一直睡呀。”第一块蛋糕搭出一条平缓的小坡，让巢里的铅笔顺着坡面，慢慢滑向柜子深处。

> 冰淇淋举起小棒指路：“看，那只长长的盒子正张着盖子，里面还空着呢！”灯笼探到盒子上方，照出刚好容得下铅笔的细长槽位，大家终于找到了合适的床。第二块蛋糕托住盒底，不让盒子晃动，好让这位细长的客人安全搬进去。苹果用叶尖轻推笔尾，铅笔滑进槽里，既不会乱滚，也不会碰到旁边的尺子。

> 星星看见铅笔躺稳，便轻轻按下文具盒前面的扣片，试试能不能把它扣牢。第二枚蛋壳扶着盒盖慢慢合上，“咔哒”一声扣好了；铅笔终于住进自己的文具盒，可以安心进书包。

**字母顺序：** P(1)=南瓜 → E(1)=蛋壳 → N(1)=鸟巢 → C(1)=蛋糕 → I(1)=冰淇淋 → L(1)=灯笼 → C(2)=蛋糕 → A(1)=苹果 → S(1)=星星 → E(2)=蛋壳

**词义怎么连起来：** 整支铅笔由散放到进入有槽有盖的文具盒，最后合上盒盖，文具盒的收纳用途清楚可见。

**孩子卡住时：** 铅笔找到槽位后，盒子还缺哪一步，才能放进书包而不让铅笔跑出来？

## make · 制作；让
