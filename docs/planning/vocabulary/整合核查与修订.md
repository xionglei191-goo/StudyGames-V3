# 词汇记忆模块整合核查与修订

日期：2026-10-22。状态：策划与数据契约已修订，尚未接入游戏。全局规则以 [GDD](../../../GDD.md) 为入口；本目录继续负责教材词条、来源、逐字母故事与册内教学要求。

本次对照了词汇规范、生成脚本与实际生成数据，并与[主线接入约定](../mainline/词汇记忆模块接入约定.md)、[字母序章](../mainline/alphabet_prologue.json)、[角色制作管线](../art/角色制作与替换管线.md)及现有地图标记对账。下面的“通过”指静态契约和来源保全检查，不表示故事已经人工审定、动画已经制作或儿童学习效果已经验证。

## 一、核查结论与统一决定

| 冲突或缺口 | 原有证据及风险 | 本次统一决定与修订位置 |
|---|---|---|
| 提示等级数量不同 | 词汇故事已有0–5六级，主线早期约定按H0–H4五级表达；相同编号会对应不同帮助量 | 保留H0–H5六级，见规范、`data/integration_contract.json.prompt_contract`和每条`guidance`。主线同步采用同一编号 |
| 提示等级被误当独立作答证据 | H0标签、儿童主动回看或重新打开任务，均不能证明没看到答案；旧H3提示文字还直接包含完整字母链 | H0只表示未预选帮助。按任务模态记录实际线索；首次响应与帮助后响应分开。H3前台文案移除完整答案链，校验链移至`answer_chain_for_evaluator_only`，展示端不得渲染该字段 |
| 每个词都拆字母易被读成“每个词都要拼写过关” | 四类教材要求实际并存，且同拼写可在不同册有不同要求 | `task_permissions`按教材出现项保存。只有听说读写项可安排正式拼写练习；故事、额外练习和拼写成绩均不成为章节通行条件 |
| 主线字段在词汇原数据中不存在 | 原目录使用`occurrences.id`、`unit_numbers`、`lexemes.tokens`、`stories.frames`；主线需要`entry_id`、`source_unit`、`letter_slots`、`story_beats` | 新增可重建适配器`data/mainline_entries.json`；保留原ID、故事和来源，不用新造ID覆盖原目录 |
| 词表来源章节可能被当教学单元 | `sources.chapter_id`指词表章节；一个出现项也可能属于两个单元 | 单元从`unit_numbers`导出并与本册真实章节核对。调用时选择`source_unit.unit_id`，且必须属于条目的`source_unit.unit_ids` |
| 字母序号、标点和补充义项可能重复计数 | 重复字母必须保留不同位置；空格、撇号、连字符和重音不能吞掉；补充义项仍引用原字母链 | 区分`letter_slots`、`reconstruction_tokens`和`boundaries`。编码镜头完整覆盖1至N且各一次；补充镜头只引用已有位置，不再生成额外拼写槽位 |
| 字母地标、故事位置和真实场景混为一谈 | 1096个核心故事有1041种中文位置标签，现有SG节点不能自动容纳这些标签 | 26个序章学习节点用于认识固定形象。词故事保留稳定`storage_slot`，默认由拟开发的固定回忆册承载；`existing_scene_binding=null`，作者场景名不等于已建实景 |
| Egg的词义与E代表形象不一致 | 地标和既有故事使用“蛋壳”，英语锚词为Egg | 明确`canonical_word_zh=鸡蛋`、`representative_label_zh=蛋壳（完整蛋形）`；保留原蛋壳动作及所有ID，制作时不能把Egg教成碎壳 |
| 每词故事被理解为独立3D动画或具名NPC表演 | 最长项25个字母、7镜；多处有猫头鹰、机器人、恐龙模型或地图 | 默认图卡分镜，共用26种代表资源，每镜最多4个活动实例。R机器人不自动等于Robbie，恐龙模型不自动等于Dino；具名角色须显式人物ID和来源审校 |

| 动态环境可能干扰听题和记忆 | 环境时钟、无关NPC动作与记忆分镜可同时运行 | 记忆阅读和听题期间冻结环境表现及非必要NPC动作；玩家控制当前分镜。该行为仍为待实现的产品规则 |

## 二、统一后的教学与证据契约

| 编号 | 名称 | 可提供的支持 |
|---|---|---|
| H0 | 自主 | 当前任务声明的题干，不自动展示故事或答案链 |
| H1 | 位置与意义 | 原位置和当前义项；显示中文义项后不能据此声称无提示词义回忆 |
| H2 | 第一步 | 第一形象与意义物体 |
| H3 | 缺口接续 | 位置框架与部分形象，补缺失位置；不直接显示校验答案 |
| H4 | 逐步搭桥 | 当前动作及下一位候选，定位卡住的字母位置 |
| H5 | 完整示范 | 完整字母、形象、动作、意义及已制作的整词声音 |

求助方向为H0→H5，示范淡出方向为H5→H0。玩家可以直接请求完整示范。主动打开历史故事同样记为线索；退出重进延续同一次调用及帮助日志，不能刷新为无提示尝试。

整词音频在听词选义和听写中可作为预先声明的题干；在“回想目标读音并说出”中则是答案支持。看图拼写时额外播放声音须记录，不能悄悄改写任务模态。看范例抄写单列，不等于撤去范例后的回忆。本项目未提供自动口语评分，不能因跟读、NPC动作或看完故事生成发音分数。

每次调用需保存`task_mode`、目标维度、声明题干、起始答案可见状态、`cue_events`、首次响应、帮助后响应及观察状态。未测维度保留null；未制作或未听检的整词音频不能支持“听力通过”。具体事件字段由[机器契约](data/integration_contract.json)定义。

| 本册要求 | 出现项数 | 允许的教材任务维度 | 正式拼写练习 |
|---|---:|---|---|
| `listen_speak_read_write` | 708 | 意义、听辨、口头表达、文字认读、正字法 | 可以安排，仍不锁主线 |
| `recognition` | 358 | 意义、文字认读 | 不自动安排 |
| `listen_speak_read` | 146 | 意义、听辨、口头表达、文字认读 | 不自动安排 |
| `listen_speak` | 102 | 意义、听辨、口头表达 | 不自动安排 |
| `not_distinguished` | 0 | 原表未区分时先保留意义理解，其余待审 | 不自动安排 |

计数单位是“教材出现项”，不是去重单词。自由额外练习单独记录，不改变本册要求或教材覆盖口径。所有故事均可跳过；同一词在不同册出现时，沿用稳定故事同时服从本次出现项的任务权限。

## 三、身份、单元与字符适配

适配器版本为`vocabulary-mainline-adapter-v1`。`entry_id`直接等于`occurrences.id`；`lexeme_id`沿用词形ID；`sense_id`和`story_id`均指原故事ID，不能把仅用于归并的`sense_key`误当永久义项ID。

条目提供`source_unit={book_id, unit_ids}`。一次主线调用另带所选`source_unit={book_id, unit_id}`，册ID必须相同，单元ID必须属于条目的数组。实际有45个条目同时引用两个单元，所以不可固定取第一个单元。空数组不得推测章节；本批没有空数组。

来源的词表印刷页`page`、文件页`file_page`及词表所列课文页`listed_lesson_page`各自保留。教材来源定位与任务所在章节分别存储。主线选用了某单元的部分词，不等于该单元教材内容已经全覆盖。

所有位置从1开始。`raw_char_index`按NFC规范化后的Unicode字符计数；`letter_index`只计字母。`word_index`与`word_letter_index`在空格或连字符后重置，用于界面定位，不表示词源、音节或构词分析。撇号、缩略点不重置词段，é保留原字形并附重音事件。

`reconstruction_tokens.raw`依次拼接必须严格等于`spelling_display`。只展开`role=encoding`的`story_beats.letter_positions`，结果必须完整等于1至字母总数。`supplemental_beats`标记`role=sense_extension`并使用`ref_letter_positions`，只引用同一条链。跨册补充义项按其`book_ids`匹配，不能给不属于该册的条目自动加义项。

## 五、可制作范围与保留事项

默认渲染为`card_storyboard`。26种固定代表形象可做图卡、简单节点或共用小道具；重复字母只增加带位置编号的实例。每镜最多4个活动实例、每个可见故事分组最多5页，是注意与制作预算草案，仍需设备和儿童试玩验证，不是性能或学习效果保证。

推、接、翻页、进入等动作可用分镜定格、图层切换和简单移动表达。独立骨架、精确手部接触、复杂物理和每词一段电影均非默认要求。小型3D桌面舞台只在原型验证后选用。无法清楚表现的镜头回到待制作状态，保存原字母位置和故事索引，主线仍提供陪同或跳过路径。

当前所有故事的`meaning_reference_review`仍为`pending_human_editor`。1096个故事的语言自然度、准确性、动作可画性、义项区分以及儿童负担，仍要逐项编辑；没有把本次规则统一称作全量内容审定。新的声音、地图、人物参考、分镜资源和实际场景绑定均需各自验收。
