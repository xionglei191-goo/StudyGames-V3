# 字母岛主线策划

策划版本：0.2（2026-10-22）；实施状态更新：2026-10-23，当前工程 v0.10.0-dev。此目录保留主线制作基线，已实现范围见下方当前状态与对应实施记录。

本轮把用户确认的两条暗线放入同一套主线：**先认识26个字母并熟悉全岛，再按课本推进生活事件；新单词按逐个字母调用固定地标形象，编成有顺序、联系词义的记忆故事，系统在需要时逐步帮助。**

全局规则以 [GDD](../../../GDD.md) 为总入口；本目录提供主线细案与来源索引。跨域冲突处理见 [整合核查与修订](整合核查与修订.md)，机器合同见 [integration_contract.json](integration_contract.json)。教材事实仍以原文、页图及各自审校状态为准。

## 已确定的规则

- 序章先建立26字母地标的初步认识和全岛空间印象；教材主线随后展开。
- 地标是稳定字母编码，`nose`按 `N-O-S-E` 联想，不能把这项机制替换成只按词根、词缀或合成词拆解。
- 顺序、重复字母、不发音字母和词内结构都保留；字母名与整词读音分开。
- 看过地图、完成故事、记住图像、拼写、词义、听懂与表达分别记录。
- 提示随时可用，不收取叶币，不以独立答对或连续登录作为剧情门槛。
- 多次出现的同义项优先复用已有记忆故事；跨场景使用和真实间隔回忆另外观察。

## 数据与核验

- [alphabet_prologue.json](alphabet_prologue.json)：26字母序章数据。
- [curriculum_arcs.json](curriculum_arcs.json)：八册单元主线映射。
- [source_snapshot.json](source_snapshot.json)：源文件指纹、册次版本与读取时间。
- [validation_report.json](validation_report.json)：本轮规划文件检查结果。

核验脚本只读取教材、地图清单与策划文件，写入本目录的报告。它不启动Godot、不改变游戏存档、不导出游戏。

```powershell
python docs/planning/mainline/validate_mainline.py
```

结构核验不能证明故事有趣、课堂目标完整或学习有效。内容编辑和儿童试玩仍是独立步骤。

## 当前工程与协作边界

初稿读取时项目源码为 v0.4.0，包含当时正在推进的基础校园活动；该静态快照继续保留，上方历史表中的待办不代表今天仍全部未实现。

当前 v0.10.0-dev 已沿用五街区 26 字母体验、三上 U1–U3 连续生活事件与词故事浏览，并接入首站发现卡、五张街区旅行页、U3 欢迎桌/四幕聚会与八位朋友的事实回应。发现作品和桌面可暂存、确认、取消、回家查看与继续修改；只有实际看完聚会才留下相聚回忆。入口与范围见[游玩说明](../../Blender地图版游玩说明.md)和[生活纪念记录](../../verification/life-keepsakes/README.md)。这些生活结果不新增叶币，也不推导英语掌握。

八册 81 单元目录和事件映射不等于完整生活剧情全部可玩；真实间隔复现调度与统一家长观察页尚未实现。既有课程内容、主线和可选词故事分别以 `game/data/curriculum.json`、`game/data/learning/`、当前代码及各自验收记录为准，不再仅凭旧课程文件判断全部旅程范围。

词汇策划成果位于 [vocabulary](../vocabulary/README.md)，已完成本轮全量内容生成与结构核验；1314册内记录关联1073准确拼写和1096核心义项故事，不等于1314个不同单词或已经教学审校。主线通过适配索引读取真实ID，规定何时调用、如何返回与怎样记录，不重复维护词表。

旧世界设计与历史方案保留。本版主线规则已吸收本轮用户决定；后续实现应按具体章节细案推进，并为每次修改保留范围与验证证据。
