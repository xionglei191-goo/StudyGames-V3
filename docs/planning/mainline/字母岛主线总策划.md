# 字母岛主线总策划

版本：0.1，2026-10-22。状态：可讨论的制作策划草案；新增章节、教材任务和字母记忆系统尚未据此实现。

## 1. 已确定的设计基础

以下来自本轮用户决定，后续细案应保持一致。

1. 游戏围绕课本知识点推进。先认识26个英语字母并探索全岛，再按教材内容安排情境复现。
2. A—Z既是熟悉地图的线索，也是后续拼写记忆的固定图像编码。单词按每个字母拆解，例如 `nose → n-o-s-e → 鸟巢—猫头鹰—星星—蛋壳`，再按顺序组成联系词义的记忆故事。
3. 孩子暂时想不出画面时，系统应提供示范、选择、动作提示和分步共同编故事；帮助不作为失败或能力评价。
4. 地标映射和公共空间位置稳定；美术采用当前温和、自然的方向。
5. 单词内容在独立会话中整理现有三至六年级八册教材。此目录负责整体剧情、章节推进、系统规则与内容接入，不重复维护逐词故事库。

本版提出但仍需试玩调整的内容包括：故事名称、NPC分工、每次游玩长度、奖励种类和数量、章节活动安排。已做选择不等于已经验证儿童使用效果。

## 2. 产品体验

孩子是字母岛的新居民和新同学。在这里拥有自己的家，认识熟悉的邻居，参与学校与街区的共同活动，并逐渐能够用英语处理越来越复杂的生活事情。

玩家看见的主线是“我和朋友让小岛生活越来越丰富”；系统持续维护两条学习线：教材知识的出现与复现、字母地标记忆故事的建立与提取。

| 层次 | 玩家体验 | 策划责任 |
|---|---|---|
| 生活故事 | 帮朋友、制作东西、参加活动、布置家园 | 每段有明确愿望、可操作过程和可见结果 |
| 教材进程 | 听懂人物、选择回应、执行需求、介绍成果 | 按实际教材单元与先修内容安排，不凭场景主题提前算覆盖 |
| 记忆过程 | 想起地标、编小故事、补全画面、再次想起来 | 保留完整字母顺序，关联词义和全词读音，逐步撤去帮助 |

首批交互设计以三年级英语初学者为起点。八册提供后续内容的总体路线，不要求一个孩子先完成低年级全部任务才能查看自己正在学习的册次。可由家长选择起点册次；26字母地标序章仍提供适合初次进入世界的导览。册次跳转的补充教学必须显式标注，不能假定孩子已经会前册内容。

制作验证先使用现有Windows客户端和Godot工程。其他平台的触控、性能与发布方案另立验收范围。

## 3. 全局流程

`建立自己的家 → 字母探索序章（五次街区旅程）→ 教材单元故事 → 回到日常生活复现 → 册末共同成果 → 下一册`

家园开场只教基本移动、交互、帮助和退出，不提前引入大量英语。序章按五街区完成26地标初访，每处有大小写配对、字母名称和代表形象的体验。访问与体验可在帮助下完成；是否能独立辨认字母另行记录。

教材主线以实际书本顺序为准。A—Z决定图像编码和世界识别，不决定所有词汇的教学顺序。蛋糕坊可以出现milk、egg等食材；词的字母图像仍来自全岛固定地标。

每个单元建议有三个可分开完成的段落：

1. **发生一件事。** 角色提出具体愿望，示范必要表达和操作。先让孩子看懂要做什么。
2. **共同完成。** 孩子在情境中使用内容，遇到需要记忆的词时调用词汇故事模块。主线中的操作、语言与记忆活动之间有自然承接。
3. **留下结果并再次遇见。** 人物关系、物件或公共布置产生可见变化；后续事件换人物、换对象再调用同一知识。

上述段落是内容组织单位，时长需试玩决定。建议以一次约10–15分钟的可暂停活动为起点，不将计时或连续登录作为通关条件。现实几天未玩，故事保持可继续状态。

## 4. 长期叙事骨架

暂定贯穿道具为《小岛生活册》。序章收集字母地标页；教材章节留下生活照片、作品、人物留言与事件记录。照片和留言是可见成果，学习表现保存在独立记录中，避免把装饰收集量误当英语掌握度。

| 册次 | 本册故事提议 | 主要生活变化 | 与教材的对应方式 |
|---|---|---|---|
| 三上 | 新居民的第一学期 | 认识朋友与家人、拥有自己的物品、完成第一次生日活动 | 问候、姓名、年龄、家庭、所属、身体、颜色、识物、喜好、生日 |
| 三下 | 一起安排小岛生活 | 能约定时间、根据天气准备活动、参加儿童节与出行活动 | 问候状态、时间、天气、衣着、数量、位置存在、卫生、节日、交通、职业 |
| 四上 | 我们的学校和邻里 | 从被带领的新同学变成能够介绍学校、家庭和活动的人 | 校园、作息、食物、动物、能力、识物、物品归属、规则、家居与职业 |
| 四下 | 我们来组织一次活动 | 参与班级分工、活动安排、公共标识和节日准备 | 位置、课程、星期、计分、职业帮助、季节、观察、正在做的事、端午与标识 |
| 五上 | 我的选择与责任 | 能描述、提出请求、照料、选择、承担家务并处理相处问题 | 以当前2022源教材的10个单元为准，不套用旧版五上提纲 |
| 五下 | 小岛小小向导 | 阅读研究、完成制作、邀请祝福、介绍周边并回顾经历 | 以当前三年级起点版12个单元为准 |
| 六上 | 一起照顾我们的社区 | 分享经历、安排活动、帮助他人、节约资源并作出比较 | 假期、作息、节日、预测天气、准备物品、提供帮助、节水、比较、身体状态与团聚 |
| 六下 | 把小岛故事讲给别人听 | 共同出行、讲故事、照顾自己与环境、展示愿望和旅行发现 | 以当前三年级起点版9个单元为准 |

这张表是叙事提议。具体教材标题、页面、来源版本及81个单元事件见 [教材章节与主线事件](教材章节与主线事件.md) 和 [结构化章节表](curriculum_arcs.json)。单元标题映射不等于已经逐条审校完整课文、语法、听力和活动覆盖。

册末成果复用本册角色和事件：例如生活册展示、校园开放日或节日合照。不能为赶到一个大型结尾而要求孩子重复刷同一任务。下册开启由故事完成和补充教学决定，独立掌握记录继续积累。

## 5. 角色和空间分工

| 角色或空间 | 持续职责 | 设计要求 |
|---|---|---|
| 玩家家园 | 安全起点、整理成果、装饰、接待朋友、回想故事 | 无任务也可停留；回家不等于进入考试界面 |
| 熊叔 | 帮新居民熟悉生活、支持序章、提供提示 | 保留现有角色；不包办所有教学与奖励 |
| 班级老师槽 `current_teacher_slot` | 引入教材活动、示范表达、组织成果；候选映射 `textbook_miss_li` | 依美术角色槽审校后绑定；现有teacher外形不证明教材身份，不另造老师ID |
| Lingling、Peter、Anne、Mingming、Dongdong、Tim与Dino | 按教材来源和章节需要作为稳定同伴或故事角色 | 直接使用美术人物表的稳定ID；出场、动作和性格提案要与教材事实分开 |
| 各地标主人 | 提供该场所的生活活动和专业道具 | 活动产生物品、作品、故事或关系变化 |
| 家庭成员 | 家庭、日常照料、物品归属和回家交流情境 | 作为游戏角色设定，不要求录入真实家庭信息 |
| 学校及七处功能场所 | 教材活动、社团体验与同伴交流 | 体育、美术、音乐等动作参与主线，但不擅自声称其等同某项英语能力 |

教材人物身份与外形依据 [教材人物来源核对](../art/教材人物来源核对.md) 和 `textbook_characters.json`；首批覆盖该表全部已确认角色，未具名角色使用既有角色槽，名字命中和具名道具不冒充NPC。熊叔、兔兔保留生活与导览职责。81单元的 `cast_binding` 只列来源候选，配戏仍待页图、语境与章节审校；首批资产覆盖不等于首章全员到场，也不表示模型已制作。

每个场所优先承担一两个稳定的核心动作，再在章节里变换需求。制作、收集、观察、排列、选择、递交、装饰等交互应尽量复用。当前35个场景不需要各自拥有一套独立经营系统。

## 6. 词汇记忆怎样嵌入主线

触发来自教材任务：孩子第一次需要理解某词，或愿意为已经学过的词建立记忆故事。系统先呈现物件、动作或明确情境以及全词读音，再调用逐字母地标图像。故事中的字母形象顺序必须与准确拼写一致。

本版只定义调用过程，单词和故事内容由 [词汇策划目录](../vocabulary/) 提供。交接规则见 [词汇记忆模块接入约定](词汇记忆模块接入约定.md)。

| 孩子此刻的状态 | 主线中的帮助 |
|---|---|
| 不知道这个词指什么 | 回到实物、动作或明确语境，先解释词义并播放全词读音 |
| 认识字母但想不出画面 | 依序显示地标代表形象，让孩子从少量动作或关系中选择 |
| 不认识某个字母图像 | 提供已访问地标的回忆卡，缺少初识经验时补一次导览 |
| 有画面但顺序混乱 | 按字母位置分镜，显示重复出现的序号；只提示出错或遗漏的位置 |
| 喜欢故事但拼不出词 | 从画面提取对应字母，再隐藏形象回想；不把复述故事计作拼写成功 |
| 拼对但不懂词义或读音 | 回到新的实物辨认、听音选择或生活请求，分别记录 |
| 不想编故事 | 可使用系统示范并继续剧情；以后可自愿替换为自己的故事 |

全局帮助采用 H0自主、H1位置与意义、H2第一步、H3缺口接续、H4逐步搭桥、H5完整示范六级，与词库 `prompt_ladder[0..5]` 一致。等级记录帮助深度，不是能力标签；同次尝试中可增加帮助，最高已用等级与答案揭示痕迹不可撤销。H0入口打开历史故事后也必须升级帮助，不能仍算独立。

主线不要求每遇到一次词都重新编故事。已建立的词条保持稳定；同义项跨单元出现时复用原故事，改变使用情境。不同义项、近似词、同一单词的不同大小写要求交由词汇策划显式区分。

完整单词故事拥有固定存放位置或稳定回忆卡入口；A—Z地标作为编码来源，公共建筑不会因单词变化而搬迁。一个单词不强制让孩子依次跑遍它的全部字母地标。

## 7. 主线完成、学习表现与奖励

主线允许在示范和帮助下完成。剧情完成表示玩家参与并完成了事件；独立辨认字母、独立拼写、理解词义、听懂请求和主动表达是分别记录的学习证据。

奖励优先展示事件产生的结果，例如种下的植物、完成的作品、一起拍的照片、朋友的留言或可选装饰。基础叶币作为可选购买资源，不能成为英语提示的费用。重复任务和使用帮助不扣除已得到的成果。

每个故事步骤需要可靠的退出与恢复点：对话结束、物品交付、故事分镜保存、奖励发放。恢复时重述当前愿望，提供回到现场或继续下一步的入口。奖励应只发一次；重复观看故事与自由练习不会刷出无限奖励。

游戏里的睡觉只推进游戏日。复习间隔按真实时间记录；错过复习窗口时在下次合适事件中补上。不得通过反复睡觉伪造“隔天回忆”记录。

详细规则见 [主线状态与成长规则](主线状态与成长规则.md)。

## 8. 首个可制作范围

第一轮制作应包含完整26字母序章，以及三上Unit 1的完整事件闭环，并为Unit 2–3的连续事件留下实际衔接。源素材和其他场所保留。序章的26处活动使用少量通用交互组合，控制制作量。

首章细案见 [首章详细流程](首章详细流程.md)。本轮策划同时给出三上其余单元和后续七册的事件提纲，逐词内容由独立会话并行完成。

词故事组件可先独立试验nose、重复字母词和长词，但这些组件试验不改变教材顺序。例如nose的主线教学应放在真实教材对应的身体主题内容中，不能因为它是演示样例就把它算入开场问候单元。

## 9. 制作阶段与判定

| 阶段 | 可审阅成果 | 进入下一阶段前需要的证据 |
|---|---|---|
| 策划对齐 | 本总纲、26字母序章、81单元事件表、首章细案、词汇内容接口 | 用户决定与内容表不冲突；来源版本、页面、已实现范围清楚 |
| 交互试作 | 选一个街区片段和一个词故事组件，用现有素材试作 | 新玩家能找到目标、看懂反馈；帮助可随时使用；字母顺序可完整还原 |
| 首章制作 | 完整序章与三上U1事件、保存继续、奖励与后续伏笔 | 玩家能完成闭环；学习记录与剧情完成分开；重复进入不重复领奖 |
| 连续内容 | U2–U3事件，之后按册逐章推进 | 旧知识能在新情境调用；没有只换背景重复同一选项位置的问题 |
| 教材扩展 | 逐册内容审校、音频与动画、完整回访编排 | 每个知识点有明确覆盖证据；词表、句型、课文功能分别核对 |

试玩应观察实际行为：是否知道下一步要做什么、是否主动尝试互动、哪一层提示能帮助继续、能否从图像还原字母顺序、在新情境中是否仍理解目标内容。短期试玩用于改进设计，不直接形成“提高记忆力”或“已熟练掌握教材”的结论。

## 10. 当前基线与边界

规划期间工作区源码版本已从此前交付的v0.3.2更新为v0.4.0，基础校园活动和生活记录正在其他工作中推进。此策划以读取时的源码快照为依据，记录在 [source_snapshot.json](source_snapshot.json)。本会话不据此宣称已完成v0.4.0运行验收。

现有教材运行内容仍应以 `game/data/curriculum.json` 的真实覆盖字段为准。规划中的81单元主线、全词记忆故事、分级想象引导和完整跨情境回访不等同于已发布功能。

本次仅新增策划文件与规划数据核验，不修改游戏代码、资产、课程包、存档、启动脚本或发布成品。旧世界设计和旧方案保留为历史材料；主线教学顺序和字母记忆规则以本版已确定决定为准。
