# 主线与词汇记忆模块接入约定

版本：0.2，2026-10-22。**此文是已对齐数据的制作合同，尚未成为运行API。** 全局规则见 [GDD](../../../GDD.md)，主线状态见 [integration_contract.json](integration_contract.json)。

## 1. 内容事实与分工

词汇策划已生成 **1314册内记录、1073准确拼写、1096核心义项故事**。其中45条册内记录关联两个教学单元，因此81单元索引共有1359条关联；不能把关联数当成新增单词。生成与结构校验完成不代表人工教学审校、读音听检、模型动画或游戏接入完成。

主线负责教材路线、生活情境、人物目的、步骤恢复与章节结果；词汇侧负责来源、准确拼写、义项、完整字母链、分镜和分层提示。主线不复制故事正文，也不临时改义或另建一份词表。

权威数据：

- [原始词库catalog](../vocabulary/data/catalog.json)：`occurrences / lexemes / stories / sources`。
- [主线适配索引](../vocabulary/data/mainline_entries.json)：`entries`及81条`unit_index`。
- [词汇接入合同](../vocabulary/data/integration_contract.json)：帮助、任务权限、字形、素材和存放规则。
- [主线单元索引](curriculum_arcs.json)：每单元保存实际`entry_ids`候选和当前内容版本。

## 2. 真实ID与字段映射

| 主线适配字段 | 当前来源与语义 |
|---|---|
| `entry_id` | `occurrences.id`；一条册内拼写/义项出现记录，不是全书共用的lexeme ID |
| `lexeme_id` | `occurrences.lexeme_id → lexemes.id`；同一准确拼写身份 |
| `sense_id / story_id` | `occurrences.story_id → stories.id`；核心义项故事身份 |
| `source_unit.book_id / unit_ids[]` | 真实书ID与经过教材章节验证的`unit-N`列表 |
| `spelling_display / meaning_zh / requirement` | 本册准确字形、义项和教学要求，直接取该occurrence |
| `source_ids` | 指向`catalog.sources`；来源页、区域和审核状态不由主线重写 |
| `letter_slots / boundaries / reconstruction_tokens` | 由准确字形和lexeme字母链生成；可逐字符还原原文 |
| `story_beats` | `stories.frames`转为`role=encoding`，每个字母位置恰好一次 |
| `supplemental_beats` | 义项补充只引用已有位置，不能重复占用拼写槽位 |
| `memory_home` | `storage_slot / story_page / root_location_label`的稳定索引；当前`existing_scene_binding=null` |
| `guidance` | H0—H5逐条实际提示；界面选择不决定能力等级 |
| `audio / review_status` | 读音候选、待制作状态、来源审校、编辑和儿童验证分别标记 |

主线的`source_unit_key=book_id/unit_id`只是本域派生标签，原词库没有这个字段。调用必须满足：`call.source_unit.book_id == entry.source_unit.book_id`且`call.source_unit.unit_id in entry.source_unit.unit_ids`。空归属不自动编章；单元候选列表不等于该章必须安排全部词，更不等于该单元所有语言目标已经覆盖。

当前内容版本为`vocabulary-75cc8eb5b90ed004`，编码版本为`codebook-7976c505db8c0ea5`。实现时从条目读取版本；修订必须保留旧记录的内容语义，不能只改显示内容却继续使用旧记录解释掌握。

## 3. 字母、字形与存放位置

所有位置从1开始，原始字符索引按NFC标准化Unicode字符计数。严格按显示拼写保留大小写、空格、连字符、撇号、标点与重音；`reconstruction_tokens.raw`拼接必须等于`spelling_display`。空格与连字符后重启`word_index / word_letter_index`，撇号不重启；这是书写定位，不宣称音节或词源切分。

重复字母各占独立位置，例如book中的两个O使用同一猫头鹰资源的两个实例。不发音字母照常编码；字母名和整词读音分别教学，不能把地标词音拼接成整词读音。故事编码只展开：

`concat(beat.letter_positions for beat in story_beats if beat.role == "encoding") == [1, ..., letter_count]`

补充镜头只使用`ref_letter_positions`引用已有位置。分镜直接取词库，不在主线按另一个固定长度重切；当前编码镜头为1—4个位置。长链可静态展开，活动实例数量遵守词汇素材合同，不为每条故事制作独立电影或骨架。

A—Z代表图与公共地标稳定不动；完整故事保存在固定回忆册页。`memory_home`的“家中镜子旁”等是作者存放标签，目前不是已存在的SG节点。已有SG点是进入回忆的入口，不自动扩建1096个世界节点。

E沿用Egg地标：`canonical_word_zh=鸡蛋`，`representative_label_zh=蛋壳（完整蛋形）`。故事旧字段`anchor_zh=蛋壳`是显式别名，不换资源、不换ID，也不把egg词义教成碎壳。

## 4. 教学要求与任务权限

| `requirement` | 本册允许作为课程目标的维度 | 拼写边界 |
|---|---|---|
| `listen_speak_read_write` | 义、听、说、认读、书写 | 可安排审校后的书写练习；仍不锁剧情 |
| `listen_speak_read` | 义、听、说、认读 | 不自动升级为四会或强制书写 |
| `listen_speak` | 义、听、说 | 文字与故事可选，不自动升级认读或拼写验收 |
| `recognition` | 义、认读 | 不自动安排拼写测验，故事与字母链仅作可选支持 |

例如三上Unit 1的dinosaur是`recognition`，有字母链也不能改成强制拼写题。孩子自愿拓展练习必须标为额外练习。句型和完整对话由主线情境承担，不能用单词故事覆盖整段交际目标。

先用准确实物、动作或情境教清词义，有已听检且可用的完整词音时再开展听音任务。没有合格音频时保持内容待制作或使用明确的静音图示教学，不生成听力通过或自动发音分数。

## 5. 六级帮助与独立证据

| 等级 | 具体内容 | 必须记录 |
|---|---|---|
| H0 自主 | 不先显示故事或字母链，先按当前任务回应；帮助随时可用 | 题干、可见目标、首次回应；H0本身不等于独立 |
| H1 位置与意义 | 提醒稳定存放位置、当前义项和回忆入口 | 实际呈现的词义或场景线索 |
| H2 第一步 | 提示第一个形象、字母或动作 | 已揭示的位置与受影响维度 |
| H3 缺口接续 | 保留序号与重复实例，遮住一格让孩子补回 | 可见完整/部分链与补回结果 |
| H4 逐步搭桥 | 只展开当前步骤，提供下一形象或动作候选 | 每次展示、选择与具体答案线索 |
| H5 完整示范 | 按词库分镜展示完整串，回到词义 | 示范、重播及未亲自作答的事实 |

等级可随时提高，同一尝试的`max_help_level`、答案揭示与首次错误不能因关闭面板、重进或选择较低级别而抹去。H0主动打开历史故事也要升级并记录实际线索。可以在新的情境启动新尝试，但不能删除旧帮助记录。

每次尝试记录`invocation_id / attempt_id / task_mode / target_dimension / declared_stimulus / answer_visible_at_start / cue_events / first_response / later_response / observation_status`。每次线索保存时间、请求者、等级、种类、内容引用、揭示字母位置与受影响维度。

无提示尝试与首次独立正确分开：`unassisted_attempt_requires`要求真实响应、无相关答案线索和明确的任务条件，允许正确或错误；`independent_success_requires`在此基础上要求首次答案正确。无提示错误保留实际响应与“未正确”，不能改成未尝试；同次错误后重试保留首次/随后回应与实际提示，不改写为首次独立正确。既有历史记录不因此重写。

独立与辅助按任务模态判断。例如听写的完整词音是题干；主动口语回忆中播放目标词音属于答案帮助；看词照抄与撤去范例后的拼写回忆是不同任务。未揭示答案的问题重播可只记录重播次数，不自动升级。看图故事完成、H0入口或主动求助均不能自动生成独立正确。

## 6. 调用、返回与恢复

调用以真实条目为例，nose属于三上Unit 6，不是开场Unit 1：

```json
{
  "schema_version": "mainline-integration-v1",
  "invocation_id": "example-nose-session-001",
  "attempt_id": "example-nose-attempt-001",
  "entry_id": "occ-89a38b8a39c8",
  "lexeme_id": "lex-d77e22123e64",
  "sense_id": "story-d7e8439b06b1",
  "content_revision": "vocabulary-75cc8eb5b90ed004",
  "codebook_revision": "codebook-7976c505db8c0ea5",
  "source_unit": {"book_id": "xiangshao-g3-1", "unit_id": "unit-6"},
  "story_step_id": "example.body_activity",
  "purpose": "supported_spelling_practice",
  "requested_help_level": 5,
  "resume_state": {"seen_beats": [], "current_beat": 1, "max_help_level": 0, "support_used": [], "answer_revealed": false, "attempts": [], "cue_events": [], "task_mode": "picture_to_spelling", "target_dimension": "orthography", "declared_stimulus": "reviewed_nose_meaning_picture", "answer_visible_at_start": false},
  "return_to": "example.body_activity.resume"
}
```

示例会话/步骤标识仅展示格式，不是生产记录。此例从实义图拼写任务请求H5，尚未展示答案，所以当前最高已用帮助仍为0；真正展示时才追加线索事件并升至H5，后续回应为有帮助练习。条目自身携带完整字形、镜头、教学要求与审校状态，调用不复制或临时改写它们。实际调用需通过内容/音频/任务模式审核；当前nose音频仍是待制作或适配候选。

返回`session_result`区分`exposure_completed / paused / deferred / content_unavailable`，另带`invocation_id / attempt_id / entry_id / content_revision / codebook_revision / story_choice / max_help_level / support_used / cue_events / actual_observations / interrupted_at_beat`。学习维度如`ordered_images_recalled / spelling_recalled / meaning_understood / listening_understood / spoken_expression`只保存真实观察；未测为`null`，不能因看完示范填正确或补分。

中断保留同一调用ID、已看镜头、完整字母位置、帮助和已有回应，返回原生活步骤。不想编故事可选示范、以后再练或伙伴陪同，章节继续且奖励相同。故事修改另存版本和孩子选择，不静默覆盖旧回忆入口。

## 7. 接入核查

检查实际ID和版本、书/单元成员关系、教学要求、字形重建、每字母一次编码、固定26图像、逻辑存放位置、分级线索记录、未测维度与奖励幂等。来源页图核对、教学编辑、读音听检、资产制作、运行验收与儿童使用各自留证；静态通过只证明结构及引用符合本合同。
