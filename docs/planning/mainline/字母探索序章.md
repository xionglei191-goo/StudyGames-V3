# 字母探索序章

状态：**完整策划草案，新增序章机制尚未实现**。日期：2026 年 10 月 22 日。配套结构化配置：[alphabet_prologue.json](alphabet_prologue.json)。

本稿让孩子分几次认识二十六个固定地标、大小写和字母名，为之后用熟悉图像辅助词记忆编码打基础。孩子先形成“我见过这里，它有这样的形象和字母伙伴”的初印象，再进入教材主线；不以二十六个字母或锚词全部独立掌握作为通行条件。

核对时项目版本为 `0.4.0`。当前已有场景、探索和部分基础活动；本稿新增的序章编排、字卡、分离音轨、轻动作配置、回忆册、进度规则和地图捷径均为计划内容。本次只写这份文档及配套 JSON，不修改运行内容、公共几何、入口坐标或现有存档。

## 1. 固定边界与结束条件

五街区和二十六个主锚词沿用现有世界。A—Z 每字母一个主锚词，I 固定为 **Ice cream**、Y 固定为 **Yarn**、Q 固定为 **Quilt**、V 固定为 **Volcano**、X 固定为 **Xylophone**。独立家园 `home` 与校园 `school` 不占字母编号；“山丘学园”是 Q—U 的街区名，不等于必须把五座地标搬进校园。

序章的硬结束条件只有：**二十六处均已实际到访，并完成相应的有支持体验**。每个字母的记录拆开：

- **到访 visited**：进入对应 `landmark_<字母>` 场景并看到环境。地图缩略图、菜单勾选不能代替到访。
- **体验 experienced**：代表图像已呈现、一个短动作的反馈已看见、大小写字卡已呈现、字母名支持已提供。孩子自己做、提示后做、陪同做或看完整示范均可。
- **可选回想证据**：大小写关联、字母名回想、地标图像回想分开记录，可标未尝试、独立回应、支持后回应、看示范或未回应。它们不参与序章通关判断。

示范也必须在该地标场景中呈现对应内容，不能用一个“全部会了”按钮勾满二十六处。一次操作独立完成只说明操作无需帮助，不自动写入英语掌握标记。语音未播放就记“未播放”；静音、不会跟读、没有麦克风或跳过回想都可以继续。

实体门与英语表现分开：`school`、`classroom` 和现有自由探索入口保持可访问。二十六处完整覆盖决定本策划的**主线阶段切换**，不是用考试锁住学校或删除已有课程。也不要求一口气按 A—Z 走完、跑遍每场景五个记忆点、集齐货币或装饰。

每段都可拆成 2—3 个字母的小批次，做完一站即保存，随时退出。回来恢复当前站未完成步骤，已提交字母不重做、不扣奖励。孩子先逛到其他街区时，同样按字母去重记录；推荐路线不构成强制顺序。

计划中的跑图控制只使用现有场景和节点：

- **慢慢走**：从 `home/SG_EXIT` 回到 `village`，沿现有道路到 `SG_DOOR_A` 等主岛入口，进入对应地标。
- **陪同抵达**：家园选定本次小批次后，可让向导陪同到第一站；抵达落点引用该场景已有 `SG_SPAWN`。这是待实现的地图捷径，不增建交通建筑、不写新坐标。
- **熟悉地点回访**：已访问街区或场所可从地图快速返回，落点仍引用现有 `SG_SPAWN`；入口资格与英语正确率无关。
- **回家集合**：任意一站结束或中止后可回到 `home/SG_SPAWN`，保留已完成记录。下一批从家园继续，不要求为了复习横穿全岛。

## 3. 每站共用的短体验

一站只选下文指定的一个已有 `SG_MEMORY_01`—`SG_MEMORY_05` 位置，不要求把五点都做成序章任务。流程为：**抵达 → 看清代表形象 → 一个具体动作或示范 → 大小写与字母名呈现 → 收下发现页 → 可选回想**。

动作由六类模块配置：观察取景、二选一、单图拖放、轻点反馈、短路径跟随、图像盖章。拖放与路径跟随提供点选或分步按钮替代。动作内容和反馈随地标变化，不开发二十六套必须通关的完整小游戏；敲鼓不必演奏整曲、接车厢不必驾驶火车、装饰蛋糕不必完成烘焙经营。

**字形与声音的呈现约定：**

- 大写字形来自 `village` 上已融入建筑的构件；短动作在独立地标场景里发生。室内看不到原建筑字形时，显示同一个主岛模型的取景图并高亮原构件，不新刻字母、不移动建筑。下列建筑部位是既有世界设计的观察目标，实现时需用真实取景核对可辨性。
- 小写在同一张字卡上与大写并排。选用易辨印刷字体，I/l/i、b/d/p/q 和 a/g 在实现前按所选教材审校，整段序章保持一致。无需描写或打字才算体验完成。
- 两个按钮明确区分“听字母名 A”和“听地标名 Apple”。字母名音轨与整词音轨独立，不自动重叠；不把词首音或字母名称当作自然拼读教学。
- Q、V、X 的难词仅作图像命名支持，可始终显示图片、中文和可重播词音，不要求独立说词、拼词或知道专门学科知识。Xylophone 的读音不能拿来代替 X 的字母名或固定字母音示例。
- 代表图像来自现有地标外观或室内对应物件。观察卡、图像图层和反馈为待制作内容，不表示当前资产已包含完整教学演示。

提示顺序为“再看/重播 → 指出部位或目标 → 陪同分步 → 完整示范”。孩子可以直接请求最后一级。发现页和街区图章按到访与体验发放；有帮助完成也照常记录，不贴“差生”或失败标签。

## 9. 进度、回想与失败恢复

序章使用独立的计划命名空间 `alphabet_prologue`，不覆盖现有课程、地图或家园记录。每字母至少保存：到访、代表图像呈现、动作反馈、大小写呈现、字母名支持是否提供、两类音轨是否播放、体验完成方式和最后完成步骤。这里只定义策划数据，不规定当前 Godot 存档必须已经具有这些字段。

例如孩子在 Q 看完向导示范、看过 Qq 和拼布被，字母名支持已提供，即可记 `visited=true`、`experienced=true`、`completion_mode=demonstration_viewed`。即使没有独立配对、没有播放 Quilt 词音，也可继续；掌握状态不能因此被设为“会了”。

回家时最多邀请回想当天自选的一两张图，可先不给字母高亮，再逐级揭示街区、代表形象、大小写和完整示范。另记回想是否独立、用了哪种提示；没有回应和选择跳过均不消除旅行页。不把反应时间、拖放精度、口音或路线熟练度解释为英语水平。

未理解时回到当前一步，向导给中文和动作示范；误操作不扣币、不回退街区。保存后退出则从下一未完成字母继续，中途退出恢复当前站的步骤。实现验收要分别试静音、无麦克风、只用点击替代拖放、跨街区先逛、未做回想、示范完成和中途退出。

## 11. 从序章进入教材主线

二十六处到访与体验记录齐全时，序章完成标记成立。下一次家园集合提供简短邀请：“我们已经拜访过二十六位字母伙伴。带上旅行册，去学校认识教材故事里的新朋友；想不起来，仍然可以回来看看。”收册仪式可略过，不另加考试。

后续课可以在需要时调出少量已经建立联系的代表图像，再进入词义、听懂、情境使用和回想。不是每个词都需要记忆故事，也不按首字母把同类课程硬塞进固定建筑。家园、校园和二十六个地标继续自由回访。

## 12. 实现前与试玩验收

本稿的静态检查应确认：

1. A—Z 恰好二十六条，无漏重；锚词与现有清单完全一致，五街区分组不变。
2. 所有场景、主岛入口与选用记忆点存在；没有新增坐标或公共几何改动。
3. 每字母都有一个具体动作、代表形象、大小写/独立字母名支持、可选回想和阶段记录；六种模块足以表达，不衍生成二十六个完整小游戏门槛。
4. 完成公式要求二十六处实际到访与体验，允许帮助、陪同和完整示范；不强制 independent、不把进度当掌握。
5. Q/V/X 不要求难词独立掌握；X 的字母名与 Xylophone 词音分开。N—O—S—E 使用四张代表图，不移动公共建筑。
6. 暂停恢复、静音、点选替代和跨街区先逛可按同一规则处理，已有入口不被考试锁住。

后续实现后再做实际场景与儿童试玩验收，重点看：能否认出图像与原地点、字形取景是否清楚、帮助是否容易找到、路程是否过长、一次曝光是否太多，以及是否愿意回访。记录行走/加载和操作时间，分别调整；不能由策划时长或少量试玩声称学习效果已验证。本次没有运行 Godot、渲染或修改源资产。
