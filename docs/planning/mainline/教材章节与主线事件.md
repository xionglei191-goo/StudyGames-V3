## 1. 阅读方式与事实边界

本稿承接“完整 A–Z 地图探索在前、教材主线在后”的顺序。玩家先学会在小岛移动、互动和回听，随后通过欢迎会、校园生活、社区协作、观察研究和毕业展使用英语。这里的岛上人物、冲突、行动与世界变化是原创事件设计，教材事实只来自下列实际文件。

- 目录源：`D:/Project/Englishbook/public/library.json`。
- 单元源：该目录指向的 8 份 `public/books/*.json`，用实际 `chapters` 中的 `unit-*` 逐项建立 81 个关联。
- 机器可读主线：[curriculum_arcs.json](curriculum_arcs.json)。逐页证据与排除章节：[curriculum_arcs.source-audit.json](curriculum_arcs.source-audit.json)。
- `source_unit_key = book_id/unit_id` 仅为主线派生标签。词库真实关联采用 `mainline_entries.json` 的 `source_unit.book_id` 与 `unit_id in source_unit.unit_ids`；本稿每单元列稳定 `entry_ids` 候选，不复制故事，也不把候选条目全部变成强制任务。
- 人物依据美术来源表；各单元 `cast_binding.source_character_candidates` 是页内出现的身份候选，`event_cast_review_pending` 不能解释为已经审校的配戏。

文件页码使用 manifest 的 `pages[].id`，从 1 开始；印刷页码优先使用对应章节的 `printedStart/printedEnd`，缺失字段逐页查 `pages[].printedPage`。每单元 JSON 保留了完整逐页对应，不使用统一减 7 等偏移推算。

三上 10 条开页 Objectives 区域中，6 条的源字段为 `source=ai-repaired`，4 条为 `source=pdf`（Unit 3、4、5、9）；本次读取到的这些目标区域均为 `reviewed=false`。`sourceVerified=true` 只是来源自己的声明，不等于本次独立页图审校。本稿读到的是这些区域文本，不能据此声称整册教材已经经过人工核对。

## 4. 序章与进度规则

### 先认识完整 A–Z 小岛

序章位于全部 81 个教材事件之前，使用 `village` 和 `landmark_A` 至 `landmark_Z`。玩家可以分次走访全部字母地点，观察大小写配对和地标形象，学习互动、返回地图、回家、到校与回听。初见记录可在图示、读音或引导支持下取得，不要求一次无提示测验通过。

序章的故事条件是完成 26 个字母地点初见及基本导航，或经过审核的无障碍替代；英语认读表现另记。三上前六单元再出现的 Aa–Zz 是旧知在新情景中的重遇，不能重新包装成第一遍认识字母，也不能把走完 26 个地点当成全部字母已掌握。


默认按三上至六下的顺序推进。家长可以选择起点册次，但所有新档仍先完成完整 26 字母探索序章。所选起点册的首个 Unit 是“前一 Unit 故事已完成”的明确例外；必要先修仅作为本章导入补充，不能计作前册、前章覆盖或掌握。后续单元依所选 `curriculum_route` 顺序继续，具体状态约定见 [主线状态与成长规则](主线状态与成长规则.md)。

### 剧情与英语分别记录

- 故事进度建议放在 `story_events/<source_unit_key>`：行动完成、世界变化确认、使用了什么帮助。受助完成仍可推进故事。
- 英语证据建议放在 `english_evidence/<source_unit_key>`：来源位置、任务变体、提示使用、尝试时间、实际回应及复核状态。初始为 `not_assessed`。
- 有提示完成、独立回应、换人物或地点后的迁移分别留证；基础小游戏成绩、探索发现、故事完成不能自动写成“英语掌握”。
- 后续正式题目、判定阈值和复习策略必须等待教材正文、页图、音频及教学审校。标题级单元目前只能确定最小主题方向。
- 以下每个事件列出的三个行动均是剧情草案；“世界变化”是该事件故事完成的可见结果。它与语言表现是否成功、是否独立、是否稳定分开。

每个事件还共同需要：教材证据复核、对白及语音来源绑定、事件状态与世界变化持久化、独立英语证据接入。单元条目中的“新增需求”只列该事件特有的部分。
