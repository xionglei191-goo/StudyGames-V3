# 字母岛：经营与创作系统设计 v0.1

日期：2026-11-13。状态：第一版设计稿，尚未实现、数值尚未经过试玩。

实现跟进：本设计完成后，已按用户后续指令接入首批代码。当前实际能力、测试结果及尚待完善项见 [2026-11-13 实现交付](../../delivery/life-creation-20261113.md)。下文保留本版设计基线，不作为实现完成度声明。

本版采用已确定的方向：**以自己的家和社区生活为中心，小店经营是可选择的发展路线；玩家通过收集、制作、设计和使用作品，逐渐形成自己的生活。** 本轮只编写设计文档，继续遵守“不改游戏代码”的范围。

## 1. 玩家要得到的体验

**“我住在这里。我能决定这里是什么样子，也能做出别人会使用、会记得的东西。”**

长期目标来自玩家自己的生活项目，例如：把小院变成阅读花园、设计一套星星家具、开一个周末茶点摊、做出自己的绘本展示角。项目可以随时改选，已有物品和设计继续保留。

一段体验应让玩家获得以下至少一种进展：做出一件喜欢的作品；改变一个生活空间；学会一种制作方法；让一位朋友使用或回应自己的作品。每次游玩都有保存点，复杂项目可以分多次完成。

本版把五件事情连起来：

**生活愿望 → 设计预览 → 收集材料 → 制作实物 → 布置／赠送／展示／可选销售 → 新的生活机会。**

设计可以先于收集：孩子先看到自己想做的东西，材料清单才有意义。探索中偶然获得的材料和图案，也可以反过来启发一个新项目。

## 2. 经营哪些东西

| 经营对象 | 玩家作出的决定 | 世界如何回应 | 长期积累 |
|---|---|---|---|
| 自己的家 | 房间用途、配色、家具、展示内容、院子安排 | 物品可实际使用，来访者在空间中活动 | 个人空间、家具、作品收藏 |
| 材料与生产 | 采什么、买什么、保留多少、加工成什么 | 原料转成有用途的实物 | 材料储备、配方、工作设施 |
| 创作工坊 | 使用什么模板、怎样组合部件和图案、制作哪个版本 | 作品在场景中保持玩家选择的外观 | 永久设计稿、部件与图案库 |
| 可选小店 | 摆什么商品、布置什么风格、接待哪些需求 | 顾客看商品、选择、购买、记住店里的作品 | 叶币、熟客经历、陈列空间 |
| 社区项目 | 参与哪个公共角落、贡献什么作品、邀请谁使用 | 公共空间出现实际变化 | 共同作品、照片和关系经历 |

家园路线、创作收藏路线和小店路线共用材料、作品与居民。基础配方、编辑工具和社区项目都有家园／创作入口，开店不会成为全体玩家的前置条件。

本版生活模拟围绕活动与空间用途展开：坐下、看书、吃点心、交谈、制作、休息。暂不增加一组持续下降的饥饿、卫生和社交数值。NPC 的活动由当前场所、共同经历和本次邀请决定，玩家能看懂他们为什么来到这里。

## 3. 世界空间与开放规则

### 3.1 固定地标与可创作空间

26 个字母地标的核心形象、字形、公共入口和主要通路继续稳定，承担地图识别与字母记忆的作用。创作主要发生在家园、店铺陈列区和明确划定的公共布置区。

| 空间 | 本版允许的操作 | 保留的空间条件 |
|---|---|---|
| 客厅、小院 | 摆放、收纳、旋转、换图案、划分活动角 | 门口、主要通道和剧情互动点保持可达 |
| 原有卧室、书房 | 继续使用已有装修能力 | 新系统不删除原有布置和购买成果 |
| 个人工坊角 | 打开设计、试做、制作、查看作品册 | 工作台可用，不要求先买高级设备 |
| 小院的小摊位置 | 借用基础摊台或摆上自制展台，陈列商品 | 营业由玩家主动开始和结束 |
| 社区作品角 | 选择一个公共展示位，安放或替换自己的作品 | 公共功能不因玩家收回作品而中断 |
| 字母场所 | 采集、向居民学手艺、参加已有活动 | 固定记忆形象不随玩家图案被替换 |

首批新增流程只使用客厅、小院、A 果园、C 烘焙坊、F 花园五处现有空间。其余场所继续保留已有游玩内容，后续再加入新的手艺和材料变体。

### 3.2 与原主线的关系

- 家园基础引导完成后，开放生活心愿、基础设计与制作；可以和五街区探索交替进行。
- 原有“先建立 26 字母体验，再进入所选册次教材主线”的顺序继续保留。
- 生活项目不授予教材单元完成，不替代字母体验事实，也不因答题结果锁定。
- 剧情正在使用某位 NPC 时，来访安排避开该段演出；玩家可先邀请另一位伙伴或继续布置。
- 既有 U1 合照、U2 回信、U3 欢迎桌进入作品展示与生活记录，原来的领取和完成事实继续使用。

## 4. 收集什么，为什么值得收集

收集内容分成六类，每类都有后续用途。

| 类别 | 例子 | 获得方式 | 后续用途 |
|---|---|---|---|
| 消耗材料 | 木料、纤维、黏土、苹果、花材、石料 | 采集、购买、生活委托 | 制作实物 |
| 永久配方 | 小圆桌、灯笼、花瓶、苹果蛋糕 | 居民陪做、生活项目、图纸购买 | 开放一种制作模板 |
| 创作素材 | 色板、印章、织纹、图案、部件款式 | 初始工具、探索发现、共同创作 | 改变作品表达 |
| 实物 | 玩家制作或购买的桌椅、食物、摆件 | 制作、购买、收到赠礼 | 使用、摆放、出售、赠送 |
| 个人设计 | “我的星星招牌”“苹果阅读桌” | 玩家编辑并保存 | 再制作、改版、应用到作品 |
| 生活收藏 | 合照、回信、发现卡、公共项目纪念 | 真实完成的经历 | 收藏、展览、触发具体朋友回应 |

收藏册同时呈现已拥有的内容与可发现的去处。未知内容给出可理解的线索，例如“去花园看看花婆婆的新作品”；不以重复随机掉落作为基础配方的来源。

材料与作品分开收纳，制作时可直接使用家中仓库。初版不通过背包不足反复打断创作；技术容量限制应有明确提示与保留方案，不能丢弃旧物品。

### 4.1 采集与游戏日

沿用可以通过休息推进的游戏日。各采集点按游戏日恢复，重复进出房间不刷新。跳过多个游戏日只恢复到当前一批，不累计多日未领取产量。

本版提供采集与材料商店两种来源。玩家可以外出收集，也可以用经营所得补齐材料。没有必须等待现实日期才能得到的基础材料。

完整种植系统作为后续扩展：选作物、安排花坛、照料并收获；成熟后保留，离线不枯萎。第一批先完成果园与周边采集、花艺制作，暂不增加多作物生长和季节价格系统。

## 5. 创作系统：从想法到游戏资产

### 5.1 四种首批创作

| 创作 | 玩家能改变的内容 | 输出 |
|---|---|---|
| 家具组合 | 模板允许的桌面／靠背／装饰部件、配色、适用图案 | 保持坐、放、照明等用途的家具 |
| 图案绘制 | 画笔、填色、橡皮、印章、准确文字工具、撤销 | 可应用到招牌、桌布、地毯、装饰画的图案 |
| 空间布置 | 位置、朝向、作品组合、桌面陈列 | 一处可进入、可使用的生活空间 |
| 食物装饰 | 基础配方、装饰样式、果片摆法、包装图案 | 可招待、赠送或出售的食品 |

首批图案画布采用可放大的 64×64 方格，提供 16 色基础色板与 8 个可收集图案／印章。画笔、填色、橡皮、撤销和文字工具从开始即可使用。尺寸和工具数量是制作初值，后续根据操作体验调整。

图案自由表达与教材字形分别处理：需要准确表达英文时可以使用文字工具；自由画的字母保留为玩家作品，不自动写成字母辨认或书写正确记录。

家具部件采用已经制作好的兼容组合，例如同一小桌的圆／方桌面、不同桌腿和边缘装饰。首批不要求孩子使用专业三维建模工具。允许的组合应保持功能与通行条件，图案和造型变化不改变字母地标的固定编码。

### 5.2 配方、设计稿、实物各自保存

这是本版的核心资产规则：

1. **配方**：说明能做哪类物品，需要哪些材料；学会后永久保留。
2. **设计稿**：记录模板、部件、颜色、图案和玩家起的名字；保存、复制和编辑不耗材料。
3. **实物**：按某个已确认的设计版本制作；确认时消耗材料，获得一件可以使用或流通的物品。

完整操作是：**选模板 → 试搭与画图 → 保存设计 → 看材料清单 → 确认制作 → 得到实物 → 立即摆放或收入仓库。**

材料不足时仍可设计与预览，并把清单加入生活心愿。取消制作不消耗材料；退出编辑保留草稿。

### 5.3 修改与复制

- 修改设计稿先形成新版本，玩家选择是否应用到自己拥有的某件实物。
- 同一模板内换颜色、图案和允许的外观款式免费。改变功能类型需要制作另一件物品。
- 复制设计免费；再制作一个实物按照配方消耗材料。
- 已出售或赠送的实物保持当时外观，修改原稿不会改变别人家里的作品。
- 删除草稿不销毁已经制作的实物；成品保留恢复其设计外观所需的信息。
- 家具的摆放和收纳改变位置，不改变所有权或数量。

### 5.4 作品可以去哪里

| 去向 | 具体规则 |
|---|---|
| 自己使用 | 家具进入布置；食品实际招待或食用时消耗一份 |
| 家中展示 | 图案、照片、回信放入相应展示载体；收藏记录保留 |
| 赠送朋友 | 先预览对象与物品，确认后实物转到朋友处；玩家保留设计稿 |
| 社区借展 | 提交一件实物占用展示位，可换作品或收回；原物不能同时出售 |
| 小摊销售 | 只陈列自己制作且在库存中的实物，成交后移出库存并获得叶币 |
| 材料回收／出售 | 首版使用固定回收价；不采用随机价格波动 |

作品可以命名、查看缩略图、再次编辑和查看来历。人物只回应实际见过、使用过或收到的作品。

### 5.5 后续 AI 创作的接入位置

以后可由草图或描述生成图案、摆件候选，再经过玩家预览和确认进入作品册。生成过程不直接改变场景、扣除游戏材料或替玩家上架。

生成摆件仍需指定属于哪种物品模板，检查尺寸、摆放和允许用途。首批使用预制部件与图案编辑完成整个创作循环，AI 生成三维物品与开放作品交易列入后续范围。

## 6. 让居民真正使用玩家的作品

玩家完成布置后，可以邀请一位已认识的朋友来坐坐。新档首轮由熊叔来访；在原旅程正式结识 Lingling、Anne 后，再开放她们的来访，不虚构 U1 已经完成。系统按物品的实际用途安排短活动：走到椅子坐下、看画、围桌交谈、吃一份点心、查看招牌或购买一件商品。

物件需要有明确功能。首批功能包括座位、桌面、展示、照明、容器和食品；烘焙先使用 C 烘焙坊的公共设施。尺寸相同的不同配色家具具有同样用途。

布置时先检查通道与使用位置：椅子前方需要留出活动空间，展品应可走近。放不下时说明具体受阻处，保留玩家当前草稿。功能检查不评判作品是否好看。

### 6.1 首批人物分工

| 人物 | 本版作用 | 能留下的具体经历 |
|---|---|---|
| 熊叔 | 介绍生活心愿、仓库、作品册和借用摊台 | 记得玩家最先做成的生活角落 |
| 阿梨 | 果园材料与采集引导 | 记得苹果被做成点心或用于招待 |
| 米洛 | 陪做苹果食品，教包装和点心陈列 | 看见玩家使用自己的配方创作 |
| 花婆婆 | 花材、花瓶和小院陈列 | 对玩家选的花艺组合作出具体回应 |
| Lingling | 原旅程结识后开放的阅读与作品参观伙伴 | 使用玩家布置的阅读座位、看见装饰画 |
| Anne | 原旅程结识后开放的茶点与小聚会伙伴 | 使用餐桌、收到邀请或品尝点心 |

表中的生活偏好和活动分工是本版游戏创作，不扩写成未经核对的教材人物事实。独立建筑居民继续使用自己的身份，熊叔不会代替米洛成为所有烘焙坊对话的发言人。

关系成长通过共同经历表达。例如“你上次那张星星招牌，我还记得”，前提是该人物确实看过。首批不增加刷礼物提升的好感数值；相同礼物重复赠送可以成立，但不会无限产生首次事件、配方或币奖。

## 7. 小店经营：一条可选路线

玩家先可以在小院借用一个基础摊台，验证自己是否喜欢经营。之后可制作陈列架、调整店名和招牌、增加陈列位，把小摊做成自己的风格。

### 7.1 一次营业

**选 1–3 件库存商品 → 预览招牌和陈列 → 主动开摊 → 依次接待最多 3 位顾客 → 查看实际成交 → 继续或收摊。**

- 每位顾客提出一条清楚的需求，例如“想买一份苹果点心”或“想要一块写得清楚的招牌”。
- 玩家介绍、选择并确认交付；确认前商品保留在自己库存里。
- 本版使用固定售价，款式选择影响外观和具体回应，不设自动审美评分加价。
- 顾客没有倒计时流失；暂停、退出或改天继续保留本次营业状态。
- 售空可补货或收摊；未售商品仍属于玩家。
- 每次营业有独立记录。重看结算或恢复同一次成交不会重复得到收入。

本版不做租金、欠债、雇员工资、自动离线销售和动态市场。经营的决策先集中在产品、材料用途、空间布置和接待。

### 7.2 不开店的收入路径

居民生活订单提供送货入口，采用与小摊相同的同款交付价。玩家可以把作品送给需要的人获得收入，也可以只采集、装修和收藏。公共建设与基础编辑工具不以累计销售额作为条件。

订单是可选的明确需求；接受后可以暂存、取消或换一单。接单与取消不扣材料，材料在确认制作时消耗，成品在确认交付时移出库存。社区纪念和首次作品体验主要给图案、配方与展示机会，避免所有行为都叠加发钱。

## 8. 经济与成长规则

### 8.1 一种货币、三种积累

继续使用叶币。材料是生产投入；配方和设计是永久知识；照片、回信与共同经历是收藏。生活成果和学习观察分别记录。

叶币主要用于补材料、买现成家具、扩充可选空间和陈列设施。基础制作、画图与一次招待能依靠开场材料和采集完成。借用的公共设施提供制作入口，购买设施主要改善便利与布置选择。

数值初稿见 [首版内容与经济](首版内容与经济.md)。本稿给出可算清楚的一组起点，不把它视作已完成平衡。

### 8.2 三条可以交叉的成长路线

| 路线 | 起步 | 中期目标 | 较长目标 |
|---|---|---|---|
| 家园生活 | 做一张桌子或一个阅读角，招待一位朋友 | 让几个房间形成各自用途 | 拥有能展示自己经历的完整家园 |
| 创作收藏 | 保存一张图案，制作第一件自己的作品 | 收集素材，形成个人主题系列 | 举办作品展，让朋友使用自己的设计 |
| 小店经营 | 借摊台试卖一小批物品 | 形成自己的产品和陈列风格 | 经营一处有熟客与主题活动的小店 |

成长主要增加可做的事情、样式和使用空间。制作速度与作品售价不会因为使用提示或英语表现而降低。

基础配方由人物陪做或生活项目解锁；“招待一次”“完成一件作品并展示”等条件允许不同路线达到。一次项目只记录一次对应解锁，作品改色和重播演出不重复结算。

### 8.3 社区共同成果

首批社区项目为“邻里作品角”。玩家可以贡献一件装饰画、花瓶或小凳，任选其一；其他居民提供基础设施。完成后出现可使用的展示／停留空间、一次参观和一张合照。

作品作为借展登记，可以替换和收回。收回后保留居民提供的基础设施与已发生的经历，不反复发放建设奖励。后续可扩展阅读角、花园、公共餐桌和节日活动。

## 9. 学习与剧情怎样进入生活

英语在需要理解或表达时出现：查看材料名、听朋友想要什么、给作品命名、介绍一张画、邀请别人来坐、接待顾客。

- 生活动作始终有清楚的图像与操作支持，伙伴可以示范或陪做。
- 需要某个词时，可进入现有字母形象故事，返回后继续原来的生活步骤。
- 使用帮助得到相同的实物和生活成果；学习记录保留实际提示与回答。
- 采果、搬物、放椅子、成交和看演出只生成对应生活事实。发生真实听辨、选择或表达时才生成该维度的学习观察。
- 游戏新编需求与教材目标逐项关联，只有已核实的内容进入正式学习观察。

剧情为经营与创作提供人物和情境：朋友想组织阅读下午茶、居民需要一个新招牌、社区想布置作品角。玩家仍可改变样式、安排和参与方式。

现有 U1–U3 成果可以直接成为生活材料：合照放入新做的画框，回信挂在作品角，欢迎桌使用玩家自己的桌布图案。完整毕业展以后可以汇集这些真实作品；本版先做好首批生活项目。

## 10. 首批制作范围

| 本版必须形成的能力 | 具体范围 |
|---|---|
| 家园与采集 | 客厅、小院、A 果园、C 烘焙坊、F 花园的新增流程；6 类基础材料 |
| 制作 | 12 个配方：10 类耐用物件、2 类食品；缺材料可先保存设计 |
| 创作 | 兼容部件与配色；一个图案编辑器；4 类可应用表面；8 个初始／可收集图案 |
| 资产使用 | 设计与实物分别保存；制作、布置、收纳、再编辑、展示、赠送和销售 |
| 人物生活 | 4 位生活引导／手艺居民、2 位结识后开放的来访伙伴；熊叔承担新档首轮来访；坐、看、交谈、招待和购买等实际行为 |
| 项目 | 家园招待、主题作品展示、可选小摊，以及一处可共同布置的邻里作品角 |
| 进度与恢复 | 中途退出保留草稿、材料、布局、已成交事实和来访位置；旧成果继续可用 |

现有卧室、书房、其他地图、服装、剧情和学习内容继续保留；首批范围只表示新增系统集中验证的位置。

后续扩展包括：更多手艺、种植、服装裁剪、独立店面、更多居民生活事件、玩家间参观与交换、AI 辅助图案与模型。需要先让现有作品能够制作、使用和流通，再扩大数量。

## 11. 后续实施顺序与完成标准

| 顺序 | 要完成的事情 | 可检查的结果 |
|---|---|---|
| A | 设计稿、配方、实物和材料的完整关系 | 同一设计可制作两件；修改一件外观不会改动已送给朋友的另一件 |
| B | 家园制作与使用 | 玩家可完成一个生活角落，朋友走过去并实际使用 |
| C | 图案创作与收藏 | 自己画的图案应用到多个允许表面，关闭重进后仍一致 |
| D | 赠送、借展、订单与可选小摊 | 物品和叶币正确流转，作品在接收处可见，重复操作不重复结算 |
| E | 社区项目、旧成果与学习记录接入 | 合照回信进入新展示，已有存档保留，生活行为与学习观察各有来源 |

详细体验和验收在 [体验流程与验收](体验流程与验收.md)。阶段顺序是设计建议，没有编造工期。

试玩重点观察：玩家能否说清自己的目标；是否愿意主动修改作品；是否理解实物去了哪里；不同路线是否都能推进；是否看到居民使用自己的东西；能否满意地停下并在下次接着做。数值与节奏按观察调整，不用在线时长代替好玩。

## 12. 与现有工程的连接及文档边界

已有基础包括：叶币、采果与蛋糕、自由网格装修、可穿戴与手持物、发现卡、照片回信、朋友回应、字母故事与保存体系。新增工作集中在材料体系、通用配方、可编辑设计资产、图案工具、物品功能、营业与订单、统一作品入口。

本稿只创建一份后续制作依据，没有宣称这些新增能力已经运行，也没有调整既有价格、存档或教材进度。遇到旧规则冲突时，后续实施应按配套经济文档的迁移方案处理，保留原有物品与领取事实。
