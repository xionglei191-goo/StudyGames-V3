# 体验流程与后续制作验收

版本：v0.1，2026-11-13。配合 [系统设计](README.md) 与 [内容和经济](首版内容与经济.md) 阅读。

本文件是后续实现的体验脚本与验收要求。下列过程尚未在游戏中制作或实测，本轮没有执行对应游戏测试。

## 1. 首次进入：先拥有一个自己的项目

原家园引导完成后，熊叔把“生活心愿”加入旅行册。玩家可以开始，也可以继续字母探索。首次说明只介绍眼前需要的功能。

| 步骤 | 玩家看到什么 | 玩家做什么 | 游戏保存什么 |
|---|---|---|---|
| 1. 选择愿望 | 三个可预览的例子：阅读角、作品角、苹果点心摊 | 选一个，或从空白作品开始 | 当前想做的事；不替换教材进度 |
| 2. 看结果 | 一个可以转看的示例小桌、招牌或点心 | 选择喜欢的模板，改颜色或图案 | 未完成的设计草稿 |
| 3. 做第一件作品 | 材料清单显示已有／缺少数量 | 使用开场材料确认制作，或先存设计 | 扣除材料，获得实物并保存设计版本 |
| 4. 放进生活 | 家园预览、使用位置与收纳入口 | 找位置、调整朝向、确认摆放 | 实物所在房间与位置 |
| 5. 获得回应 | 一位可来访的伙伴；摊主路线则有试营业入口 | 邀请、使用作品或接待一次 | 真实发生的使用／交易经历 |
| 6. 自己选下一步 | 继续改、再做一件、去探索、先收好 | 自由决定后续 | 作品、材料、进度；可选下一次心愿 |

第一件作品应在短流程内出现。完整项目以约 10–20 分钟作为初次试玩观察范围，实际取决于玩家花在绘画、选择与探索上的时间；不设倒计时或玩满奖励。

阅读角等示例只帮助理解用途，不要求照抄指定颜色、物件数量或布局。剧情保留当前步骤，玩家可以先去做自己的生活项目再回来。

## 2. 路线一：我想有一个舒服的阅读角

这是默认推荐路线，验证家园生活本身是否有吸引力。

1. 玩家在小院挑一个位置，决定放桌子、一个座位和一块自己命名的招牌。
2. 在工作台预览小圆桌；选桌面和桌布颜色，保存为“我的苹果桌”。
3. 使用开场材料制作桌、凳和招牌。可以先只做其中一件，剩下的清单保留。
4. 布置时，椅子朝向和桌边空间有实际作用；被挡住时只提示具体通道，保留当前布局。
5. 在招牌上画图案，使用文字工具写上自选名称。玩家决定是否加英文；自由命名不计入英语正确记录。
6. 新档先邀请熊叔；原旅程结识 Lingling 后可以邀请她。来访者从入口走到阅读角，坐下，查看招牌或画，作出与实际选择相符的回应。
7. 玩家可以拍一张照片，换成另一块桌布，或结束来访。

**项目结果**：可使用的阅读角、三份可复用设计、一张实际来访照片、一次共同经历。食品可选，不营业也能完成。

**下一次可以做什么**：把照片装进自制画框；学会绘本架配方；制作另一把凳子再邀请朋友；换一个季节主题。后续由玩家选择，不自动连续弹出任务。

## 3. 路线二：我想做一套自己的作品

这一条验证创作、收藏与展示能否持续提供乐趣。

1. 玩家在作品册里选择“星光纸艺”作为参考，也可以自己命名一个系列。
2. 打开图案画布，画星星与条纹，保存“星星夜晚”。没准备材料也能完成设计。
3. 预览同一图案在招牌、桌布、地毯和装饰画上的效果，分别调整裁切与重复方式。
4. 按自己的选择制作其中两件实物；缺少的材料列出采集地点和商店价格。
5. 一件摆在家中；另一件可以赠送、借展或完成接受该类作品的居民订单。
6. 修改“星星夜晚”的配色，另存新版本。已送出的作品保持原样，家里的作品可以选择换成新版。
7. 邀请已结识的 Anne 看作品；尚未认识她时由熊叔陪同参观。用一张照片和一句自己的介绍收录这个系列。

**项目结果**：一份可再次编辑的图案、至少两件有明确去向的实物、一个作品系列、一次真实的展示经历。

**长期变化**：收集更多图案，尝试部件组合，设计不同空间主题，为邻里作品角准备自己的小展。需要叶币时可以送货，不要求开启小摊。

## 4. 路线三：我想试试自己的苹果点心摊

这一条验证生产和经营，而不是要求全体玩家采用同一种生活方式。

1. 玩家选择点心摊心愿，在 C 烘焙坊预览苹果蛋糕与果盘，自己选一种。
2. 米洛陪做一次。已有蛋糕配方直接承接；没有资格的玩家获得同一制作资格，原一次性苹果委托另行保留。
3. 玩家去 A 果园采果，也可以购买补料。在开工前看清材料需求。
4. 做出食品，安排果片样式和包装，保存自己的设计。
5. 在小院借用一个基础摊台，画招牌，陈列一件实际库存商品。
6. 主动开摊。顾客走近、看招牌，提出一条清楚需求；玩家选择商品并确认成交。
7. 实物从库存移出，叶币到账；顾客带走商品，交易保留记录。
8. 玩家选择补货、收摊或把收入花在自己的家里。未售商品保留，也可以用来招待朋友。

**项目结果**：自有招牌和食品设计、一次真实交易、一份收入、顾客对商品的具体回应。以后可以扩充陈列位或改变产品，价格不因自由图案被自动评高低。

**不同选择**：相同苹果可以做蛋糕、做果盘、留作招待或直接回收。每种方式的材料数量、获得的实物和收入事先可见。

## 5. 一段把系统连起来的具体故事

以下是原创生活事件“院子里的苹果下午茶”的首版编排，在原旅程结识 Anne 后开放。新档第一轮来访使用前面的熊叔流程。该事件使用上述系统，同时让玩家保留选择。

| 场面 | 人物愿望 | 玩家可作出的选择 | 实际操作与结果 |
|---|---|---|---|
| 产生想法 | Anne 想找一个能坐下来聊节目的小地方 | 在家招待，或把心愿改成作品展示 | 选定一个已有家园位置；保留未选路线 |
| 准备空间 | 需要座位和放东西的桌面 | 使用已有家具，或自己制作新样式 | 布置可用的座位与桌面，确认通道 |
| 准备内容 | 玩家想用自己的方式欢迎朋友 | 做点心、展示作品，或两者都做 | 做出食品或摆出一件真实作品；纯参观路线不强制食物 |
| 留下个人痕迹 | 玩家想让这个角落有个名字 | 自由命名、选图案、写一句介绍 | 制作招牌或装入装饰画 |
| 朋友到来 | Anne 想看看准备好的地方 | 先参观、先坐下、先看作品 | NPC 按可用设施执行对应行为 |
| 一起度过一会儿 | 朋友回应刚才看到／使用的东西 | 改摆法、合照、聊一件小事、结束 | 保存实际发生的经历与照片 |
| 后续机会 | 别的居民也对点心或作品感兴趣 | 接一单、尝试小摊、继续自用 | 新的可选需求；原作品与设计保留 |

事件检查功能需求，允许玩家用已有家具完成。购买更贵的桌子、选择某种颜色、独立回答英语都不属于完成条件。

如果想加入语言目标，一次只选与当前动作直接有关的机会，例如理解朋友想要苹果点心、介绍一张画、发出邀请。先核对目标，再提供图片、文字、语音和伙伴示范，记录实际使用的支持。

## 6. 反复回来时有什么变化

这里描述几次可能的回访，不规定连续登录、真实日期或固定顺序。

| 再次游玩的动机 | 可继续的活动 | 世界中保留的变化 |
|---|---|---|
| 我想把昨天的作品改好一点 | 打开原设计，换图案或布局 | 旧版本可保留，选择应用的新版本改变自有物品 |
| 我想做另一种东西 | 向居民学一个新配方，去找材料 | 新的制作能力与实物进入收藏 |
| 我想让朋友也用到 | 再制作一件，赠送或完成订单 | 朋友处有对应作品，交付事实可回看 |
| 我想看看我的摊子会怎样 | 准备新商品，主动开启一场营业 | 真实成交、熟悉顾客经历、重新投入的叶币 |
| 我想让街区更好看 | 给邻里作品角借展一件作品 | 公共空间出现作品，居民可走近使用或观看 |

来访对白读取具体事实：谁见过哪件作品、在哪里使用过、共同完成过什么。未发生的经历不提前生成。玩家长时间没回来，原有成果和关系经历保持保存。

## 7. 必要的界面与信息

沿用现有旅行册与家园入口，主要增加四个内容区域；具体界面外观在后续制作时细化。

| 位置 | 首先回答的问题 | 需要保留的信息 |
|---|---|---|
| 生活心愿 | 我现在想做什么，下一步是什么 | 一个当前目标、下一动作、材料缺口；可切回原旅程 |
| 我的作品 | 哪些是我设计的，哪些已经做出来 | 设计稿／实物两个视图，缩略图、名称、版本、实物去向 |
| 工坊 | 我能做什么，还缺什么 | 模板预览、编辑、材料来源、制作确认、草稿恢复 |
| 布置／营业 | 这件东西放哪里，谁能使用，实际卖出什么 | 功能与通行提示、真实库存、成交确认、暂存和退出 |

同一时间只突出当前选定的生活目标。材料不足可以先保存，作品未完成也允许退出。为功能服务的提示直接说明问题，例如“椅子前面需要留出位置”，不在玩家流程中展示实现术语。

## 8. 后续实现的验收清单

下表列出要验证的行为，不是本轮测试结果。

| 编号 | 场景与操作 | 应观察到的结果 |
|---|---|---|
| V01 | 新档完成家园引导，尚未完成 26 字母 | 可进入自由设计与基础制作；教材主线顺序保持原规则 |
| V02 | 材料不足，画图、预览、保存并退出 | 设计草稿保留，材料和叶币不变；回来可继续 |
| V03 | 确认制作与取消制作各执行一次 | 只有成功确认的制作扣料并新增一件实物；失败或重复提交不多扣、多产 |
| V04 | 用同一设计制作两件，赠送一件，再修改设计 | 朋友收到的那件保留原版本；自有那件可选择更新 |
| V05 | 摆放、收纳、换房间、反复旋转 | 实物总量与所有权不变，所有已确认位置恢复正确 |
| V06 | 把图案应用到四类表面，重新进入游戏 | 图案、裁切和重复方式一致，源设计可继续编辑 |
| V07 | 椅子被挡住，再移到可用位置并邀请朋友 | 清楚提示受阻；修正后角色实际走近、坐下、继续活动 |
| V08 | 把实物借展到社区，再收回或替换 | 同一物品只有一个实际去向；共同经历保留，奖励不重复 |
| V09 | 在小摊确认一笔成交，暂停、退出、恢复、重看结算 | 商品只减少一次，收入只增加一次，顾客和营业状态一致 |
| V10 | 订单领取后取消，再重新接新订单 | 未交付的实物与未投入制作的材料保留；已制作成本不退回，只有实际交付产生收入 |
| V11 | 采集后反复进出，再推进游戏日 | 同日不重复恢复；次日恢复到上限，不累计跳过天数 |
| V12 | 将开场材料用于别的项目或回收，再回到原心愿 | 可通过采集、购买或借用设施继续；借用演示物不进入销售循环 |
| V13 | 用全提示完成制作／经营，再查看学习观察 | 正常获得生活成果；只记录真实发生的语言尝试，搬物与成交不写成答对 |
| V14 | 使用现有旧档进入新系统 | 钱包、苹果、蛋糕、服装、家具、作品、章节和领取事实保留；新增材料包只发一次 |
| V15 | 原苹果委托未做，通过米洛陪做学会蛋糕 | 获得制作资格；原委托未被虚构完成，之后交委托按原一次性记录处理 |
| V16 | 当前剧情使用某位来访角色 | 不生成身份冲突的第二个人；可换人、改日来访或先继续创作 |
| V17 | 保存失败或中途退出编辑、制作、交易 | 保留可恢复草稿；材料、实物、叶币按同一已保存结果恢复，不提前宣称到账 |
| V18 | 分别走家园、收藏、小摊三条路线 | 都能制作、使用或展示成果；不开店可获得基础配方与需要的材料 |
| V19 | 新档未结识 Lingling、Anne 就完成首次生活项目 | 熊叔能承担来访；不会提前生成两位伙伴的结识或 U1 完成事实 |

### 内容验收

- 六类材料都有可理解的来源和准确库存说明。
- 十二个配方有制作预览、外观选择、材料消耗与用途表现。
- 四类图案表面能显示玩家真实绘制的内容，而不是只保存一个“已创作”标记。
- 八个图案的来源事件可完成并保存，不靠重复抽取。
- 两位来访伙伴能回应实际发生的事；不同布局、作品和活动应产生相应表现。
- 共享社区角里可以看见并使用／观看被借展的作品。
- 涉及英文学习的内容有核实过的目标、合适的支持和独立的观察记录。

## 9. 试玩要回答的问题

第一次试玩重点看五件事：玩家是否能说清自己想做什么；是否理解材料怎样变成作品；是否能找到自己的设计和实物；是否看见居民使用作品；是否愿意主动改一处自己不满意的地方。

之后再观察：三条路线各自哪里有重复劳动，哪种收集有意义，收入是否允许选择，朋友回应是否具体，暂停后是否记得接下来做什么。

记录玩家实际行为与原话，区分操作困难、内容不清楚和缺乏兴趣。完成了一轮流程只说明这一轮能走通；经济长期平衡、持续吸引力和英语学习效果需要另外观察。

本轮设计交付到此为止。后续实施应先实现“保存一个设计 → 做出一件实物 → 放进生活 → 让朋友使用”的完整过程，再逐步扩展内容数量和经营种类。
