# 主线、单词故事与美术资产整合核查

日期：2026-10-22。结论文件：[GDD.md](../../../GDD.md)。本记录区分“已消除的规则冲突”“已补齐的制作接口”和“仍需内容/运行验收的工作”，不把文档修改写成游戏实现。

## 1. 核查范围与方法

读取 `mainline/`、`vocabulary/`、`art/` 的正文、结构化数据、生成脚本与原有验证报告，核对当前工程与教材来源键；主线、词汇和美术分别由独立复核者审查，再由主集成者核对连接结果并编写 GDD。

覆盖数据为八册、81 单元事件、26 字母序章、1314 册内目标、1073 拼写、1096 核心故事页、24 项环境规格、142 条教材来源身份与144条 NPC 规划、40 项动作。全量检查 ID、版本、字符、单元关联和资产引用；具体故事语义与显示边界重点检查 nose、hello、book、football、长词、缩略式、标点与重音等样例。核查不等于逐页重审全部教材或逐个验证全部游戏画面。

词汇正式词表中的 52 张页图和人物来源的 59 张代表页图是不同检查集合，可能重叠，不能相加声称看过 111 张独立页面。各域保留原来源与审核层级。

## 3. 已补齐的接口缺口和歧义

| I02 | 1041种中文故事位置标签可能被当成1041个既有场景节点 | root_location是建议标签，storage_slot是稳定内容页位；场景绑定未核实保持null，不新建世界建筑代替索引 |

| I04 | 背景冻结可能连讲rain/river的语义演出也一起冻结 | 世界环境/全部背景NPC日程与当前表演分开计时；暂停菜单/后台两者均停；语义雨水由演出层表现，可静态分步 |

## 4. 关键裁定示例

- 新档选择五年级上册：仍先体验26字母，完成后进入 `english-grade5-volume1-smartedu-2022/unit-1`，补必要先修，不把三四年级单元批量标成完成。
- 孩子在H0主动打开book故事：剧情照常；本次拼写记录具有故事线索。之后可重新安排一次尝试，不把刚看过的同次表现改写为无提示。
- café 是听说目标：提供可选文字故事；é对应E并保留重音，不强迫拼写，也不把重音事件再加一次形成重复字符。
- 夜景中做Good morning：先切入明确清晨的教学语境或标注时间的局部卡；保留环境相位/游戏日，退出后回到原自由生活状态。
- 同一教材身份去学校：演员预约确保不在家园复制第二个人；book中的两个O则允许创建同一猫头鹰资源的两个有序缩影。
- 主线完成照片：U1-08只保存照片子事件；U1-09回家安放后结算整章，重拍与补看动画不重复领奖。

## 5. 联合核验与可复现性

[validate_gdd.py](validate_gdd.py)独立读取三域文件，检查八册源版本、26编码、六级帮助、角色来源、81事件候选集与1359关联、适配条目、字符还原、重复次数、逐镜位置、教学要求、20种美术样例、引用指纹和GDD本地链接。输出[联合报告](integration_summary.json)，报告中的输入SHA用于判断后来改动是否已重新核对。

三域各自结果见：

- [主线核查说明](../mainline/整合核查与修订.md)、[主线报告](../mainline/validation_report.json)。
- [词汇核查说明](../vocabulary/整合核查与修订.md)、[词汇报告](../vocabulary/review/validation.json)。
- [美术核查说明](../art/整合核查与修订.md)、[美术报告](../art/validation_report.json)。

主线原 `source_snapshot.json` 中游玩说明的历史指纹与当前文档有变化，保留为历史快照提示，没有改写旧SHA来伪装不变；它不等同教材内容变化，也不构成本轮运行验收。当前关键内容版本以联合报告和词汇适配版本为准。
