# 字母岛：玩法与剧情梳理

整理日期：2026-11-13。用途：作为下一轮玩法、剧情完善的讨论底稿。

后续讨论已进一步聚焦经营与创作，新的系统方案见 [经营与创作系统设计 v0.1](life-creation-v01/README.md)。本文继续作为现有玩法与剧情的核对底稿。

依据当前工作区的 Godot 项目、章节数据和既有策划整理。工程版本为 4.5.0-v45；本次是内容与代码核对，没有重新逐章实玩。下文分别说明现有内容、运行框架与完善建议；建议尚未写入游戏。完整章节目录见 [八册 81 章剧情清单](章节剧情清单-20261113.md)。

## 1. 游戏要让玩家经历什么

**孩子成为字母岛的新居民，在探索、交朋友、共同做事和布置自己的家时接触英语，逐渐从被欢迎的人，成长为能够组织活动、帮助伙伴、向别人介绍小岛的人。**

这条成长线来自现有八册主题：第一批朋友 → 安排生活 → 校园与邻里 → 公共活动 → 选择和责任 → 研究与旅行 → 照顾社区 → 毕业世界展。

玩家的具体动力有三种：

- **想去看看**：岛上有不同的建筑、物件、居民和小发现。
- **想做成一件事**：帮朋友送邀请、准备座位、做礼物、举办活动。
- **想留下自己的东西**：照片、回信、发现卡、旅行页、家具和共同完成的作品。

建议后续始终围绕这三种动力组织内容。教材提供语言目标，生活事件提供使用这些语言的理由。

## 2. 一次游玩的基本循环

**接着上次的心愿 → 找朋友或到目的地 → 观察、交流、亲手做事 → 遇到困难时获得帮助 → 留下一件成果 → 回家展示、自由玩或下次继续。**

现有设计建议每段活动可以中断，约 10–15 分钟仅作为试玩节奏的起点；序章可每次走 2–3 站。实际时长还需要试玩调整。

| 玩法线 | 玩家具体做什么 | 现有内容与作用 |
|---|---|---|
| 小岛探索 | 走路、找建筑、观察字形、操作代表物、收集发现 | 五街区、26 字母地标、大小写展示、发现卡和街区旅行页；建立空间印象与固定字母形象 |
| 生活制作 | 采苹果、捧物、投递到工坊、制作与出售蛋糕、接受委托 | 既有生活经济，加上 30 个场景的捧物与分享台；提供可见操作和叶币来源 |
| 社交故事 | 问候、认识朋友、递书、寄邀请、安排来客、相聚 | 具体的 U1–U3 连续事件，以及八册通用章节框架；让英语与人物需求发生联系 |
| 家园创作 | 换装、选家具、摆放照片和回信、装饰欢迎桌 | 客厅、小院、卧室、书房支持自由网格装修；个人作品可保存和再修改 |
| 单词记忆 | 看立体书、跟随字母形象演出、补接顺序、按需回想 | 逐字母故事、分级帮助与词库检索；跟读、伙伴轻聊和回访提供补充入口 |

这些玩法已经各有入口，接下来需要让它们围绕同一件生活事件互相推动。例如“准备生日会”可以自然连接果园、烘焙、邀请、装饰和表达祝福。

## 3. 世界与探索序章

当前场景清单包含 43 个子场景，加主岛共 44 个场景。空间分成主岛、字母场所、校园功能区和家园房间。

| 街区 | 固定字母与代表形象 | 现有序章的生活主题 |
|---|---|---|
| 晨光村 A–F | A 苹果、B 小船、C 蛋糕、D 鼓、E 鸡蛋／完整蛋形蛋壳、F 花 | 从家出发，认识果园、码头和烘焙坊，把欢迎会的路认熟 |
| 巧手街 G–K | G 地球仪、H 帽子、I 冰淇淋、J 罐子、K 风筝 | 观察、试戴、开合、装配，为旅行册增加小发现 |
| 林间村 L–P | L 灯笼、M 蘑菇、N 鸟巢、O 猫头鹰、P 南瓜 | 认识林间邻居，观察自然，发现安静场所 |
| 山丘学园 Q–U | Q 拼布被、R 机器人、S 星星、T 火车、U 雨伞 | 拼布、动作选择、星星、车厢与晴雨观察 |
| 海湾远行区 V–Z | V 火山、W 鲸鱼、X 木琴、Y 毛线、Z 斑马 | 沿海湾探索、听声音、找线索，最后在邮局留下明信片 |

每站的基本结构是：**到达 → 看代表物 → 做一个动作或看示范 → 看大小写 → 可听读音 → 保存发现。**

A 果园有角色摘取、持物走动、放进篮子的具体过程；其他字母已有对应的观察、开合、点击、摆放等操作。V4 又在各地标叠加了捧物送到工坊台的通用活动。两层活动应分别说明，不能把所有地标都描述成已有完整经营玩法。

原主旅程规定新档先完成 26 站体验，再进入所选册次；可在帮助下完成，分次保存，自由探索和校园活动保留。新增章节画册可直接选册、选章，其衔接规则需要与原旅程统一，见第 8 节。

## 4. 目前最具体的一段剧情：我的朋友角

这段故事由家园开场、字母探索、三上 U1–U3 和聚会收尾组成，适合作为下一轮完善的样板。

| 阶段 | 发生的事情 | 玩家操作与英语 | 留下的结果 |
|---|---|---|---|
| 搬入小屋 | 熊叔迎接新居民，带着玩家认识自己的家 | 学移动与交互；选花朵或星星装饰，也可稍后选择；领取旅行册 | 一个有个人选择的小屋，以及出门的目标 |
| 认识字母岛 | 分次拜访五个街区，结识向导和居民 | 观察地标、做小动作、看大小写；不会时可请伙伴示范 | 字母发现卡、街区旅行页，可带回家展示 |
| U1：欢迎角的第一张名牌与合照 | 到校园认识 Lingling、Peter、Anne | 问候、自我介绍、放名牌、选装饰、接过朋友递来的书并致谢；可看 hello 记忆故事 | 欢迎角和第一次合照，回家摆放照片 |
| U2：寄给新朋友的邀请 | 想让更多朋友参加欢迎会，需要先问清收件人 | 到校园找 Lingling，到邻居屋找 Tim；询问姓名，把两封邀请投进正确的信格，向 Anne 道别 | 两封回信；邀请封面与回信可以组成“我的朋友角” |
| U3：欢迎会座位数 | 先认识三位来客，Anne 后来加入 | 根据角色回答贴年龄数字；先摆三张座位卡，再补第四张；练习年龄表达与数人数 | 准备好的欢迎桌，可选择桌布并安排四位朋友的位置 |
| 相聚与回访 | 朋友来到布置好的桌旁，之后还可以再见面 | 观看欢迎、认识来客、一起相聚、道别四幕；回访时朋友回应实际发生的小事 | 相聚回忆；照片、邀请、回信、桌面布置组成可持续修改的个人作品 |

年龄卡使用游戏情境设定。年龄和来客人数分别处理：Anne 的年龄卡写十岁，新增后是四个座位。

这段故事已经有连续因果：**认识了朋友，才会想邀请；有了回信，才需要准备座位；布置完成，才有相聚和回忆。** 后续章节值得沿用这种连接方式。

## 6. 英语如何进入玩法

### 6.1 在生活中产生用途

优先让表达决定接下来做什么：问姓名确定邀请送给谁，听年龄选择数字，理解人数决定摆几个座位，表达喜好帮助安排果盘。

当前基础主线已有这些情境；新增通用委托主要是根据中文意思选英文贴纸。需要逐章决定“这次必须理解或表达什么，事情才会向前走”，同时提供陪做和示范。

### 6.2 固定字母形象构成记忆故事

这是项目最有辨识度的机制：每个字母有稳定形象，单词依照完整字母顺序串成有动作、有词义联系的小故事。

例如当前 book 故事：

**B 小船运来书 → 第一个 O 猫头鹰打开封面 → 第二个 O 猫头鹰翻开内页 → K 风筝托起打开的书。**

两个 O 分别出现并承担不同动作。hello 同样保留两个 L；nose 使用 N 鸟巢、O 猫头鹰、S 星星、E 蛋壳，并以鼻子顶星星、打喷嚏和鼻印连接“鼻子”的意思。

当前内容包有 8 册、1,314 条册内词表记录、1,073 个不同拼写目标、1,096 个核心义项故事。跨册重复出现会增加册内记录数量，词库规模应沿用这些明确口径。

### 6.3 帮助、复现与记录

已有帮助协议从 H5 完整示范，逐步到 H4 搭桥、H3 补缺、H2 第一步、H1 位置与意义、H0 自主尝试。孩子可以随时增加帮助，完成生活成果不要求先独立答对。

现有“朋友捎来的小邀请”面向已体验的 26 字母和 U1–U3，使用真实时间安排可选回访；游戏里睡到下一天与现实隔天分别记录。八册全部章节的回访还需要逐章接入。

语音播放、跟读识别和伙伴轻聊已有代码入口；实际可用性依赖对应服务和资源。伙伴回复支持配置云模型，也有离线模板回退。这些能力可以陪伴玩家，核心事件仍需有确定的角色目标、操作和结果。

| 人物层 | 当前作用与依据 | 后续剧情可以深化的部分 |

| 熊叔、兔兔 | 熊叔负责生活与旅程引导；兔兔参与果园体验及后续回访 | 向导逐步放手，给玩家组织和帮助他人的机会 |
| Lingling、Peter、Anne、Tim、Mingming、Dongdong | 参与问候、递书、邀请、年龄卡、欢迎桌等具体事件 | 为几位常驻伙伴补充各自的愿望、困难、擅长的事和连续变化 |
| 建筑居民 | 34 位有独立模型、姓名和职业的居民，分布在 A–Z 与校园 8 个区域；如阿梨、阿渡、米洛、鼓鼓、啾妈、花婆婆 | 把职业转成独特操作与需求，例如摆渡、烘焙、节奏、照护，形成街区内外的协作 |

已有八位朋友会依据照片、邀请、桌面或发现作品等保存事实回应。建议扩展这种“记得共同经历”的关系表达，并为重要伙伴设计可持续的变化。

## 8. 当前需要优先统一和完善的地方

### 8.1 两套章节进度需要接成一条旅程

原旅程分别保存家园引导、26 字母、U1 详细步骤、U2/U3 事件；V4 另行保存当前单元和每章 0–3 的阶段。章节画册展示整册单元并提供选章按钮。

因此，后续需要明确：新档从哪里开始、序章何时结束、家长选册如何生效、画册选章属于自由体验还是主线推进、同一章的合照与纪念牌如何对应。应让玩家始终知道眼前的心愿，以及完成后发生什么。

依据：[原旅程状态](../../game/scripts/journey_progress.gd)、[V4 状态](../../game/scripts/game_state.gd)、[章节画册](../../game/ui_v4/chapter_atlas_view.gd)。

### 8.2 三幕文字需要变成具体场面

当前 V4 共用“聆听心愿 → 亲手共创 → 点亮纪念”的流程。第二幕可以进入主题活动，也保留“直接完成共创进入终幕”的按钮；在对应房间提交物件也可推进第二幕。第三幕主要落地为章节纪念牌与叶币。

章节提纲则写有寄信、修复展台、举办世界展等不同结果。后续需要给关键动作和成果建立各章自己的表现：朋友确实收到信，展台确实被修好，世界展确实展示玩家选择的内容。使用帮助时，也应让玩家看见伙伴把事情做成。

依据：[通用三幕对白](../../game/gameplay/unit_storyline_director.gd)、[章节推进与物件联动](../../game/scripts/main.gd)、[场景纪念物](../../game/gameplay/tactile_life_quests.gd)。

### 8.3 五类主题界面需要发展出不同操作

现有五类主题为点餐配盘、天气穿搭、问路寻宝、作息时钟、主题百宝箱。按当前关键词分类规则静态计算，81 章分别落入 9、8、14、11、39 章。

目前它们共享的操作是：按中文提示，从英文卡中依次选出三个目标，填满三个格子。主题标题、配色、格子名称和提示语不同。

后续可保留界面基础，逐步增加对应的操作规则：配盘考虑顾客需求与食材组合；穿搭考虑天气和服饰；问路在实际路径上选方向；作息调整时间与先后；百宝箱根据物品用途整理。这样重复游玩时会出现新的判断和反馈。

依据：[主题玩法](../../game/gameplay/chapter_thematic_play.gd)。以上新操作是完善建议。

### 8.4 每章的语言目标需要人工选定

当前 V4 数据中，三上 U1 的引导词为 bag，主题活动前三词为 bag / good / hello；U2 为 afternoon / and / back；U3 为 are / eight / five。它们来自关联词表，但与问候、问姓名、问年龄这些事件目标的贴合程度不同。

建议每章明确一个交流目的、少量必要表达、可选拓展词。词故事在孩子遇到相应词时出现，和当前事情衔接，避免章节主词仅由词表排列决定。

依据：[V4 章节数据](../../game/data/learning/curriculum_arcs_v4.json)、[当前目标卡选择](../../game/gameplay/chapter_thematic_play.gd)。

### 8.5 生活完成与英语表现需要统一记录规则

原旅程与词故事细分了观看、提示、独立尝试和实际回答。V4 新链路在部分章节推进、捧物交付时，会直接写入对应词的正确记录；章节终幕和部分交付使用零支持等级。

这些操作能证明玩家完成了生活动作，英语记录还需要对应的听辨、选择或表达证据。完善时应分别保留生活成果、接触过的内容、提示条件和实际作答，家长页据此呈现观察结果。

依据：[交付和章节推进的记录入口](../../game/scripts/main.gd)、[既有帮助规则](../../GDD.md)。这是本轮静态核对发现的具体规则冲突，尚未修改实现。

### 8.6 长期剧情需要反复出现的愿望和结果

现有八册主题有成长方向，各单元也有生活题材。接下来可为每册设置一件逐章准备的大事，并让几位伙伴的个人愿望穿插其中。每章解决一件小事，同时改变最后活动的内容。

例如三上的“第一场生日欢迎会”已经存在于 U10 提纲中，可以承接前面收集的名字、照片、邀请、颜色、食物喜好和礼物。下一册开场时，朋友还会提起这场活动，家的展示也继续保留。

### 8.7 文档状态需要跟随内容深度更新

README 和 GDD 顶部已有 V4.5 的整体完成描述，正文仍保留早期实施范围，部分数据也带历史策划状态。下一轮宜统一成四种可检查的状态：事件提纲已定、可交互流程已接通、具体场面与成果已制作、试玩后已修订。这样可以逐章推进，避免仅凭目录数量判断完成程度。

## 9. 建议下一轮怎么完善

建议先把一个连续篇章做扎实，再以它作为其他册次的标准。第一批聚焦“我的朋友角”与三上欢迎篇：

1. **先定整段故事**：我为什么想办欢迎会，谁与我一起准备，各位伙伴希望得到什么，最终留下什么。
2. **梳理 U1–U3 的完整游玩流程**：统一旧旅程与 V4 入口、进度和成果，让第一次问候、第一次来信、第一次聚会连贯发生。
3. **细化关键操作**：递书、问姓名、投信、加座位、选桌布、邀请来坐；为不会时的陪做路径准备完整表现。
4. **接续 U4–U10**：把家人、失物、热身、颜色、动物、果盘和生日题材编成欢迎篇的后续准备与插曲，逐章选择合适的语言目标。
5. **用具体成果检验完成度**：玩家能说出自己做成什么，能回去看，朋友能回应；再检查所需表达是否有真实使用机会。

每章建议固定使用下面的策划卡，先写清内容，再决定实现：

| 项目 | 需要写清的内容 |
|---|---|
| 章节愿望 | 玩家想完成什么，朋友为什么需要这件事 |
| 开场事件 | 在哪里、由谁提出；与上一章有什么联系 |
| 小困难 | 缺少的信息、物品、安排或沟通；要有可以采取的行动 |
| 主要操作 | 2–4 个有先后关系的观察、交流、移动、制作或布置动作 |
| 英语用途 | 每次理解或表达如何影响行动；本章实际使用哪些词句 |
| 玩家选择 | 至少一个选择改变成品、安排、路线或朋友回应 |
| 帮助与中断 | 如何陪做、示范、暂停，回来后从哪一步继续 |
| 结尾与承接 | 留下什么可查看的成果，朋友有什么变化，下一章为何发生 |

本轮仅新增梳理文档与章节清单，保留现有游戏实现、资产、存档和其他工作区改动。
