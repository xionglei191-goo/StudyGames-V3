# 完整住宅与小院 · v2设计落地

用户选择：完整住宅外观＋院落，进门后再选房间。沿用项目奶油白、青绿、木色和暖石色，几何为原创Blender模型。

- 轮廓：34×32米院落中的28米宽三体量住宅。主楼前伸，高檐4.4米、脊约7.05米；两翼檐3.7米、脊5.8米，屋脊方向与主楼交叉。内侧屋顶伸入主楼，形成连续屋谷。
- 结构：墙面按洞口分段，玻璃内缩；窗框、百叶、窗台和少量花箱提供深度。墙脚石基、木角柱、檐板和雨水管让各体量落地。
- 材质：奶油墙为高明度主体，青瓦为中低明度大色块，深色门和暖灰台面强调唯一入口。瓦片使用低对比三档颜色与浅厚度，未添加高对比黑格纹。
- 院落：院门向正门的曲线铺石路与横向通道连接五个活动点。种植带有清楚边界；两侧树、信箱和长椅形成不对称生活区域。
- 游戏：正门前站位 Blender `(-3.5, -8.7, 0)`，Godot `(-3.5, 0, 8.7)`；第三生活点移至门廊旁 `(-6.3, 0, 9.2)`。屋体使用三块简化碰撞，石径表面继续由主地面支撑。
- 检视：Blender1500×1320预览；Godot1440×900正常镜头、正门前镜头与同前版总览；960×640入户面板。视觉评审与引擎路线验证分开记录。

七个三级房间没有在本次重新建模；二级不再用七块房间剖面代表住宅外观。前版v01与旧原生截图保留用于对比。
