# 二级住宅 v2：院落模块

源码：`scripts/home_courtyard_detail.py`。在 Blender 内执行 `build_courtyard(m, helpers=None)`；`m` 是现有 `assets/blender/interiors/scripts/modeling.py`。函数返回占地与坐标摘要。

设计采用暖灰拼石、奶油色矮墙、深青铁艺、蜂蜜木条和分层绿色植物。入口曲线路径将门柱与正门连起来；横向通道串联五处生活互动。石材只出现在道路、花境边、树池和休憩铺地中。叶片是闭合的尖叶几何，树冠是分枝上的不规则低面簇，避免在地面随意摆满球形树和花瓣。

模块只建立静态院景和简化碰撞代理，不创建地板、住宅、锚点、交互状态节点、灯光、摄像机，不写出任何资产或 manifest。所有几何原创，无外部图片、模型和贴图。沿用原有 palette，新增 7 种纯色 PBR 材质。

## 本模块检查范围

已完成 Python 语法检查。使用不依赖 Blender 的模块执行替身检查 279 个自建 mesh：所有边恰有两个邻接面，所有网格有正向有符号体积。该检查只覆盖模块直接创建的 mesh；既有 helper 生成的 box/ball/beam 由既有管线校验。

5 个记忆点、主岛出口、出生点、正门站位均通过半径 `.45 m` 的静态碰撞圆检查。实际 Blender 导出、Godot 导入、路径行走和画面检查由完整住宅总装流程执行；本模块的静态检查不替代引擎验收。
