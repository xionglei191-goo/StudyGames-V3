# 字母岛：八册 81 章剧情清单

整理日期：2026-11-13。配合 [玩法与剧情梳理](玩法与剧情梳理-20261113.md) 阅读。

本清单从当前运行数据 [curriculum_arcs_v4.json](../../game/data/learning/curriculum_arcs_v4.json) 提取，保留教材单元顺序、原创生活事件、玩家目标和提纲中的结尾，便于后续逐章讨论。

**阅读口径：表中的“玩家目标”和“提纲中的结尾”描述章节想让玩家经历的事情。当前 81 章共用三幕推进框架，具体行为和世界变化需要逐项核对与制作。** 例如出现“修复展台”“开放毕业展”的文本，不能据此认定场景内已有对应的完整操作与结果。

三上 U1–U3 另有具体旅程步骤、人物事件与生活成果，详见主稿；原旅程与 V4 的章节阶段分别保存。教材题目来自现有内容包，生活事件为游戏创作。各单元的全正文教学审校仍需按 [来源提纲](../../game/data/learning/curriculum_arcs.json) 的记录继续完成。

全表共 8 册、81 章。册次单元数依次为 10、10、10、10、10、12、10、9。

## 逐章完善时的检查方式

- 看这一章为什么紧接上一章发生，结尾给下一章留下什么。
- 把目标拆成玩家确实能够执行的操作，为帮助和中断设计清楚的路径。
- 为参与人物补充愿望、困难和具体回应，明确本章由谁推动。
- 选定本章真正要使用的词句，并对照教材核实；语言目标应对应生活中的沟通需要。
- 指定可看见、可保存、可回访的成果；逐项确认实际完成了哪些制作。

本清单只整理既有章节内容，没有新增单元、改写剧情数据或修改游戏进度。
