# 家园画质样板

用户在看过 Godot 原生精修建议后授权执行。第一批限定为 `home_estate` 庭院和 `home` 客厅；沿用已有温暖、柔和、可游玩的微缩家园方向。

- 引擎：现有 Godot 4.7.2，Compatibility，1440×900 主验收；不改变渲染器或玩法架构。
- 镜头：原有斜俯视正交游戏镜头；另用固定近景和全景作明确标注的美术复核。
- 造型：树冠采用有分枝层次的叶簇；软装使用圆润体块和可读褶皱；家具保留简洁轮廓和克制倒角。
- 色彩：奶油墙、低饱和青绿、暖木、少量玫瑰粉；深色用于树叶内层和家具接触处，避免整体提亮压平。
- 材质：木材、陶器、织物、灰泥和植物分别处理；贴图随 GLB 内嵌，程序节点不能代替导出的真实材质。
- 光照：提高主光与环境填光的区分，加入局部遮蔽，保留昼夜/天气系统的调度。
- 预算：两处样板优先重用材质、合并细叶几何；新增细节集中在主镜头可见区域。实际面数、文件体积和原生帧耗随验收报告记录。
- 保留：旧版 `.blend` / GLB / 预览；所有原有互动、门、楼层、碰撞、家庭任务、聚会和装饰根节点。
- 验收：同机位原生 before/after，实际移动和门口转场，源与游戏资产一致，正式存档未变。外观检查与性能采样分别报告，不能由 Blender 渲染替代 Godot 验收。

本次为本地精修样板；源文件分别派生 `home_estate_v03` 和 `home_v03`，新旧版本都保留。视觉方向由用户授权后按现有项目风格选择，不批量改造其他场景。
