## 地图副本与原始精度

本机内存为 8GB。首次使用全部高分辨率材质预览时 Blender 失去响应，恢复后改为在地图中使用轻量副本：各地标最多约 50,000 个三角面，B 原有约 18,000 面保留；贴图上限为 1024 × 1024，仍保留已有的底色、法线和粗糙度/金属度贴图。

26 个地标从源资产合计 4,715,024 个三角面降至地图副本合计 1,268,031 个。所有 Tripo 源 GLB 的 SHA-256 校验值均未改变，可继续用于高精度近景和精修。这里的轻量化是地图工作副本的处理，并不要求重新生成 Tripo 模型。

整岛 GLB 约 137.1 MB，包含 3,481 个节点、约 1,762,369 个实例三角面、76 张内嵌贴图。已经完成整岛实际渲染，但尚未在游戏引擎中验证帧率；仍需后续 LOD、材质合批和碰撞优化。

## 模型更新

模型放在项目的 `assets/tripo/`，支持 `D.glb` 或 `D_drum_music_hall.glb` 这样的名称。同一字母有多个候选时选择修改时间最新的文件；A 固定使用 `A_apple_house/A_apple_house_optimized_v02.glb`。

打开当前地图工程后运行 [refresh_landmarks.py](refresh_landmarks.py)。它逐个检查源文件校验值，跳过未变化模型，替换变化模型并重新按第二版预算处理地图副本。刷新不自动保存，不重建地形和道路，也不会更新预览。新模型仍需人工核对正面、门口和台阶；源模型正面方向不一致时需要调整旋转。

在 Blender Python 环境执行外部脚本时提供 `__file__`：

```python
from pathlib import Path
p = Path('/Users/xionglei/Documents/StudyGame/assets/blender/alphabet_island/refresh_landmarks.py')
exec(compile(p.read_text(), str(p), 'exec'), {'__name__': '__main__', '__file__': str(p)})
```

[prepare_map_assets_v02.py](prepare_map_assets_v02.py) 负责地图副本减面和贴图预算；[detail_sites_v02.py](detail_sites_v02.py) 记录本次入口与道具更新；[save_map.py](save_map.py) 检查并保存当前版本工程、GLB 和清单，会覆盖同版本文件。准备新一轮迭代时先另存版本。

基础地形制作代码在 [world_builder.py](world_builder.py)、[layout.json](layout.json) 和 [refine_map.py](refine_map.py)。[build_world.py](build_world.py) 是最初的基础地图构建入口，不等于第二版的一键重建脚本。现阶段继续编辑应优先打开交付的第二版 `.blend`。
