# 二维学习素材 · storybook-v2

本套为 26 张字母学习插图及 10 张故事道具。B、O、K 复用已验收的 v1 原图；其余 23 个字母和 10 张道具由内置 image_gen 生成。统一使用奶油白、鼠尾草绿与暖木色的绘本风格。

- [完整清单](manifest.json)记录实际尺寸、透明边界、SHA-256、提示词、生成源路径和参考图。书封及单页参考本套书本底图，翅膀参考 v1 猫头鹰；其余新增图参考已确认的风格板。
- `source/` 保存未修改的 PNG 副本；运行时副本在 `game/assets/learning/storybook_v2/`。两个目录的 `props/` 子目录保存故事道具。
- 字母图由 `memory_story_content.gd` 的统一入口加载，供故事、补接候选、字母体验和发现卡使用；字母 PNG 缺失时仍使用原有 SVG。
- 道具由 `memory_story_stage.gd` 按需加载，以清单中的可见边界确定绘制 UV。书封、书页、足球和翅膀随原有动作进度变化；书的三张图缺少任意一张时，整本书回退原绘制。
- 图片文件不做裁剪、缩放、抠图或像素清理。缩放、透明边界取景及翻转只发生在游戏渲染中。Godot 使用无损、非预乘 alpha，关闭导入时的透明边缘颜色重写。

学习内容、字母编码和存档语义未因换图而改变。旧 SVG、v1 原图与历史版本产物均保留。动态文字、提示框、光束和连接线继续由程序绘制。

[本地开发流程](../../../docs/planning/art-refresh-all/local-workflow.md)说明原图检查与导入；[本轮验证](../../../docs/verification/art-refresh-all/)分别记录源文件检查和实际窗口验证。本轮只运行本地工程。
