## 语义边界

逐步映射包含 2,192 个具体道具步骤、395 个带运行时文字的卡片/相框步骤、21 个既有专用故事步骤、3,210 个抽象文字步骤和 297 个地点文字步骤。当前 1,314 条词条均有明确分类；“covered”表示映射完整，**不表示每一步都应显示一张具体物体图**。

- 只根据原课程明确提到的对象和已核对的具体名词选择图片；“模型、材料、东西、朋友、颜色”等通用词不自动变成另一件物品。
- 字母演员与其携带的道具分开处理；“第二朵花”“第三只猫头鹰”仍是演员，不额外复制成道具。
- 数量按源动作逐步配置并在运行时绘制对应实例。八的 2×4、九的 3×3、二十的 4×5及每组十根计数棒保留真实数量与排列。
- 三眼怪物的底图有三只眼。小提琴底图刻意不含琴弦，游戏在同一琴身上精确绘制四条弦；`runtime_parts.violin_strings`保留实际绘制端点诊断。
- 文字、数字和抽象含义保持运行时排版；卡片/相框内不烘焙伪造词条。牙刷、画笔、清水杯、果汁杯、交通工具和同形异义词分别处理。
- H3 不解析答案道具、不载入答案纹理、不绘制答案图；原学习判定、存档结构与故事原文未改写。

## 重建

在仓库根目录运行 `uv run --with pillow python -X utf8 scripts/build_story_prop_art.py`，会读取既有生成文件、复制资源、执行只读 alpha/SHA 检查并重建注册表和覆盖表；该命令不调用生成模型、不编辑课程文本。

重建或修改资源/驱动后，应重新运行受影响的原生检查并更新独立 `validation.json`，不能沿用 SHA 不匹配的验收结论。正式存档、已验收 36 张旧图、字母体验内容及旧动作关键帧均由专项保护基线另行核验。
