# 第一批生成式故事素材 · B / O / K

这批素材供词故事舞台、分步候选图片和字母体验页共同使用：B 小船、O 猫头鹰、K 风筝。由内置 `image_gen` 参照同一风格板逐张生成，采用奶油白、鼠尾草绿和暖木色，圆润轮廓、哑光手绘质感与透明背景。完整提示词、生成路径、源文件摘要和透明度数据见 [manifest.json](manifest.json)。

## 文件与导入

- `source/style-board.png` 是制作参照；`source/B.png`、`O.png`、`K.png` 是保存的原始生成结果。
- 游戏副本位于 `game/assets/learning/storybook_v1/`。三张均为 1254 × 1254 RGBA PNG；源文件与游戏副本 SHA-256 一致，没有对生成像素做后期改写。
- 使用 Godot 无损纹理导入，关闭 mipmap、预乘透明和 `fix_alpha_border`。关闭透明边缘自动修补是为了保留源 PNG 在低透明度处的颜色；已在游戏实际浅色背景上检查。
- `memory_story_content.gd` 通过资源加载器读取导入纹理，并在运行时缩放到现有 `160 × raster_scale` 接口尺寸。舞台与小按钮沿用原有布局；缺失映射资源时回退到旧 SVG。

## 使用边界

只替换表现素材。B/O/K 对应字母、学习内容版本、词条 ID、重复字母位置和动作顺序保持不变。`book` 的两只猫头鹰仍分别打开封面与翻开内页，随后由风筝托书；共享同一张 O 图片不合并两个演员。

这三张是二维插图。其余字母仍使用原有素材，三维兔兔、地图、骨骼和碰撞没有由这次图片替换生成。全部源图保留在工程中，旧 SVG 继续作为回退资源。

本批是生成素材，不宣称来自第三方素材库或具有排他性版权。项目内使用记录和实际画面验收见 [v0.6.1 实施记录](../../../docs/verification/v0.6.1/README.md)。
