## 使用边界

本包交付的是单视角参考图片。模型的隐藏侧面、拓扑、UV、骨架、动画、碰撞和引擎运行尚未在本轮验证。文件名中的 front 沿用人物包命名；动物按其解剖形态使用侧三分之四视角，具体以图片为准。

角色来源图来自现有教材项目；本包保留来源记录，不据此声明教材或既有形象的版权归属。未画出的下装、鞋袜和材质为游戏设计补充；群像未标名处保留对应关系的不确定性。
