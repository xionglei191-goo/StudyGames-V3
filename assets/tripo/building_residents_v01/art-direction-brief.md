# 字母岛建筑居民 · 美术简报 v01

日期：2026-11-12。阶段：供用户在 Tripo3D 中生成模型的角色正面参考图。

## 覆盖与身份

- 26 座字母建筑、山丘学园及其 7 个子场所，共 34 个独立居民；16 位人类、18 位动物。
- 建筑名称和房间 ID 来自当前项目 `game/data/landmark_interiors.json`。玩家住宅属于个人空间，此套不安排新主人。
- 每位有独立姓名、职业、服装、配色和后续模型 ID。兔兔、熊叔及教材主角的已有资源保留，新的场所主人作为后续独立角色。
- 当前阶段只交付图像与映射；场景主人、对话、任务关联将在模型导入阶段统一替换。

## 统一视觉方向

现有 Lingling 和熊叔正面图作为人类、动物的风格参照：圆润连续的身体、友善面部、柔和暖色、哑光布料、块面化毛发。每张均为新角色。成年人、老年人和少年通过面容、发型和体型区分；动物通过耳朵、口鼻、尾部与手足形状区分。

以大色块和职业服装优先建立识别：果园的苹果贴布、图书馆的书页徽章、天文台的星形纽扣、木琴乐手的琴键贴布。装饰尽量贴近身体。手持的水果、书籍、球与工具在后续场景内单独配置。

## 参考图规格

- 单张一个角色，完整正面全身，白色背景，均匀柔光。
- 双臂轻展，双腿分开，双手空置；头顶、耳朵、鞋底不裁切。
- 原始 PNG 原样复制进交付目录，保留工具输出元数据，不裁切、不拉伸、不重新编码。
- 方形、实际尺寸见 manifest.json；提示词目标为至少 1024×1024。生成图的实际构图留白以目视检查记录为准。
- index.html / preview/overview.png 用于选角和对照；独立 *_front.png 用于 Tripo。

白底、单主体、柔光和可辨认的 A 姿势符合 [Tripo 输入图指南](https://www.tripo3d.ai/help/features/how-to-get-better-image-to-3d-results) 的建议。正面图没有提供完整侧背几何，侧背部细节以生成模型后的检查为准。

## 后续模型交接

项目使用 Godot 4.x 的 3D 场景，当前实测引擎 4.7.2。生成后以 manifest.json 的 model_filename 保存 GLB，保持 room_id 与 resident_id 映射。按现有角色流程检查朝向、尺度、脚底、材质、蒙皮和步态；带尾巴、鹿角、鸟类翼手的角色需要额外检查连接和关节空间。服装贴布可先作为纹理处理。

这套 PNG 没有验证拓扑、UV、骨骼、碰撞、动画、运行时内存或帧率。所有这些验收属于模型阶段。
