# 美术交接简报

- 项目：Godot 3D 字母岛；本包为图生 3D 输入参考。
- 画面：白色不透明背景、单主体、柔光，图片最短边至少 1024 像素。原始尺寸见 manifest.json。
- 造型：圆润轮廓、清楚的主体边界、适量细节、柔和饱和色；人物使用空手 A 姿势，动物保持物种姿态，道具优先三分之四视角。
- 材质：柔和布料、雕塑化毛发与羽毛、温润木材，按对象使用金属；食品保留食物材质。
- 可见性：完整头部/帽饰/尾巴/双脚或物体轮廓。复杂背面与细小开口需要在生成模型后核验。
- 范围：参考图片已经生成并逐图目视核查；没有把它们直接当作可运行的模型或动画。
- 文件：每个资产一个 PNG 和一个建议 GLB 名称；最终提示词、来源参考与校验值都在同目录 JSON 文件中。
- 后续：先核对模型与图片身份，再校正比例、原点、接触面和碰撞；运动角色完成骨架/动画检查后再接入现有场景。
