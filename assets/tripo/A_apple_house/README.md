# A 苹果屋 Tripo 建模素材包

这套素材用于生成字母岛的 A 苹果屋外部模型。首次试模优先使用三分之四视角主图，验证苹果外形、A 形入口和材质，再把模型交回 Blender 做尺寸校正、构件拆分和场景整合。

本包包含 4 张独立 PNG 参考图、英文 Text to 3D 备用提示词及参考图生成提示词。素材已经完成，用户生成的 Tripo 模型已返回并接入果园。当前可用的 [精简苹果屋模型](A_apple_house_optimized_v02.glb) 有 79,999 个三角面；[整合场景说明](../../blender/A_orchard/README.md)记录了放置与检查结果。以下保留首次生成的操作说明。

## 首次操作

1. 打开 [Tripo Studio](https://studio.tripo3d.ai/)，进入 Image to 3D。
2. 上传 [01_primary_three_quarter.png](images/01_primary_three_quarter.png)，每次只生成这一座苹果屋。
3. 首次建议选择 Clean Topology / Smart Mesh；若界面提供面数设置，先用约 **10,000 个三角面**作为试模起点，贴图用 **2K**。这些是本项目的初始制作参数，最终精度根据模型外观和游戏性能调整。
4. 生成完成后，旋转检查正面、两侧、背面和底部，按下方标准挑选结果。
5. 导出带贴图的 **GLB**，建议命名为 `A_apple_house_tripo_raw_v01.glb`。如同时生成了需要继续编辑的四边面网格，再保留 **FBX 和贴图**。
6. 把导出的模型与贴图放回本项目，再进入 Blender 修整和场景整合。

Tripo 官方提供 Image to 3D、可控制面数的 Smart Mesh 和导出功能；具体可用选项以账号界面为准。[图生模型说明](https://www.tripo3d.ai/product-doc/model-generation/image-to-3d) · [导出说明](https://www.tripo3d.ai/product-doc/export-and-integration/export-dcc)

### 需要补充视角时

如果单图生成的侧面或背面明显不正确，可改用 Multi-view，分别上传 **02 正面、03 右侧、04 背面**。每张图是同一个模型的一个视角，不要将它们作为三个不同模型批量生成，也不要把多张图拼成一张再上传。

Tripo 官方说明 Multi-view 接收 2—4 张独立图片，并要求设计、尺度和光照一致；该模式不接受文字提示词。本包的 [英文提示词](tripo_text_to_3d_en.txt) 仅用于 Text to 3D 备用路径或人工交接。[多视图说明](https://www.tripo3d.ai/product-doc/model-generation/multi-view-to-3d)

## 苹果屋的固定构件

| 构件 | 规格 |
|---|---|
| 苹果外壳 | 红色、矮胖、圆润，底部平稳，顶部有果梗凹窝；外壳稍宽于高，保持完整体积 |
| 木柄 | 一根较粗的短弯木柄，与苹果顶部连接 |
| 叶片 | 一片宽绿叶，有厚度；主图及正面中向画面左方展开 |
| A 形入口 | 蜜黄色木材；两根斜梁在顶部相接，一根横梁连接两侧；圆角、有厚度，紧贴前立面并延伸到门口地面 |
| A 内侧 | 横梁上方保留三角形区域；后方可以是苹果外墙，无需贯穿房屋 |
| 房门 | A 横梁下方的拱顶木门，门上半部小窗、正面右侧门把手；当前图为关门状态 |
| 门槛 | 门前一块浅木质门槛，与房屋相连 |
| 侧窗 | 左右侧各一扇竖椭圆木框窗，位置与大小相近，窗内十字分格 |
| 背面 | 连续红色外壳，保留苹果形体，不增加后门、字母或背面窗 |
| 材质 | 红色柔和光泽外墙、绿叶、温暖木框与木门、琥珀色窗面；图中高光与阴影不是额外几何 |

A 必须能从正常游戏视角辨认，作为入口框架融入建筑。若 Tripo 把它做成贴图、缺一根横梁、熔成模糊凸起或堵住房门，保留好的苹果主体，在 Blender 中重建这组入口构件。

首轮只生成建筑外部。果树、篮子、道路、围栏、花草、场地底座、室内家具和内部五个记忆位置均在后续 Blender 场景阶段制作。

## 生成后的选用标准

- 苹果外形在正面和背面都成立，有完整厚度，底部能够落地。
- 一根木柄、一片叶子均连接正常，没有复制、悬浮或破损。
- A 字形清楚，门位于横梁下方；门框与主外壳没有严重穿插。
- 两侧窗户的位置合理，背面保持简单。
- 没有多生成底座、草坪、人物、独立标牌或散落物。
- 转动模型时没有明显塌陷、破洞、拉长尖刺或黑色贴图块。
- 苹果与木框的形体优先；少量木纹差异、窗格和门把手细节可留给 Blender 修正。

## Blender 交接规格

下面是项目搭建目标，图像和 Tripo 生成本身不保证精确尺寸或对象拆分。

- 坐标统一为 Z 向上，正门朝本地 -Y，地面中心作为原点。
- 苹果主体宽度先按约 6 米布置；比例以主图为准，门洞净宽约 1.2 米、净高约 2 米，由 Blender 按角色尺寸校正。
- 建筑主体、木柄、叶片、A 形木架、门、侧窗、门槛应尽量保留独立编辑能力。Tripo 输出合并网格时，后续拆分或重建必要构件。
- 当前关门外观不代表已经有可开合门、门后空间、碰撞体或室内。可通行门洞、门扇动画、碰撞体和室内由后续制作补齐。
- 生成的 2K 材质是试模起点；导入 Blender 后检查颜色、法线、粗糙度与发光设置，避免把参考图的强高光当作固定颜色。
- 原始导出文件保留一份，后续修改另存版本；这次无需生成角色绑定或动画。
