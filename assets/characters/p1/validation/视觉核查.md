## 采集证据

使用现有学校 GLB、Godot 4.7.2 原生 Compatibility 渲染，固定实际游戏观察方向 `(18, 25, 24)`，近景正交镜头 960×600。按 0.05 秒动作步长保存 **364 张 PNG、8 段 GIF、2 张关键帧拼图**，所有帧保存返回值为 0，原生进程正常结束，`render.stderr.log` 为 0 字节。

逐段检查起始、0.65 秒、接触/中段 1.1 秒、结束帧，并放大检查招手与放篮的关键帧。拼图可快速比较，GIF 可检查时间连续性；原始逐帧数据与挂点坐标保存在 [capture-report.json](capture-report.json)。GIF 为原生 PNG 缩放和拼接，首尾停留各 1 秒，中间每帧 50 毫秒，没有补画或生成替代帧。

## 程序化复核

[动作测试报告](../../../../game/actors/p1/animation-test-report.json) 为 **623 项检查通过、68 次动作测量、0 项失败**。普通与减少动态版本均测试；本目录原生截图展示普通版本。

- 预测接触点与真正 `BoneAttachment3D` 手部节点同步，最大坐标误差约 0.000002 米。
- 站姿动作的最低脚底约高于地面 0.005 米，根节点无漂移；步行支撑另有脚底近地检查。
- 2.2 / 2.4 秒动作按完整时长结束，接触动作在 1.1 秒触发一次，再完成恢复动作。
- 同一非空事件键重播两次仍展示两次接触，但语义回执仅一次；持久化奖励由任务层负责。
- 暂停/后台、剧情参与者和减少动态切换均有检查，Jim 拒绝步行、站起与地面拾取。
- 真实移动测试覆盖障碍和水边；角色移除后跨帧释放引用、外部释放及交互数组清理均通过。

## 证据边界

本目录使用校园固定镜头和接触检查道具，果园中的真实果枝遮挡、原 NPC 显隐、玩家路线、任务按钮与回执由果园集成证据单独覆盖。当前模型使用刚性 BoneAttachment，未蒙皮，未下载或上传 Mixamo/Tripo。教材全角色完成情况仍以总策划和角色清单为准。

这次没有在截图读取期间采集帧率；环境风、水的固定镜头动态序列和 GPU 性能由独立报告覆盖。已有天气/时段静态组合图不能替代风、水连续动作的验收。

## 复现

使用 [capture_p1_actor_actions.gd](../../../../game/actors/capture_p1_actor_actions.gd) 进行原生采集，再以具备 Pillow 的 Python 执行 [build_validation_media.py](../build_validation_media.py) 汇总 GIF 与拼图。原生采集会占用 GPU，应与性能采样错开。
