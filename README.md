# StudyGames V3 · 字母岛

面向小学生的生活模拟与英语学习项目。当前 **v0.11.0-dev · 小岛界面整理** 将位置与心愿收在左上，地图、背包和旅行册合在底部；旅行册采用当前旅程与分类目录两页，地图、对话和其他面板统一标题、间距与按钮样式。当前引擎实拍与专项验证见 [主界面更新记录](docs/verification/main-ui/README.md)。

保留 v0.10.0 的可编辑字母发现卡、五街区旅行页、U3 欢迎桌与四幕小聚会，以及八位朋友基于已保存经历的回应。第一站实际体验完成后就能做发现卡；作品确认后可带回小屋，之后继续改样式。功能范围见 [生活纪念记录](docs/verification/life-keepsakes/README.md)。

打开「旅行册 → 发现卡和街区旅行页」看收藏；U3 完成后打开「我们的欢迎桌 · 相聚回忆」挑桌布、换座位，再请朋友来坐坐；「去看看我的朋友」可回访已结识的人。新作品不增加或消耗叶币，重看与改样式不会复制成果，也不会新增英语掌握记录。真实间隔复现调度、统一家长观察页和八册 81 章完整生活事件仍未完成。

沿用 v0.9.0-dev 的移动与镜头：连续路径不再逐点停顿，起停有短缓冲，右键随时停止，鼠标滚轮可拉近；对话镜头配上真实角色头像。中文界面使用圆体、暖纸色和更清楚的字号，小窗口自动放大界面。该版历史画面与专项结果保留在 [体验优化记录](docs/verification/cozy-ui/README.md)。

v0.8.1 的「我的朋友角」样板继续保留：先选邀请封面，完成 U2 投递与收信，再把回信挂在自己的欢迎合照旁，回访的朋友会记得那张邀请。入口为「旅行册 → 我的朋友角 · 小岛心愿」。支持拖放或点击摆放、暂存试摆、确认、取消和旧档迁移，U2 结束后由玩家选择布置、继续 U3 或自由活动。原范围与实拍见 [朋友角样板验收](docs/verification/friend-corner/README.md)。

家园准备、五街区短旅、26 个字母体验、三年级上册 U1 欢迎会及 U2/U3 连续生活事件沿用已完成的 P0–P2。字母体验包含对应物件操作与原始三维地标的字形观察；U3 按实际人数摆座位，提示、示范、跳过可选回想和存档恢复继续保留。此前完整范围见 [P0–P2 验收记录](docs/verification/p2/README.md)。

沿用 v0.7.0 的 12 个 Blender 蒙皮角色、6 种近景道具、6 类场景材质、182 张新增透明 PNG 和原有 36 张学习插图；完整美术来源及此前专项检查见[美术整合验收](docs/verification/art-finish-v3/README.md)。地图仍分为“主岛 → 场所 → 功能房间”，主岛之外共有 28 个二级场景和 7 个校园三级场景。

后续制作以 **[GDD 游戏设计文档](GDD.md)** 为总入口，统一主线、八册单词故事与动态美术资产策划；[整合核查记录](docs/planning/integration/冲突核查与整合记录.md)列出已修订的冲突和待验收工作。GDD 中 P3/P4 的八册完整课程及后续扩展仍是后续范围；当前实现以本轮验收记录为准。

## 本机运行 v0.11.0-dev

Windows 下双击根目录的 **[启动字母岛.cmd](启动字母岛.cmd)**，默认用本机 Godot 4.7.2 直接运行当前 `game/` 工程；也可运行 `./start-game.ps1`。`./start-game.ps1 -Editor` 打开工程编辑器。当前迭代只做本地运行与必要测试，不导出 EXE 或制作 ZIP；启动入口不会因 `build/windows` 中存在旧文件而自动切换到旧成品。[本地开发流程](docs/planning/art-refresh-all/local-workflow.md)说明素材复制、检查和导入步骤。

查看词故事：打开「旅行册 → 教材里的词故事」，搜索 `book`，选择「我们一起看」并播放。两只猫头鹰分别打开封面和翻开内页，风筝最后托起书。字母图共用于故事舞台、补接候选、字母体验页和果园发现卡。原有 10 张道具图包括书的底图/封皮/翻页纸、足球、门、窗框、阅读台、球门框、猫头鹰翅片和鼓槌；新增道具按每一步的具体对象匹配。新增 182 张图中，181 张用于故事实体，科学烧瓶为界面专用；连同原有 36 张，登记资源共 218 项。原图、生成提示词和对应故事登记见[故事与界面素材](assets/art/story_props_v3/README.md)。动态文字、提示框、光束及连接线仍由程序绘制，抽象含义保留文字；1,314 条词表记录已建立素材/文字处理映射，逐词教学内容仍需编辑审校。

三维角色见[角色源工程](assets/characters/storybook_v3/README.md)，包含玩家、熊叔、兔兔和 9 位已实现教材人物；眨眼、笑容与说话表情作用于真实网格。苹果、篮子、蛋糕、书本、邀请函和姓名牌，以及木材、树皮、植物、纸张、布料、墙面的细节见[近景与场景美术](assets/art/world_refresh_v3/README.md)。角色动作骨架、地图布局、碰撞和交互标记保持原有约定。

[v0.6.1 Windows 离线包](build/AlphabetIsland-v0.6.1-Windows.zip)是保留的历史成品，只包含首批 B/O/K 插图更新；其 123 项成品检查见 [v0.6.1 实施记录](docs/verification/v0.6.1/README.md)，不能代表当前开发版。只有明确需要运行旧成品时才用 `./start-game.ps1 -Built`。P1 的样板验收和原性能记录保留在 [v0.6.0 实施记录](docs/verification/v0.6.0/README.md)。

## 获取完整素材

`.blend`、`.glb` 和 `.zip` 文件使用 Git LFS。克隆前安装 [Git LFS](https://git-lfs.com/)，然后运行：

```sh
git lfs install
git clone https://github.com/xionglei191-goo/StudyGames-V3.git
cd StudyGames-V3
git lfs pull
```

游戏地图日常编辑使用 v06_game，v05 保留作原始版本。二级地图各自包含 Blender 工程、GLB、预览与导出检查；原始素材的完整从零重建流程尚未验证。

历史地图版本和原始模型一并保留。Blender 自动备份、Python 缓存和本机临时文件不纳入版本控制。
